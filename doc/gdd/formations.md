# 陣形スキル（レシピ・カタログ）

**特定のユニット配置（編成レシピ）が盤上で揃うと発動できる能動アクション**＝senaris 独自の看板機能。「配置で撃つ特殊能力」であって、ただの配置バフではない。

- **本書はレシピの正本（カタログ）**。冒険譚が増えるたびにここへ追記する（ユニット表 [units.md](units.md) と同じ「増える表」の位置づけ）。
- 参加者が発動者1体だけで、効果を味方1体に乗せるものは **ユニットスキル** として別に置く。仕組み（レシピ・行動完了・状態補正・持続の数え方）は本書と共通で、カタログだけを分けている。

---

## 共通ルール

- 発動は **プレイヤーの明示操作**（条件が揃っても自動では出ない）。
- レシピが要求するユニットは **スキンID で照合**する（スキン未指定の駒は種別IDへフォールバック）。性能が同じでも見た目が違えば別物＝クレリック性能のゴブリンはグレイスに参加できない。敵に陣形スキルを持たせるときは、その陣営のスキンをレシピに書く。
- **参加ユニットは行動完了**（1体は1ターンに1つの陣形スキルにのみ参加）。
- 参加者のレベルは、着弾のあるレシピだけ上がる。攻撃と同じ「戦ったら+1・倒したらさらに+1」（→ [combat.md](combat.md)）を**1発の単位**で当てる＝面で何体倒しても +2 が上限、対象に1体も当たらない空撃ちは 0。効果が味方に乗るだけのレシピ（②）では上がらない。
- 参加できるのは**そのターンまだ行動を使っていない**駒（待機も攻撃もしていない）。囲まれて行ける先が無い駒も参加できる＝発動に移動先も攻撃相手も要らない。
- **発動者は移動してから発動してよい**。レシピの成立も射程も移動先の位置で判定する。参加する残りのメンバーはその場に留まる（移動すると行動を使い切るため）＝寄ってきた1体が号令をかける形になる。単独発動のユニットスキルも同じ扱い。
- 効果は原則 **間接攻撃扱い**＝**支援は乗らない／包囲は乗る**（[combat.md](combat.md) 間接攻撃）。※バフ系は対象の攻撃/防御に準ずる。

## 設計原則（レシピを増やすときの判断軸）

陣形スキルは「殴るか、スキルか」の二択を作る装置。レシピを足すときは、効果を決める前にここを通す。

二択はターン単位ではなく駒単位で成立する。共通ルールの「参加ユニットは行動完了」が値札で、プレイヤーが実際に迫られるのは「このステージでスキルを撃つか」ではなく「この駒を殴らせるか、供出するか」。盤に12体いれば12回の判断になる。

### 1. すべてのスキルは行動で値付けする

生産が無いため、この作品で補充される資源は行動しかない（兵数は減る一方で、増えるのは拠点占領の garrison だけ）。効果の強さを議論する前に、何行動ぶんかを決める。

### 2. コストは、その駒の本業で払わせる

本業は駒ごとに違う。攻撃力の低い駒で払えるスキルは実質タダで、二択にならない。

| 兵種 | 本業 |
| --- | --- |
| 魔法兵 | 殴る（間接で、貫通を持つ＝対アーマー） |
| 占領兵 | 占領する。増援・湧きの停止・回復・勝利条件をすべて握る（[map.md](map.md)） |
| 歩兵・重装 | 前線を保つ／包囲の頭数になる |

### 3. 面・射程・持続で払わせ、威力では払わせない

ダメージ系の威力は発動者1体の実効攻撃力に留め、参加者ぶんを合算しない。合算した瞬間、常にスキルが勝って二択が死ぬ。例外は⑨マジックアロー（2人・単体）で、合算ではなく「大きい方＋10」に留める＝2人・単体なら壊れないことを試算で確かめたうえでの例外（[../campaign/roadmap.md](../campaign/roadmap.md) ネタ帳の試算：素の合算＋貫通は通常攻撃2回に勝てない）。面のレシピには持ち込まない。①が3行動で1体ぶんの威力なのはこの原則によるもので、敵が1〜2体なら普通に殴ったほうが強い状態を保つ。

威力の攻撃力は相手によらず常に対地値で計算する＝対空値は見ず、飛行の敵にも同じ威力で通る（`atk_air` 0 のパラディンの③でも飛行のボスを狙撃できる）。対空の得手不得手は通常攻撃の住み分けで、聖なる光や爆発が空に届かない絵にはならない。例外は矢のレシピ（④トリックショット・⑥アローレイン・⑨マジックアロー）で、通常攻撃と同じく相手が飛行なら対空値・地上なら対地値を使う（弓兵の本業＝対空がそのまま威力になる）。

### 4. コストが定数だと、二択は解ける

「敵3体以上で撃つ」のような定数解が出ると、プレイヤーは初回に計算して以後考えなくなる。盤面によってコストが変わるスキルのほうが寿命が長い。

### 抑え方の分類

レシピごとに、どれで抑えるかを決めておく。混ぜない。

| 抑え方 | 調整する場所 | 例 |
| --- | --- | --- |
| コスト | 数値（行動数・威力・射程） | ①トリニティノヴァ・⑥アローレイン・⑨マジックアロー |
| 機会費用 | マップ（競合する仕事を置く） | ②グレイス・⑤シールドウォール |
| 可用性 | 編成（そのユニットを置くか） | ③ディバインジャッジメント |
| 位置 | 対象の周りの配置（誰かを敵に張り付かせる・対角に置く） | ④トリックショット・⑧バックスタブ |
| 本業 | 供出する駒の仕事（魔法兵の貫通攻撃＝敵の魔法を止めるために自分の魔法を撃たない） | ⑦マジックシールド |

①はコストで抑える。3行動で1体ぶんの威力。加えて着弾面（中心＋周囲6）と包囲の輪（敵の隣接6）は同じ図形で、参加者以外の味方は焼ける。包囲は乗るので、囲むほど威力が上がり、囲むほど自軍を焼く。盤面に依らず常に同じ判断になる。

②はマップで抑える。`_cluster` は連結成分の探索なので、敵を囲んだ占領兵の輪はそのままクラスタになる＝配置の競合は起きない。参加者はクラスタ全員で人数を選べないため、効果は人数で伸ばす（5体 ×1.3・1体ごとに +0.05）＝固まっているほど消費だけが増える形にしない。効いているのは占領との機会費用のほうで、占領がやりたいこと（バラす）とレシピが要求すること（固める）が真逆な点、およびクレリック／プリーストの足の遅さが痛みの実体。拠点の取り合いが無いステージではタダに戻るため、グレイスが使えるステージには、そのターン占領兵が向かうべき拠点を必ず置く。中立拠点の garrison を強くするほど二択は鋭くなる。

③は編成で抑える。パラディンをレアにすることで、レベルデザインが解禁／封印を直接握る。数値調整の対象外で、強すぎて構わない。

④は位置で抑える。斥候が対象の敵に隣接していなければ撃てず、撃った斥候はその場に留まる＝足止めされたまま敵ターンを迎える（防20の駒を敵に張り付かせる）。2行動の値札はあるが、斥候の本業は殴ることではない（殴れば反撃で5〜7失う）ので行動の値札は軽く、実体は位置のほう。対地では通常攻撃2回と削りが同程度で「斥候を反撃に晒さない」交換、対空では斥候の行動がもともと空に効かないので実質1行動の貫通付きの矢＝対竜の決め技になる（エルフなら竜に7）。強いが、ステージでは教えず自分で見つけるレシピなので、見つけた人の褒美として許す＝発見の爽快感が値打ちで、数値で削らない。

⑤は機会費用で抑える。参加者は列から動けない（動けるのは発動者1体だけ＝共通ルール）ので、列を組んで受けるか、崩して前に出るかの二択になる。殴れる敵が居るなら殴るほうが強い（攻撃1回で敵を4〜5減らす＞守って1回の被弾で1人助かる）ため、使い所は「次の敵ターンに波が来るが、こちらからは届かない」ターン＝膠着の待機の上位互換。そこではタダになるが、効果を薄くしてあるので構わない（森に立つ程度）。②と同じく、列を組む場所と前に出るべき理由（拠点・時間制限）をマップに置くと二択が立つ。

⑥は①と同じくコストで抑える。3行動で1体ぶんの威力を19ヘクスに撒く。威力に倍率は掛けず、弓の素の性能（攻30・貫通なし）で自然に弱い＝地上には①の半分、鎧（防70）には1しか通らず、空には①並み。面が①より一回り広いぶん、参加者以外の味方を巻き込む範囲も広い（包囲の輪の外側まで焼く）。「軽い雨を広く降らせる・空の群れに刺さる」という弓の本業がそのまま出る。

⑦は本業で抑える。魔法兵の仕事は貫通で殴ること（原則2）で、結界を張るとその1発が消える。「ウィザードで撃つか、結界を張るか」が毎ターンの問いになり、敵に術者が居ない盤では張る理由が薄い（物理には効きが小さい）＝敵の顔ぶれで値打ちが変わる（原則4）。結界は地帯なので、中に留まるか出て殴るかの位置の問いも足す。

⑧は位置で抑える。対象を挟んでシーフの正反対に味方が居ないと撃てず、その味方は行動完了。値札は「対角に置く」で、相方は敵に張り付いたまま敵ターンを迎える（④と同じ痛み）。シーフ自身は反撃を受けず元の位置へ戻るので晒されない＝刺して消える。効果は貫通0.5の一撃で、満員の敵は倒せない（削った敵を仕留める技）。通常攻撃2回（相方が殴ってシーフが仕留める）と比べると撃破の線は上がる（防40で5→7・防70で3→5）が損失ゼロの代わりに相方の1発を失う＝「確実に仕留めて無傷で下がる」か「殴り合って倒す」か。

⑨はコストで抑える。弓兵と魔法兵＝本業がどちらも殴ることの2体を供出して、1発を「少し強く・少し遠く」する。実体は届かない相手に魔法兵級の一撃を届かせることで、威力は魔法兵の通常攻撃＋10 に留める（合算すると2人の小技がボスを1発で消す＝③を無用にする）。地上のボス級（防80）に5＝削りにはなるが決め技にはならない。

### 例外：発見型のレシピ

③のように「盤の構造を読み解いて、この位置から撃つと気づく」ことが主眼のレシピは、二択を背負わせない。迷わせることが目的ではないため、コストは軽くてよく、要るときに必ず在ることのほうが重要になる。設計の負荷はレシピ自身ではなく、手前のステージ（溜めを作る側）とマップの構造に乗る。抑えるのは可用性で行う。

### 増やすときの注意

- `count` 固定はインフレする。冒険譚内で戦力が持ち越されるため（[map.md](map.md) carryover）、軍が大きくなるほど固定N体のコストは相対的に安くなる＝後半ほど自動的にスキル側へ傾く。後発レシピほど `count` を上げるか、効果の強さと連動させる。②は後者（`buff_value_per_extra`＝基準人数を超えた1体ごとの加算）。人数で伸びるのは参加者を選べない `cluster` だからで、`triangle`／`escort` のように人数が固定のレシピには持ち込まない。
- パラディンを置くとは、③を解禁するということ。占領兵なので②の頭数にも入る。パラディンは `can_capture` を持つ中で最も戦える駒なので、占領要員として出したくなる場面がある。性能だけ借りて技を封じたい場合は、paladin 性能に別スキンを貼る（レシピはスキンIDで照合する＝共通ルール）。
- 相互隣接は見た目より狭い。`triangle`（①）は参加3体が相互に隣接している必要があり、ヘックスの輪では1つ飛ばしが距離2。発動者を挟んで左右対称に2体を置くと成立しない。密室や隘路で撃たせるステージでは、成立する配置が実際に取れるか座標で確認する。③の `escort` は発動者への隣接だけを見るのでこの制約が無く、厚み1の通路でも組める。

## 発動の演出

発動したら1枚絵のカットインを挟み、盤に戻って着弾を見せる。

```
発動 → カットイン（1枚絵・約1秒・スキップ可） → 盤に戻って着弾（揺れ → 面の光 → 被弾した駒を1体ずつ）
```

- カットインだけでは「どこに当たったか・誰に効いたか」が分からない。トリニティノヴァは7ヘクスに当たる面の広さが売りなので、盤に戻って結果を見せるところまでが演出。前半が華、後半が情報。
- 盤の駒はカットインの間、撃たれる前の姿のまま置く。兵数の減少も撃破の消滅も、下の着弾の中で起こす。カットインの裏で先に消すと、明けたときには何も起きない。
- 着弾は3段に分け、まとめてではなく順に出す。一度に全部出すと1回の大きな明滅になり、何ヘックスに当たって何体が受けたのかが読めない。
  1. 画面全体が短く揺れる。当たった合図＝盤エリアだけでなく画面全体を揺らす（加護の光と同じ扱いで、右の情報ボックスも同じ衝撃の下に置く）。
  2. 効果範囲のヘックスが光る。駒の居ない空ヘックスも光らせる＝面の広さが伝わる。
  3. 被弾した駒を1体ずつ、少し間を置いて処理する。駒ごとに エフェクト → 被弾フラッシュ → 兵数の更新、撃破ならその場でフェードアウトしてから消える。順番は着弾中心に近い駒から外へ。
- ディバインジャッジメントは単体対象で面の広さが無いため、着弾だけ専用シーケンスにする：対象ヘクスが光って一拍ため → 光の柱がゆっくり降りて着弾（この瞬間に被弾フラッシュ・兵数更新・撃破フェード）→ 柱はしばらく立たせてから引く。柱の絵は幅基準で大きく出す（縦長の絵を長辺基準に収めると痩せる）。絵が無ければ共通の3段に落とす。
- 駒に重ねるエフェクトはレシピごとに1枚を描き、規約解決する（`godot/assets/formations/{recipe_id}_impact.png`。置き場と命名 → [../art/keyvisual.md](../art/keyvisual.md) §3）。武器の攻撃エフェクトのカタログからは借りない。借りると発動者スキン次第で剣の弧が天から降ってくる。絵が無いレシピは絵を出さず、面の光と被弾フラッシュだけで済ませる（欠けても穴は開かない）。
- この絵は盤でしか使わない（陣形スキルは戦闘演出シーンを通らない）ので、最初から下向き＝上から落ちてくる形で描く。演出側は回転させない。武器の攻撃エフェクトが「右へ向かう一撃」で描かれ盤で90度回されるのとは別扱いで、既存の攻撃エフェクトには影響しない。
- 大きさの倍率は持たない。絵の側を枠いっぱいに描いて釣り合わせる（攻撃エフェクトの `scale` 列に相当するものは無い）。
- グレイスのような着弾の無いものは、揺れも面の光も出さない。加護の光（画面外周から差し込む金の光）だけで見せる。光は画面全体に敷く（盤エリアだけに絞ると盤の右端で光が断ち切れる）。置き場所は画面の明暗の共通基盤（ScreenLighting）＝暗幕より前なので、暗転中も縁の光が生きる。前面パネル（右の情報ボックスなど）は光より前に浮く。
- カットインはクリック／キーで即座に飛ばせる。頭をロックしない（戦果票と違い1ステージに何度も出る＝止められる方を優先する）。着弾の3段も同じく飛ばせて、飛ばせば結果だけが残る。
- 陣形スキルで決着した場合（ボスを陣形スキルで倒す）も着弾を最後まで見せてから戦果票へ移る。決着の告知が着弾に割り込まない。
- 窓は戦闘演出シーンと同じ位置・大きさ・形（盤エリア中央の角丸の窓）。暗転は画面共通の基盤（ScreenLighting）で画面全体＝濃さは会話・戦闘と同じ。右の情報パネルは前面パネル層で幕より前＝沈まない。演出の見た目も揃う（→ [../tech/combat_scene.md](../tech/combat_scene.md)）。
- 絵はレシピごとに1枚。規約解決で、絵が無いレシピはカットインを飛ばして盤の結果だけ見せる（音は鳴らす）。置き場と命名 → [../art/keyvisual.md](../art/keyvisual.md) §3。
- 効果音は発動の頭にレシピIDの音、効果が届いた瞬間に同じIDの `_hit`（`assets/sfx/{recipe_id}.ogg` / `{recipe_id}_hit.ogg` の規約解決 → [../audio/sfx.md](../audio/sfx.md)）。レシピごとに音を変えるのは、面殲滅と全体バフが同じ音だと何が起きたのか音から分からないため。陣形スキルは戦闘演出シーンを通らないため、着弾音を `cmb_hit` から借りない。着弾音は揺れと同時に面で1回で、駒ごとには鳴らさない（被弾が続くたびに鳴らすと連打になる）。
- ユニットスキルにはカットインを付けない。単独で撃てて毎ターン飛ぶため、1秒の演出が毎回挟まると必ずスキップ連打になる。音（レシピIDの規約解決＝陣形スキルと同じ引き方。着弾音は無く発動音だけ）と盤の足元の光で足りる。

## 実装方針（決定）

- データ化の形式：当面は `godot/domain/formation/` にハードコード（各レシピは効果自体が個別でデータ化の旨みが薄い）。レシピが増えたら CSV/JSON 化を検討。AIの「ロジック＝コード／組合せ＝データ」とは違い、陣形スキルは効果ごとに専用処理。
- 形の判定：`triangle`（①）＝参加3体が相互に隣接（hex は3マス相互隣接で三角形）／`escort`（③）＝発動者に count-1 体が隣接、メンバー同士は不問／`cluster`（②）＝隣接連結が count 体以上。
- `spotter`（④）＝発動者は対象を射程に収め、もう1体（斥候）が対象に隣接。参加者同士の位置は不問。既存3つが「参加者の形」を見るのに対し、対象の周りを見る唯一の形。
- `line`（⑤）＝発動者を含む一直線上に途切れず連なる参加者が count 体以上。連なり全員が参加（`cluster` の直線版）。
- 段階実装：A＝フレームワーク＋①トリニティノヴァ／B＝③ディバインジャッジメント（①と同型・範囲違い）／C＝②グレイス（ターンまたぎの持続バフを新設＝最侵襲なので最後）。
- ④トリックショットは D＝③の単体着弾に貫通と対空／対地の切り替えを足すだけで、形の判定 `spotter` が新規。
- ⑤シールドウォールは C の持続バフの器に `{scope:participants, op:mul, target:def}` を足すだけ。形の判定 `line` が新規。
- ⑥アローレインは A の①と同型で、面の半径が2・射程が発動者依存・対空／対地の切り替えあり。形の判定は `triangle` の流用。
- ⑧バックスタブは D の単体着弾に、発動後の位置の戻し（移動開始位置を覚えておく）を足す。形の判定 `backstab`＝対象を挟んで発動者の正反対に味方が居る（ヘックスの対角＝対象からの方向ベクトルが逆）。
- ⑨マジックアローは D の単体着弾に、威力の元（大きい方＋10）と射程（長い方＋1）を2体から引く計算を足すだけ。形の判定は `escort` の流用。
- ⑦マジックシールドは C の持続バフの器に **地帯（zone）** のエントリを新設する＝`{scope:zone, hexes:7, op:add, target:def, value:10×兵数, pierce_immune:true, expiry:持続1}`。集計時に「対象の駒が地帯の中に居るか」を見る。貫通無効は combat の貫通の段で参照する新しいフラグ。形の判定は `escort` の流用。
