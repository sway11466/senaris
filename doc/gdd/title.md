# タイトル画面

起動して最初に出る画面。酒場に入り、卓の上のメニューから遊び方を選ぶ。絵と動画の素材仕様は [../art/menu.md](../art/menu.md) §5、曲は [../audio/bgm.md](../audio/bgm.md)。

---

## 画面フロー

```
起動 → 閉じた扉（入力で開ける） → 扉が開いて店内へ入る動画（入力でスキップ） → 店内の絵＋メニュー → 各項目へ
```

- 最初は閉じた扉を外から見せて入力を待つ。冒険者が依頼を受けに店の扉を開ける、という導入をそのまま操作にする。
- 再生中の入力でスキップし、その場でメニューを出す。飛ばしても最後まで見ても同じ画（動画の最終コマ）に着く。
- メニューが出た後は板のボタンだけが入力を受ける。板の外を押しても何も起きない。

## メニュー項目

| 項目 | 行き先 |
|---|---|
| 冒険の続き | オートセーブ＋中断スロット5枠の一覧から選んで盤へ（[../tech/gamesystem.md](../tech/gamesystem.md) §タイトル画面からの再開） |
| 新しい冒険譚 | 冒険譚選択（[stage_select.md](stage_select.md)） |
| 設定 | 設定画面 |
| マニュアル | 仕様リファレンス（ゲーム内の図鑑） |
| クレジット | 素材の権利表記（[../sales/credits.md](../sales/credits.md) の「ゲーム内クレジットに出すもの」を並べる） |
| おわる | 終了 |

- 項目は常に同じ並びで出す。いま選べないもの（行き先が未実装、中断セーブが無い）は沈んだ見た目にして並びだけ残す。起動のたびに並びが動かず、この画面から何ができるのかも分かる。
- 選べない項目も入力は受け取り、押すと拒否音を返す。無反応だと壊れているのか選べないのかが分からない（セレクトの未解放ステージと同じ扱い。[../audio/sfx.md](../audio/sfx.md)）。
- 冒険譚選択から戻ってきたときは、扉と動画を見せ直さず店内の絵とメニューだけを出す。項目は作り直す＝遊んでいる間に中断セーブが増減していれば「冒険の続き」の可否がそれに従う。
- 「冒険の続き」を押すとオートセーブ＋中断スロット5枠の一覧を表示する。選んだセーブが読めなければ冒険譚選択へ落とす。行き先が無いまま画面が止まらないようにする。セーブが1つも無ければ「冒険の続き」自体を選択不可にする。

## メニューの見せ方

操作の道具は酒場の物にしない。設定・マニュアル・クレジット・おわる は作中の誰の行為でもなく、アプリケーションの操作なので、木の板や看板に載せると無い物語を主張することになる。キャンペーンセレクトで繰り矢印と現在地ドットを無機質なグレーにしている（[campaign_select.gd](../../presentation/select/campaign_select.gd) の `DOT_COLOR`）のと同じ判断。逆に依頼ボードと貼り紙が酒場の物なのは、依頼を選ぶのが作中の行為だから（[stage_select.md](stage_select.md)）。

- 画面左半分の中央に、ボタンを縦一列で並べる＝列の中心は上下中央・左半分の左右中央。
- その下に中立の暗幕を敷く。左端から右へ抜ける横グラデーション1枚で、木目も枠も持たない。ボタンの帯を絵から分けるためだけのもの。
- 文字はボタン（不透明）の上に載るので、暗幕は文字の可読性のためではない。暗幕の濃さは絵を見せる度合いで決める。
- ボタンはセレクト画面・会話パネル・HUD と同じ木の板（[tavern_theme.gd](../../presentation/select/tavern_theme.gd)）。これは酒場の再現ではなく「押せる物は木の板」という作品共通の様式。
- 置き場は画面比で持つ。窓の大きさが変わっても絵に対する位置が動かない。

## タイトルロゴ

扉の絵にも店内の絵にもロゴは重ねない。作品名は起動スプラッシュ（[../art/menu.md](../art/menu.md) §6）が単独の画面で出し、遊んでいる間は盤の右上が常時出す（[uiux.md](uiux.md)）。この画面でもう一度載せると、外から扉を見ている画の上に UI の文字が乗って、入店の導入が壊れる。

## 音

- 動画の間は曲を鳴らさず、店から漏れるざわめきだけを流す。扉が閉じている間はこもらせ、扉が開くのに合わせて解く。
- メニューが出ると同時にメニュー曲へクロスフェードする。ここで初めて旋律が立ち上がる。
- 扉の軋みと焚き火は動画に入っている音をそのまま使う。効果音として別に鳴らさない。
