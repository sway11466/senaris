# エンチャント（レシピ・カタログ）

味方1体を強化する能動アクション。発動者が単独で撃てる陣形スキルであり、[formations.md](formations.md) と同じ仕組みの上で動く（レシピ・行動完了・状態補正・持続の数え方はすべて共通）。違いは参加者が発動者1体だけで、効果が陣営全体でなく選んだ1体に乗ることだけ。

本書はエンチャントの正本（カタログ）。冒険譚が増えるたびにここへ追記する。

---

## 共通ルール

- 発動はプレイヤーの明示操作。条件が揃っても自動では出ない。
- 発動者はスキンID で照合する（スキン未指定の駒は種別IDへフォールバック）。陣形スキルと同じ扱い＝ピクシー性能の別スキンは妖精の粉を撃てない（→ [formations.md](formations.md) 共通ルール）。
- 発動者は行動完了。1体は1ターンに1つのエンチャント／陣形スキルにのみ参加する。
- 対象は自分自身、または隣接する味方1体。
- 移動した後でも発動できる。陣形スキルは配置そのものがレシピなので自マスでしか撃てないが、エンチャントは他の参加者を必要としないため、動いてから掛けられる。隣接の判定は移動先で行う。
- いま効いているエンチャントは、ユニットを選択したときの情報パネルと戦闘レポートに出る。
- 演出は効果音（`map_enchant`）と盤の見た目（掛かっている駒の足元の光）だけ。陣形スキルのカットイン（1枚絵）は付けない＝単独で撃てて毎ターン飛ぶため、毎回1秒挟むとスキップ連打になる（→ [formations.md](formations.md) 発動の演出）。
- 重ねがけできる。2体が同じ相手に掛ければ効果は足し合わさる。同じスキルの重ねがけも許す（陣形スキルの既定＝同種を重ねないとは扱いが違う）。
- 持続はスキルごとに決める。数え方は陣形と同じで、発動陣営のターン開始で満了判定する（→ [combat.md](combat.md) 状態補正）。
- 発動主体は当面プレイヤーのみ。敵も使えるようにする方針だが、AIの思考軸を足す必要があるため段階を分ける。

## レシピ一覧

### ①妖精の粉（ピクシーダスト）— 単体強化

| 項目 | 内容 |
|---|---|
| 発動 | ピクシー1体（単独） |
| 対象 | 自分自身、または隣接する味方1体 |
| 効果 | 対象の実効攻撃力・実効防御力に `10 × 発動したピクシーの残兵数` を加算 |
| 持続 | 次の自軍ターン開始まで（自軍ターン1回＋間の敵ターン） |

- 加算は実効値に対して行う＝経験・包囲・地形の補正は乗らない。満員（8体）なら常に +80 と読める。
- 強さを決めるのは掛ける側の残兵数。損耗したピクシーが撒く粉は薄い。
- 値は発動した瞬間に決まり、以後は動かない。掛けたあとにピクシーが削られても倒されても、掛かった補正は変わらない。
- ピクシーは攻防10・移動5の飛行で、単体では戦えない。撃つ相手を選んで前線へ運ぶのが役割になる。

## 実装方針

- データ化の形式は陣形スキルに揃える。当面 `domain/formation/` にレシピとしてハードコードし、増えたら CSV/JSON 化を検討する。
- 状態補正エントリは `scope: unit`・`op: add` で積む（既存の器をそのまま使う＝新しい演算は要らない）。発動者の残兵数を掛けた値をエントリに焼き込むので、集計は掛けられた側だけを見れば済む。
- 対象選択の操作は陣形スキルの着弾ヘックス指定と同じ流れを使い、選べる範囲を自分＋隣接の味方に絞る。
