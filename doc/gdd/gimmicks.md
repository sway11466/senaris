# 仕掛け（カタログ）

盤の上に置く仕掛け（スイッチ・罠など）。拠点と同じく、地形とは別の層に置く物で、位置と状態を持ち、種類ごとの振る舞いで盤に効く。

- 本書は仕掛けの正本（カタログ）。種類が増えるたびにここへ追記する。
- 拠点 → [map.md](map.md) 拠点・占領。仕掛けの状態を見る勝利・敗北条件 → [map.md](map.md) 勝敗条件。

---

## 共通ルール

### 置き方（`gimmicks[]`）

ステージの本体 JSON に、仕掛けの配列 `gimmicks` を置く。

```json
"gimmicks": [
  { "id": "switch-a", "kind": "production_switch", "col": 3, "row": 5, "state": "on",
    "base": { "col": 8, "row": 3 } }
]
```

| キー | 意味 |
|---|---|
| `id` | ステージ内で一意の名前。必須。勝敗条件とセーブはこの名前で仕掛けを指す |
| `kind` | 種類（下記 カタログ）。必須 |
| `col` / `row` | 置くマス。必須 |
| `state` | 最初の状態。必須。選べる値は種類ごとに決まっている |
| その他 | 種類ごとの固有の要素。その種類が要るものだけを書く |

- 1マスに置ける仕掛けは1つ。
- 種類の定義（状態の一覧・固有の要素・振る舞い）はコードが持つ（陣形スキルと同じく、種類ごとに形が違うため）。

### 地形との関係

- 仕掛けは地形タイプを持たない。マスのルール（攻防・移動コスト・視線）は地図に描いた地形のまま＝森に置けば森、平地に置けば平地。罠が床に擬態できるのはこのため。
- 地形のスキンとも関係しない。どの床の上にも同じ仕掛けを置ける。

### 絵

- 種類ごとに、状態ごとの絵を1組持つ。盤の絵は `godot/assets/gimmicks/{kind}_{state}.png`（例 `production_switch_on.png`／`production_switch_off.png`）。
- 置き方は状態ごとに2つのどちらか。
  - 立てる：地形の上に、駒と同じく立ち絵として重ねて描く（スイッチ）。
  - 床に貼る：マスの中心に、床に寝かせた板として描く（床に刻まれた紋・床に描かれた注意マーク・爆発の跡）。上に立つ駒・手前の段差や駒とは、床と同じく前後を比べる＝駒は紋の上に立ち、手前の段差は紋を隠す。
- 状態の絵が無ければ何も描かない＝隠れている罠は床だけが見える。
- 見た目の数値は、仕掛けの見た目の表（[gimmick_visual.csv](../../godot/data/gimmicks/gimmick_visual.csv)）が種類ごとに1行で持つ＝状態ごとの置き方・盤での大きさ（立てる絵と床に貼る絵で共用）・手前に寄せる量（立てる絵だけ）・戦闘の隊列の後ろの絵の大きさ・罠の一撃の絵（攻撃エフェクトの名前。既存の絵を使い回せる）。置き方は「状態:stand」「状態:flat」を `|` で区切って1つのセルに並べ、絵のある状態を全部書く。振る舞い（状態の一覧・踏んだときの動き）はコードが持ち、表には書かない。地形・ユニットと同じく、見た目は表・振る舞いはコード、で分ける。
- 手前に寄せる量は、地形のオブジェクトと同じ意味（→ [terrain.md](terrain.md) オブジェクト）。駒より小さくする＝駒が仕掛けのマスに乗ると、駒が手前に立つ。
- 戦闘の画面にも、地形の重ね絵と同じ4つのスロットで出せる（→ [../tech/combat_scene.md](../tech/combat_scene.md)）。絵は `{kind}_{state}_combat_{スロット}.png`。置いてある絵だけを出し、状態は戦闘を開くたびに盤から引く。
- 種類によっては、決まった状態の間だけマスの床を光らせる＝駒が乗って絵が隠れても、足元のまわりで状態が読める。明滅させず、同じ明るさで光り続ける。光らせる状態と色は種類の定義としてコードが持つ（どの状態が「作動している」かは振る舞い）。隠れている罠は光らせない。
- 絵の作り方と書き出し → [../art/gimmicks.md](../art/gimmicks.md)。

### 踏む

- 駒が仕掛けのマスに止まった瞬間を「踏む」とする。止まるのは移動・降車・出撃のどれでもよい（出撃は1歩の移動）。
- 通り抜けただけでは踏まない（プレイヤーが選ぶのは行き先だけで、経路は選べない。経路の途中で発動すると避けようがない）。動かずに待機しただけでも踏まない。輸送に乗ったまま（出撃先が輸送のマス）は盤に立たないので踏まない。
- 移動タイプは問わない（飛行も踏める）。
- 踏んだときに何が起きるかは種類が決める。

### セーブ

- 中断セーブは、仕掛けの `id` → 今の状態、の表を持つ。座標は持たない＝マップを直して仕掛けを動かしても追える。
- 再開のときは、ステージ JSON で仕掛けを組んでから、`id` で突き合わせて状態を被せる。セーブにあってステージから消えた仕掛けは捨て、足された仕掛けはステージのまま出す。

## 罠

踏むと効く、隠れた仕掛け。種類ごとの振る舞いは下記 カタログ。

- 魔法の罠と機械の罠がある（敵に魔法と機械の系統があるのと同じ）。
- 強さを変えたいときは別の種類にする＝値は種類ごとに固定で、置くたびには指定しない。
- 一度きりか何度も発動するか、敵味方のどちらに効くかは、種類ごとに決める。
- 敵AIは罠を避けない（経路は移動コストだけで選ぶ）。

### 見え方

| 段階 | 盤 |
|---|---|
| 隠れている | 何も描かない＝床だけが見える |
| 見つかった | 種類ごとに決める（紋そのもの・注意マークなど） |
| 発動した後 | 種類ごとに決める |

- 罠の種類と効果は情報パネルで分かる。

### 罠発見

罠を見つけて、見つかった状態にする。ユニットスキル「罠発見」（[skills.md](skills.md)）として持ち、持ち主によって発動の形が違う。

- 罠発見は調査範囲を持つ。基本は移動力と同じ値。
- 調査範囲は視線距離で測る（[movement.md](movement.md) 視線）＝壁の向こうは見えず、森ごしは近くまでしか見えない。
- 斥候（兵種「斥候」の味方すべて）: アクティブ。発動した場所から、調査範囲内の罠が分かる。使った後も移動できる（攻撃の後と同じ再行動）。
- 調査ドローン: 行動完了スキル。行動完了した場所（待機・攻撃の後。何もしなければターン終了時の場所）から、調査範囲内の罠が分かる。
- 見つかった状態は盤で1つ＝どちらの陣営が見つけても同じ。敵は罠発見を使わない。

### ダメージの罠（共通）

- 攻撃として計算する（[combat.md](combat.md) 攻撃力・防御力の計算式）。罠の種類が自分の攻撃力・貫通率を持ち、兵数は8として計算する。
- 撃つ側に補正は乗らない（レベル・包囲・支援・地形・状態）。受ける側はふだんどおり（立っているマスの地形・支援・状態）。
- 罠で倒れる（兵数0で消滅）。
- 移動は攻撃・待機などを選んだ瞬間に確定し、罠はそこで発動する。罠で倒れたら選んだ攻撃は取り消す。生き残ったら減った兵数で攻撃する。
- 盤の上で見せ、カットインを挟む（戦闘の画面には切り替えない）。カットインの絵が無ければ飛ばす。
- 一撃は、撃たれた駒の上に絵を出して留める（出る 0.15 秒・留める 0.45 秒・消える 0.3 秒）。兵数は絵が出きった瞬間に減る。毒の演出も同じ見せ方。一撃の絵が無ければマスを光らせるだけ。

## カタログ

### 雷の紋（`thunder_sigil`・仮の ID）

魔法のダメージの罠。紋に稲妻が1本落ちる。強さは中。

| 項目 | 内容 |
|---|---|
| 効く相手 | 踏んだ駒1体。敵味方とも |
| 回数 | 踏むたびに発動する |
| 貫通 | 貫通率0.5（魔法兵と同じ＝防御を半分無視） |
| 見つかった後 | 雷の紋の絵を描く |
| 発動した後 | 見つかった扱い＝雷の紋の絵のまま |
| 一撃の絵 | 枝分かれした青白い稲妻が、上から駒へ落ちる |

### 地雷（`landmine`・仮の ID）

機械のダメージの罠。踏むと爆発する。

| 項目 | 内容 |
|---|---|
| 効く相手 | 踏んだマスと、その隣のマスの駒。敵味方とも |
| 回数 | 一度きり |
| 貫通 | なし（物理） |
| 見つかった後 | 注意マークを描く |
| 爆発した後 | 爆発の跡を描く（散らばった爆弾の破片。効果なし・見た目だけ） |
| 一撃の絵 | ボマーの爆発を使い回す |

### 生産装置のスイッチ（`production_switch`）

拠点の生産（[map.md](map.md) 生産）を止める・再開するスイッチ。

| 項目 | 内容 |
|---|---|
| 状態 | `on`（生産する）／`off`（生産を止める） |
| 固有の要素 | `base`＝対象の拠点の位置 `{ "col": C, "row": R }`。必須 |
| 味方が踏む | `on` なら `off` にする。`off` なら何も起きない |
| 敵が踏む | `off` なら `on` にする。`on` なら何も起きない |

- 拠点の持ち主は変えない。控えの出撃もそのまま。
- `off` の間、対象の拠点は生産しない＝チャージが溜まらず止まる（生めない間は止まる、と同じ）。
- コマンドメニューの「待機」は、踏むと状態が変わるときだけ「スイッチ停止」と表示する（[uiux.md](uiux.md) コマンドメニュー）。
- `on` の間はマスの床が光る（→ 絵）。色は箱の正面の紋の赤。`off` にすると消える。
- 敵AIがスイッチを踏みに行く行動は持たない（未決）。

### チャージスポット（`charge_spot`）

踏んだ駒のスキルのチャージを満たす場所。溜まり方が `spot` のスキル（[skills.md](skills.md) 共通ルール・チャージ）だけに効く。

| 項目 | 内容 |
|---|---|
| 状態 | `on` だけ。踏んでも変わらない |
| 固有の要素 | なし |
| 踏む | 踏んだ駒が溜まり方 `spot` のスキルを持っていれば、そのスキルのチャージを必要量まで満たす。敵味方とも。持っていなければ何も起きない |

- 満たすのは踏んだ瞬間だけ。上に居続けても、それ以上は溜まらない（必要量で打ち止め）。
- 1マスに立てる駒は1体なので、味方の駒を乗せれば塞げる＝敵のボスはそこへ戻れない。
- 状態が変わらないので、踏んでも絵は変わらない。`on` の間はマスの床が光る（→ 絵）＝絵が無い間も場所が読める。
- 最初の実体は第1部ボスのマナリーク（[skills.md](skills.md)）＝スポットで溜め、撃ち、スポットへ戻る往復。
