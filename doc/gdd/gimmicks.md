# 仕掛け（カタログ）

盤の上に置く仕掛け（スイッチ・罠など）。拠点と同じく、地形とは別の層に置く物で、位置と状態を持ち、種類ごとの振る舞いで盤に効く。

- 本書は仕掛けの正本（カタログ）。種類が増えるたびにここへ追記する。
- 拠点 → [map.md](map.md) 拠点・占領。仕掛けの状態を見る勝利・敗北条件 → [map.md](map.md) 勝敗条件。

---

## 共通ルール

### 置き方（`gimmicks[]`）

ステージの本体 JSON に、仕掛けの配列 `gimmicks` を置く。

```json
"gimmicks": [
  { "id": "switch-a", "kind": "production_switch", "col": 3, "row": 5, "state": "on",
    "base": { "col": 8, "row": 3 } }
]
```

| キー | 意味 |
|---|---|
| `id` | ステージ内で一意の名前。必須。勝敗条件とセーブはこの名前で仕掛けを指す |
| `kind` | 種類（下記 カタログ）。必須 |
| `col` / `row` | 置くマス。必須 |
| `state` | 最初の状態。必須。選べる値は種類ごとに決まっている |
| その他 | 種類ごとの固有の要素。その種類が要るものだけを書く |

- 1マスに置ける仕掛けは1つ。
- 種類の定義（状態の一覧・固有の要素・振る舞い）はコードが持つ（陣形スキルと同じく、種類ごとに形が違うため）。

### 地形との関係

- 仕掛けは地形タイプを持たない。マスのルール（攻防・移動コスト・視線）は地図に描いた地形のまま＝森に置けば森、平地に置けば平地。罠が床に擬態できるのはこのため。
- 地形のスキンとも関係しない。どの床の上にも同じ仕掛けを置ける。

### 絵

- 種類ごとに、状態ごとの絵を1組持つ。盤の絵は `godot/assets/gimmicks/{kind}_{state}.png`（例 `production_switch_on.png`／`production_switch_off.png`）。
- 地形の上に、駒と同じく立ち絵として重ねて描く。
- 状態の絵が無ければ何も描かない＝隠れている罠は床だけが見える。
- 見た目の数値は、仕掛けの見た目の表（[gimmick_visual.csv](../../godot/data/gimmicks/gimmick_visual.csv)）が種類ごとに1行で持つ＝盤での大きさ・手前に寄せる量・戦闘の隊列の後ろの絵の大きさ。振る舞い（状態の一覧・踏んだときの動き）はコードが持ち、表には書かない。地形・ユニットと同じく、見た目は表・振る舞いはコード、で分ける。
- 手前に寄せる量は、地形のオブジェクトと同じ意味（→ [terrain.md](terrain.md) オブジェクト）。駒より小さくする＝駒が仕掛けのマスに乗ると、駒が手前に立つ。
- 戦闘の画面にも、地形の重ね絵と同じ4つのスロットで出せる（→ [../tech/combat_scene.md](../tech/combat_scene.md)）。絵は `{kind}_{state}_combat_{スロット}.png`。置いてある絵だけを出し、状態は戦闘を開くたびに盤から引く。
- 絵の作り方と書き出し → [../art/gimmicks.md](../art/gimmicks.md)。

### 踏む

- 駒が仕掛けのマスに止まった瞬間を「踏む」とする。止まるのは移動・降車・出撃のどれでもよい（出撃は1歩の移動）。
- 通り抜けただけでは踏まない。動かずに待機しただけでも踏まない。輸送に乗ったまま（出撃先が輸送のマス）は盤に立たないので踏まない。
- 移動タイプは問わない（飛行も踏める）。
- 踏んだときに何が起きるかは種類が決める。

### セーブ

- 中断セーブは、仕掛けの `id` → 今の状態、の表を持つ。座標は持たない＝マップを直して仕掛けを動かしても追える。
- 再開のときは、ステージ JSON で仕掛けを組んでから、`id` で突き合わせて状態を被せる。セーブにあってステージから消えた仕掛けは捨て、足された仕掛けはステージのまま出す。

## カタログ

### 生産装置のスイッチ（`production_switch`）

拠点の生産（[map.md](map.md) 生産）を止める・再開するスイッチ。

| 項目 | 内容 |
|---|---|
| 状態 | `on`（生産する）／`off`（生産を止める） |
| 固有の要素 | `base`＝対象の拠点の位置 `{ "col": C, "row": R }`。必須 |
| 味方が踏む | `on` なら `off` にする。`off` なら何も起きない |
| 敵が踏む | `off` なら `on` にする。`on` なら何も起きない |

- 拠点の持ち主は変えない。控えの出撃もそのまま。
- `off` の間、対象の拠点は生産しない＝チャージが溜まらず止まる（生めない間は止まる、と同じ）。
- コマンドメニューの「待機」は、踏むと状態が変わるときだけ「スイッチ停止」と表示する（[uiux.md](uiux.md) コマンドメニュー）。
- 敵AIがスイッチを踏みに行く行動は持たない（未決）。
