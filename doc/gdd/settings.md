# 設定画面

タイトルのメニューと盤のシステムメニューから開く、遊び方の設定をする画面。絵と音の材質の考え方は [../art/menu.md](../art/menu.md)、文言の扱いは [../tech/i18n.md](../tech/i18n.md)。

---

## 開き方と戻り方

- タイトルのメニュー（[title.md](title.md)）の「設定」と、盤のシステムメニュー（[uiux.md](uiux.md) システムメニュー）の「設定」から開く。どちらも同じ1枚を重ねて出す。全画面の暗幕が降り、その上に項目が出る。
- 「戻る」または Esc で開いた先へ戻る。暗幕が薄れて、タイトルなら店内の絵とメニューが、盤なら盤がそのまま戻る。タイトルは作り直さない＝扉と動画は見せ直さない。盤も進行を止めない＝敵ターンの途中に開けば、閉じたとき進んだところから続く。
- 開いている間、後ろへは触らせない。クリックは暗幕が止め、キーも設定画面が受け止める＝盤の上で Enter を押してもターン終了に届かない。
- 盤の中で言語を変えると、盤に入ってから作って生き続ける画面（HUD・情報パネル・会話パネル）も追従する。追従の仕組みと一覧は [../tech/i18n.md](../tech/i18n.md) 言語の切り替え。

## 見せ方

設定はゲームの中の世界観ではなく、アプリケーションの操作なので、酒場の設え（依頼ボード・羊皮紙・看板・焼き印・封蝋）を持たない。持ち込むのは作品共通の様式だけ。

- 暗幕は全画面。タイトルが敷く横グラデーションの暗幕（ボタンの帯を絵から分けるための膜）とは別物で、絵を均一に沈める1枚。設定を開いている間、酒場の絵は判読できる必要がない。
- 項目は画面中央に縦一列。左半分に寄せない＝絵が沈むので、絵を避ける理由が消える。
- 戻るは画面の左下。位置と大きさはセレクト画面と同じ規則に揃える（[stage_select.md](stage_select.md)）。項目の列には混ぜない＝戻る先はどの画面でも同じ隅にある。
- 開いている間はタイトルのビルド刻印を伏せる。同じ左下の隅なので戻るボタンと重なる（[../tech/build.md](../tech/build.md)）。閉じれば出直す。
- 押せる物は木の板（[title.md](title.md) メニューの見せ方と同じ様式）。板の外は無機質なグレーで、キャンペーンセレクトの繰り矢印・現在地ドットと同じ側に置く。
- 音量のつまみと数値の欄は Godot 標準の部品をそのまま使う。設定はシステムの操作なので世界観を織り込まず、文字の大きさと色だけ項目名に揃える。

## 項目

### 言語

- 日本語 / English を横に並べ、押した方へ切り替わる。切り替えはその場で画面に出る（再起動を挟まない）。
- 選択中は板の縁に灰色の細枠を回す。沈んだ板（`dim_wood_button`）は「押せるが選べない」を表す形として使っているので、非選択には使わない。同じ見た目が二つの意味を持つと読めなくなる。
- 言語名は各言語の自称で書き、翻訳キーにしない。英語表示のときに `Japanese` と出ると、日本語で遊びたい人が自分の言語を見つけられない。
- 起動時にどの言語で立ち上がるか、切り替えたあと何が追従するかは [../tech/gamesystem.md](../tech/gamesystem.md) 設定 と [../tech/i18n.md](../tech/i18n.md) 言語の切り替え。

### 音量

- 全体・BGM・効果音の3本。それぞれ 0〜100 の整数で、100 が素材そのままの音量、0 は無音。3本はそのまま音のバス（Master・Music・SFX。[../audio/sfx.md](../audio/sfx.md) 同時再生の扱い）に当たり、全体は BGM と効果音の両方に掛かる。
- 各行はつまみ（スライダー）と数値の欄の組。つまみを引きずれば欄の数字が追い、欄に打てばつまみが動く。細かく合わせたいときは欄に直に打つ。キーボードの左右でも1ずつ動く。
- 音はつまみを引きずっている最中から追う＝聞きながら合わせる。保存するのは手を離したとき・欄を確定したとき。効果音と全体の音量は、決まったところで決定音を1つ鳴らして、その大きさで鳴ることを聞かせる。BGM は流れている曲がそのまま追うので鳴らさない。
- 選ぶまでは 100。選んだ値の保存は [../tech/gamesystem.md](../tech/gamesystem.md) 設定。

### 画面

- ウィンドウ / 全画面を横に並べ、押した方へその場で切り替わる。選択中の印は言語と同じ細枠。
- 全画面は枠なしの全画面（排他ではない）＝Alt+Tab で他のウィンドウへ行って戻っても崩れない。
- 選ぶまではウィンドウ（`project.godot` の起動時の形）。
