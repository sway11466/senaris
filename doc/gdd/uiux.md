# UI/UX：操作モデル

Senaris の入力・画面操作の設計。基本は本ジャンルの定番（ファイアーエムブレム／ファミコンウォーズ／ネクタリス系）の **「選択 → 移動 → コマンドメニュー」** モデルに合わせる。

対応デバイス: **マウス／トラックパッド（タッチパッド）／タッチスクリーン**。トラックパッドとタッチはジェスチャ（タップ・ピンチ・ドラッグ）を共通とし、差分のみ末尾に記す。

---

## 基本モデル：選択 → 移動 → コマンド

1. 自軍ユニットを**選択**（移動範囲=緑を表示）。
2. **移動先を指定 → 移動**すると、その場で**ユニットコマンドメニューが自動で開く**。
3. メニューから行動を選ぶ（攻撃／陣形スキル／占領／待機 など）。

「動かさずに行動したい」場合は、**自分のマスを選べば**（移動距離0で）メニューが開く。

攻撃対象（赤）は選択した時点では出さない。メニューで攻撃を選んでから、射程内の敵を示す。選択と同時に敵まで光らせると、行ける場所と殴れる相手が同じ画面に混ざって移動先を選びにくい。

## 盤の表示記号

盤に出る記号の一覧。色は同じ意味に同じ色を割り当て、使い回さない。陣営色（青=味方／赤=敵）はターン板・バナーとも共通。

マスの塗り（半透明）:

| 色 | 意味 |
|---|---|
| 緑 | 選択中の駒の移動範囲 |
| 紫 | 出撃先・降車先の候補 |
| 黄（薄） | 移動先プレビュー＝コマンドメニューを開いている間の未確定の移動先 |
| 赤（薄） | 閲覧中の敵の移動範囲＝脅威範囲 |
| 藤 | 陣形スキルの着弾可能マス（射程内） |
| 桃 | 陣形スキルの着弾プレビュー（ホバー先の面） |
| 青 | ホバー中のマス |

輪・線（地面に寝かせる）:

| 色 | 意味 |
|---|---|
| 黄の輪 | 選択中の駒 |
| 白の輪 | 閲覧中の駒 |
| 橙の輪 | 包囲されている駒（攻防に不利がかかっている → [combat.md](combat.md)） |
| 赤の輪 | 攻撃対象の候補が立つマス。クリックの当たりはマス単位なのでその目印。隠れることがあるので、これ単体では対象を示さない |
| 赤の外周線 | 待機中の見張りの検知域の境界。塗らず境界だけ引く＝移動範囲の塗りと紛れない |

駒に付くもの:

| 見た目 | 意味 |
|---|---|
| 頭上の赤い下向き三角 | 攻撃対象の候補（クリックで攻撃）。ゆっくり上下に揺れる |
| 兵数バー（足元） | 残存兵数／満員 |
| 「+N」（左上） | 輸送の搭載数・拠点の控え数 |
| 足元の光 | スキルが効いている（黄緑の輪=強化・紫の塗り=弱体 → [skills.md](skills.md)） |
| 立ち絵を暗く落とす | このターンの行動を終えた駒（待機・攻撃・スキル発動） |

暗くするのは行動を終えたかどうかだけで決める。囲まれて行ける先が無い駒は暗くしない＝手が残っている（待機も陣形スキルも選べる）。ターンでない側の陣営も暗くしない＝どちらのターンかはターン板が示す。

記号をどの高さに置くかは、隠れても困らないかで決める。盤は俯角52°の3Dハイブリッド（→ [../adr/ADR-0003-board-3d-hybrid.md](../adr/ADR-0003-board-3d-hybrid.md)）なので、地面に置いた記号は手前の高い地形に隠れる（高さ×0.78ぶんの奥行が隠れる。壁ならヘックスの奥行の3割強 → [../art/terrain.md](../art/terrain.md)）。奥側は対象の駒自身の立ち絵が覆う。位置の補助でしかない記号は地面でよいが、見つけられないと操作が進まない記号（クリックの入口になるもの）は駒の高さに置く。攻撃対象がこれで、地面の輪ではなく頭上の三角が対象を示す本体になる。

頭上に置く記号は4つの約束で作る。深度判定を切って常に最前面に描く（地形にも他の駒にも隠れない）。持ち上げる向きはワールドの真上ではなくカメラの上方向にする（真上だと遠近で画面の外側へ倒れ、ビルボードの立ち絵とずれる）。画面上の大きさに下限を持たせる（盤全体を映すと1ヘックスが39pxまで縮み、駒と一緒に縮む記号は探せない）。黒の縁取りを全周に等距離で付ける。

縁取りは色ではなく明度で背景と分けるためのもので、記号と同じ色の地形（火口・炎）が来ても輪郭が残る。等距離が要点で、形を一回り大きくしただけでは辺ごとに太さがずれる（下向き三角では上辺が斜辺の2倍になり、輪郭ではなく帽子に見える）。三角なら内接円の半径を r から r+縁の太さ へ増やした相似形＝内心を中心に (r+e)/r 倍すれば全周で揃う。

## 移動の見せ方

移動は経路を1マスずつ辿るアニメで見せる（瞬間移動しない）。狙いは演出よりも可読性で、とくに敵AIのターンは「何が起きたか」を追えることが手応えに直結する。

- 速さは1マス 0.12 秒の等速。経路が長くても合計 0.6 秒で頭打ちにする（足の速い駒で待たされない）。速いほうが好まれるジャンルで、遅いアニメは瞬間移動より悪い。
- 盤の状態は移動が決まった時点で確定し、アニメは見た目だけが後追いする。攻撃・ターン切替などが割り込めば駒は正しい位置へ即スナップする＝アニメが途中で切れても盤は嘘をつかない（戦闘演出と同じ流儀 → [../tech/combat_scene.md](../tech/combat_scene.md)）。
- 敵AIのターンは駒が歩き切ってから次の手へ進む（手が重ならない）。プレイヤー自身の操作は待たせない＝アニメ中でも次の入力を受ける。
- 出撃・降車は駒が盤に現れる操作で経路を持たないため、アニメの対象外。

経路は移動を実行する前に domain 側で引く（移動後は位置と残り移動力が変わり、同じ経路を復元できない）。ZOC で止まるマスは経由地にならない＝実際に歩ける道だけを返す。

実装 → [../../presentation/board/hex_board_3d.gd](../../godot/presentation/board/hex_board_3d.gd)（アニメ）・[../../domain/battle_state.gd](../../godot/domain/battle_state.gd) `path_to`（経路）

## 敵ターンのカメラ

敵のターンは、行動を見せる前にカメラを主体へ向ける。狙いは「敵が何をしたか」を毎手見せること＝いつの間にか敵の位置が変わっている事態を防ぐ。盤が広くて全体表示に収まらない場面で効く。

- 動かすのは注視点だけで、ズーム（距離）は変えない。プレイヤーが選んだ画角を奪わない。
- すでに安全域（可視域の内側にマージンを取った矩形）に見えている主体は追わない。近くの敵が続くときにカメラが小刻みに揺れない（デッドゾーン）。
- 画面外・端にいる主体だけ、安全域に入る最小限だけ、なめらかにパンする（唐突に中央へ飛ばさない）。一度寄せたら次はその範囲の敵をまとめて見せ、離れた敵へ移るときだけ動く。
- パンが終わってから行動を見せる（移動アニメ・戦闘演出の待ちと同じテンポ制御）。プレイヤー自身のターンではカメラは介入しない。
- 見るのは移動・攻撃なら主体の現在位置、出撃なら駒が現れる出撃先。

敵が多いターンは総時間が伸びる。速度設定と敵ターンのスキップは別途（→ [backlog](../backlog.md)）。

実装 → [../../presentation/board/hex_board_3d.gd](../../godot/presentation/board/hex_board_3d.gd) `focus_camera_on`

## 決着の演出（戦果票）

ステージの勝敗が決まったら、羊皮紙の戦果票に大きなゴム印を叩きつける。**演出は短く、情報は入力待ちで好きなだけ読ませる**＝尺で持たせず情報で噛み締めさせる（長い演出は2周目以降に飽きられる）。

- 印は**セレクト画面の「討伐済」と同じ印影**を使う。依頼ボードの貼り紙に押されているあの印は、ここで押されたもの、という繋がりを作る（新しい見た目を発明しない）。
- 印は紙の半分以上を覆う大きさで押す。インクは半透明なので、下の戦果は線の隙間から読める（実際の印影と同じ）。小さい印では達成感が出ない。
- 流れ: 紙が浮かぶ → 溜め → 印が落ちる（同時に**勝敗スティンガー**が鳴る → [../audio/bgm.md](../audio/bgm.md)）→ 紙が押し込まれて戻る → 入力待ち。
- **印が落ちるまでは入力で閉じられない**（演出の頭を飛ばさせない）。落ちた後はクリック／キーで即座に抜ける。
- 敗北は同じ印だが**インクを灰墨に沈める**（色で語らせ、派手にしない）。リトライ前提の画面なので勝利より軽く扱う。
- 戦果は ターン数／生存／撃破 の3行。生存は carryover の冒険譚で次に引き継がれる数＝意味のある数字。
- 決着シグナルは戦闘結果の直後に飛ぶ（戦闘演出がまだ画面に出ている）ので、**演出が閉じるのを待ってから**戦果票を出す。戦闘中に勝敗を告げると気が早い。
- 勝利時、戦果の下に**評価ランク**（[rank.md](rank.md)）を表示する。敗北にはランクを付けない。
  - 戦果の各行の右にランク基準（具体的な数値）を S・A で並べ、達成した基準にチェックを付ける。撃破はランクに使わないので基準なし。プレイヤーは何を改善すれば上がるか一目でわかる。
  - 最終ランクに応じた**メダル**（S = 金・A = 銀・B = 銅）を出す。配置は実物を見て決める。
  - 印（ゴム印）とは重ねない。

実装 → [../../presentation/ui/result_banner.gd](../../godot/presentation/ui/result_banner.gd)（戦果票）・[../../presentation/main/main.gd](../../godot/presentation/main/main.gd)（`_show_result`・決着フロー）・[../../presentation/select/tavern_theme.gd](../../godot/presentation/select/tavern_theme.gd)（`stamp` ＝印影の共通部品）

## 会話シーンの演出

ステージ前後の会話（intro/outro）中は、盤を暗幕で沈めて会話に注視させる。会話中は盤の入力を止めている（`set_input_locked`）ので、暗幕はその「いま触れない・会話が主役」を見た目でも伝える＝盤が素のままだと操作できそうに見えて戸惑うため。

- 画面全体に半透明の暗幕をかけ、会話パネルだけをその前面に残す（周りが沈んで会話に目が行く）。盤・ターン表示・HUD はまとめて暗くなる。
- 暗幕はフェードで出し入れする（唐突に暗転しない）。会話が終われば盤が主役に戻る。

実装 → [../../presentation/ui/screen_lighting.gd](../../godot/presentation/ui/screen_lighting.gd)（画面の明暗の共通基盤。暗幕は会話・戦闘演出・陣形カットインで同じもの）・[../../presentation/main/main.gd](../../godot/presentation/main/main.gd)（`_set_scrim`・会話フローで出し入れ）・[../../presentation/ui/conversation_panel.gd](../../godot/presentation/ui/conversation_panel.gd)（会話パネル）

## ユニットコマンドメニュー

移動後（または自マス選択後）に**自動で開く**。状況に応じて項目を出し分ける:

- **攻撃** … 対象を指定して攻撃。
- **陣形スキル** … 配置で発動する特殊行動を起動（レシピが成立するとき）。
- **占領** … 占領可ユニットが拠点上にいるとき。
- **待機** … その場で行動終了（移動だけ／動かずに終わる、いずれもここ）。
- **キャンセル** … 移動を取り消して選択し直す（右クリック／長押し／Esc でも同じ）。

判定はすべて**移動先に居るものとして**行う。移動はまだ確定していないので、そこへ動いたら何ができるかを見せる。

いまできない操作は**選べない形で見せる**（項目を消さずに無効化する）。撃てる相手が射程内にいない攻撃、撃てる先が無い陣形スキルがこれにあたる。「その手はあるが、いまは通らない」を伝えるほうが、黙って消すより読み取りやすい。項目ごと出さないのは、そもそも状況が噛み合っていないとき（拠点にいないのに「入る」、レシピが成立していない陣形スキル）。

> 出撃も同じ発想で、拠点を選択 → メニューに **「出撃」** を置き、控え（garrison）を隣接マスへ1体ずつ出す。右クリック専用にはしない（タッチ・トラックパッドで困らないため）。

## ユニット情報パネル

盤の右に置く木の看板（レイアウトは `UiLayout.RIGHT_BOX`）。何を選んでいるかで中身が変わる。

| 状況 | 中身 |
|---|---|
| ユニットを選択 | 見出し（据え置き）＋タブ（能力／状態／地形） |
| 空きマスを選択 | そのマスの地形と移動コスト。拠点なら所属と控えの一覧 |
| 未選択 | 操作ヒント。一時的な通知（セーブ完了など）も数秒だけここに出す |
| 戦闘・スキルの解決後 | 戦闘レポート（→ [../tech/combat_scene.md](../tech/combat_scene.md)） |

板は固定寸法で、縦に伸ばさない。観点が変わればタブで切り替え、同じ観点の中で入り切らないぶんはページャーで送る。

### 見出し

タブの上に据え置く。タブを切り替えても消えない＝どの駒を見ているかが常に見える。

```
ゴブリン （敵軍）        ┌────┐
見張り（壁と森）   待ち伏せ │icon│
                        └────┘
```

- 1行目 ＝ ユニット名と陣営。
- 2行目 ＝ 敵は部隊名、自軍は兵種。
- 右 ＝ 敵だけに出す特性の欄。アイコンは見出し2行ぶんの高さで板の右端に固定し、特性名はその左に置く。アイコンを右端に置くのは、特性名の長さで額の位置が動くと、駒を選び直すたびに絵が横へ泳ぐため。

敵に兵種を出さないのは、リスキン元の種別が透けるため。見た目で別物として覚えた駒が同じ兵種名で並ぶと、絵で区別している前提が崩れる。

敵に部隊と特性を出すのは、Senaris が確定ゲームだから（→ [ai.md](ai.md)）。とくに部隊は一斉警戒の範囲＝この1体を起こすと誰が一緒に起きるかを示す。盤からは読めない情報なので、ここでしか出せない。

- 部隊名はステージJSONの `name`（→ [map.md](map.md)）。表示は `tr()` を通す（→ [../tech/i18n.md](../tech/i18n.md)）。
- `name` の無い部隊は `order` から「第N部隊」と組む。名前を書かなくても部隊が分かれていること自体は見せる。
- 特性名とアイコンは特性id（`charge`/`ambush`/…）で引く。アイコンは暗い木の板に載せるので、明るい単色で抜いた焼き印のような図案にする（→ [../art/direction.md](../art/direction.md)）。

### タブ

三つ。駒を選び直してもタブの選択は保つ＝同じ観点で駒を次々に見比べられる。

| タブ | 中身 |
|---|---|
| 能力 | 駒そのものの性能。兵数・Lv・対地/対空攻撃・防御・移動・移動種別・射程・特性 |
| 状態 | このターン何ができるか（移動可／攻撃可／行動完了）と、いま効いている補正・包囲 |
| 地形 | 立っているマスの地形・攻防補正・移動コスト。拠点なら所属と控え |

- 能力の「特性」には、他の行から読めないものだけ並べる。飛行は移動種別が、遠隔・近接不可は射程がすでに示している。
- 包囲は地形ではなく状態に置く。マスの性質ではなく「隣の敵に囲まれて弱っている」＝一時的な弱体なので。
- 地形名は盤に見えている絵の名前で出す（「平地」ではなく「墓地の草地」）。ステージの見た目差分と言葉を合わせる。
- 移動コストは全移動タイプを常に同じ順（`movement.csv` の行順）で並べる。そのステージに出ている兵種だけに絞ると、マスごと・ステージごとに行の並びが変わって読み比べられない。進入不可（`x`）は「不可」と書く。
- 地形の話（地形名・攻防補正・移動コスト）を先に出し、拠点と控えは最後に置く。控えは体数ぶん伸びるので、行数の決まっているものを先に出し切れば、後ろのページへ送られるのは控えの尻尾だけで済む。

### ページャー

板に入り切らない中身は、下端の ◀▶ でページを送る。スクロールバーは置かない。細い棒は木の看板の材質から浮くうえ、木彫りのバーを描き起こすのはボタンを1枚増やすより高くつく。

```
          ◀   2/3   ▶
```

- タブとページャーは役割が違う。タブ＝観点の切り替え、ページ＝同じ観点の続き。
- ページャーは板の下端に据え置く。1ページしかないときも場所は空けたまま無効表示にする。出し入れすると駒を選び直すたびに下端が動く。
- ページの割りは板に入る高さを実測して、入るところまで詰めて次へ送る。行数の決め打ちは、フォントか板の寸法を変えた時点で破綻する。
- 見出し（【移動コスト】など）はページの末尾に取り残さない。入らなければ見出しごと次のページへ送る。
- ページの頭に空行は置かない。グループの間合いは、ページが変わること自体が示す。
- パネルの上でのホイール／2本指スクロールはページ送りに使う。盤のカメラが動くのはパネルの外だけ。
- 駒・マス・タブを選び直したら1ページ目に戻す。

## ターン表示（ターン板）

ターンは盤エリア上端の中央に置く専用の板で示す。3枠を横に並べ、左が味方・中央がターン数・右が敵。

```
[味方] [ turn 3 / 30 ] [敵]
```

- ターン側の枠を活性化する。非活性側は暗く落とし、活性側は素の明るさに陣営色（盤と同じ 青=味方／赤=敵）の縁を付ける。
- 中央はターン数と上限（ステージの `turn_limit`）。上限なし（0）なら数字だけ。
- 左右の枠はその冒険譚の代表ユニットの絵。冒険譚マニフェストの `emblem` で指定する（→ [stage_select.md](stage_select.md)）。指定が無ければ左右の枠は出さず、中央のターン数だけを見せる。
- 絵は `map` スロットの立ち絵を流用し、上部だけ見せて胸像にする。専用の胸像が要るようになったら `portrait` スロットを足して差し替える。
- 板の材質は右の情報パネルと同じ木の看板（TavernTheme）に揃える。

画面上端に横長の情報バーは置かない。ターン数はこの板、操作ヒントは右パネルのユニット未選択時の本文、決着の文言は戦果票が担う。セーブ完了のような一時的な通知は右パネルに数秒出す。

### ターンの切り替わり（バナー）

ターンが移った瞬間に、画面中央へ横帯のバナーを差し込んで消す。ターン板は状態の常時表示であって切り替わりの瞬間を伝えないため、区切りは別に要る。とくに敵が1手も動かないターン（`engage=sight` や `turn:N` で待機中）は、いまは1フレームも見えずにターンが戻ってきて、プレイヤーには何も起きていないように見える。

- 左右から差し込み、少し留めて消える横帯。盤は覆わない（暗幕は張らない＝会話とは別扱い）。
- 陣営色は盤と同じ 青＝味方／赤＝敵。
- 冒険譚の代表ユニット（`emblem`）の `combat` スロットの立ち絵を重ねる。立ち絵は 512四方に対し図が下寄せの 384px なので、貼る前に非透過部分の外接矩形を取る（ターン板の胸像と同じ処理）。
- 絵の落とし方は `combat` → `map` → 絵なし（色と文字だけ）。`emblem` は冒険譚では必須だが、未指定でもバナー自体は出す。
- 敵のターンはバナー0.7秒＋間0.3秒＝合計約1秒おいてから最初の行動に入る。行動が無いターンでも、この1秒は必ず見える。
- 自分のターンはバナーが出ている間も操作を受け付ける。クリック／キーで即座に消せる（毎ターン出るものなので待たせない）。

### 残りターン板（増援の予告）

未発生の増援（[map.md](map.md) イベント）があるあいだ、あと何ターンで来るかを常時見せる。右の情報ボックスの下に、幅を合わせた小さい板を1枚置く。

```
[ 飛空艇 到着まで あと2ターン ]
```

- 文言はイベントの `label`（翻訳キー）の訳文がすべて持つ。`{n}` に残りターン数が入る（「飛空艇 到着まで あと{n}ターン」）＝言語ごとに語順を変えられる。
- 未発生の増援が複数あるときは、いちばん近いものを1つだけ出す。板が積み上がると盤が狭くなる。
- 発生したターンに板は消える。到着そのものはバナーや会話では知らせない＝盤に駒が増えることで分かる（毎回1秒止めるほどの出来事ではない）。
- `label` の無いイベントは板を出さない＝黙って加わる。伏兵を書きたいときに使うが、[map_patterns.md](map_patterns.md) の「予告なしの背後からの出現」は避ける形なので、使いどころは限られる。
- 材質はターン板・情報パネルと同じ木の看板（TavernTheme）に揃える。

ターン切り替えのバナーには出さない。バナーは毎ターン必ず出るものなので、そこへ残りターンを載せると「区切りを見せる」役と「状態を見せる」役が混ざる。状態は常時表示の板が担う（ターン板と同じ考え方）。

## ボタンの左右（進む・やめる）

同じ場所に「進む」と「やめる」が並ぶときは、**右＝次に進む／左＝やめる・引き返す**で固定する。画面が変わっても手が同じ側を探せる。

- ダイアログは下辺の両端に開いて置く（中央に寄せて並べない）。距離が離れるほど押し間違いが減り、左右の役割も読みやすい。
- 文言は行き先を言う。「はい／いいえ」「OK／戻る」のような一般語にしない＝押した先で何が起きるかがボタンだけで分かる（例＝依頼書の「出撃する」「別のステージを選ぶ」）。
- 会話パネルも同じ並び（左＝会話をスキップ／右＝次へ ▶）。
- 画面を一段戻る木の板ボタンはこの規則の外で、常に画面の左下に置く（[stage_select.md](stage_select.md)）。左＝引き返す、という向きは揃っている。

## タイトルロゴ（盤の右上）

盤にはタイトルロゴを常時出す。右の情報ボックスの上に空く帯（上端〜ボックスの上辺）に、右端をボックスの右端にそろえて置く。盤にも板にも掛からない。

作品名を見せる場所として盤を選ぶ。プレイヤーがスクリーンショットを貼るのも、配信で映るのも盤面であって、タイトル画面ではない。名前と体験が結び付くのはここになる。逆にタイトル画面の扉の絵には重ねない（→ [title.md](title.md)）。

- 絵は小サイズ版のロゴ（紋章＋文字。作りは [../art/promo.md](../art/promo.md) §1）。ゲーム用の書き出しは `godot/assets/ui/logo.png`。
- 置き場は情報ボックスの矩形から算出する（[ui_layout.gd](../../godot/presentation/ui/ui_layout.gd) の `LOGO_H` / `LOGO_TOP`）＝ボックスを動かせばロゴも付いてくる。
- 絵は透明な余白を含むので、実体の矩形だけを切り出して置く。右端そろえが余白のぶんずれないようにする（ターン板の胸像と同じ処理）。
- 会話中も出したままにする（暗幕より前面）。盤を覆う演出（戦闘・ユニットスキル・完走の勝利イラスト）とセレクト・タイトルの画面では隠れる。

## ターン終了・システムメニュー

- **ターン終了** … 画面に**常時表示のボタン**（毎ターン使うのでメニューに埋めない）。キーボードは Enter でも可。
- **システムメニュー** … 歯車アイコン（または Esc）。セーブ・ロード・設定など、頻度の低い操作をまとめる。
- デバッグメニュー … システムメニュー末尾の区画。デバッグビルド（`OS.is_debug_build()`）でだけ出す＝デバッグ冒険譚の表示（[stage_select.md](stage_select.md)）と同じゲート。
  - 敵を殲滅 … 盤上の敵駒を全て除去する。以降は通常の決着処理（戦果票 → outro 会話 → 完走イラスト）に乗せる＝専用の勝利処理は持たない。敵拠点に控えが残るステージでは勝利にならない（勝利は盤上0体かつ復帰手段なし → [map.md](map.md)）。
- 投了は置かない。ステージセレクトへ戻れば実質同じで、敗北シーンをわざわざ見せる必要もない。

## カメラ

- **パン** … **空き地からのドラッグ**（マウス左ドラッグ／タッチ1本指ドラッグ／トラックパッド2本指スクロール）。**ユニットの上からのドラッグはパンしない**（＝クリック／タップ扱い。ドラッグでユニットを動かす機能は持たない）。
- **ズーム** … マウス=ホイール、トラックパッド・タッチ=ピンチ。**カーソル位置（タッチは2本指の中心）を基点**に拡大縮小する。
- **全体表示** … 盤全体が収まる位置・倍率へ戻す（F キー／タッチは画面ボタン）。**ステージ読み込み時は自動フィット**。
- 盤は HUD（タイトル・情報パネル等）を避けた領域に収める。

---

## クリック／ドラッグの判別

押してから一定距離（数px）動いたら **ドラッグ＝パン**、動かさずに離したら **クリック／タップ＝選択・決定** とみなす（しきい値方式）。タッチの「タップ vs スワイプ」も同じ判別。

---

## デバイス差分（トラックパッド vs タッチ）

ジェスチャは共通だが、実機の前提が3点異なる:

- **トラックパッド**: カーソルがある → **ホバー強調が効く**。**2本指タップ＝右クリック相当**。キーボード併用可。
- **タッチ**: カーソルなし → ホバー無し（フィードバックはタップ後）。右クリック無し → **長押しで代替**。キーボード無し → **ターン終了・全体表示は画面ボタンが必須**。

---

## 盤入力の詳細

上記の操作モデルを、実際の入力に落とした内訳:

- **カメラ操作**（[../../presentation/board/hex_board_3d.gd](../../godot/presentation/board/hex_board_3d.gd)）
  - パン＝**2本指スクロール**、または**空き地から左ドラッグ**（左ドラッグはクリック／ドラッグをしきい値 `DRAG_THRESHOLD` で判別。ユニット上からのドラッグはパンしない）。
  - ズーム＝**ピンチ**（カーソル基点）。全体表示＝**F**。読み込み時に自動フィット。
  - **Windows トラックパッドのイベント実測（Godot 4.7）**: ピンチ＝`Ctrl＋ホイール`、2本指スクロール＝`修飾なしホイール`（縦=WHEEL_UP/DOWN・横=WHEEL_LEFT/RIGHT）で届く。**Ctrl の有無で判別**し、修飾なし＝パン／Ctrl付き＝ズームに割り当てている（ブラウザの zoom と同じ流儀）。
  - 既知の制約: 素のマウスホイールと2本指スクロールは同一イベントのため、マウス使用時はホイール＝パンになる（ズームは Ctrl＋ホイール／ピンチ）。マウス運用を始めたら割り当ての切替を検討。
- **ユニットコマンドメニュー**
  - フロー: 自軍ユニットを選択（移動範囲=緑）→ **自マス or 到達マスをクリックで `PopupMenu` を開く**（移動は**未確定**＝プレビュー表示）→ `攻撃`／`待機`／`キャンセル`。
    - `攻撃`: 移動を確定 → 攻撃対象（頭上の赤い三角）をクリックで攻撃。射程内に敵がいない移動先では項目を**無効化**。
    - `待機`: 移動を確定し、その駒の行動を終了（移動だけ／動かず終わる）。
      - 占領可ユニットが**敵/中立の拠点へ進む移動先**では、この項目のラベルが **`占領`** になる（動作は待機と同じ＝移動確定で domain が自動占領。誤操作防止のラベル変更）。
    - `キャンセル`: 移動操作そのものを取りやめ＝**選択解除**（駒はその場・未行動のまま残る。**undo不要**＝そもそも動かしていない）。移動先を選び直すだけなら別マスを直接クリックすればよいので、`キャンセル`は丸ごと取りやめに割り当てる。
  - **Esc／メニュー外クリック**＝選択状態へ戻る（＝移動先の選び直し）。Esc はさらに 選択→出撃モード と1段ずつ戻る。
  - ドメイン追加: `attack_targets_from`（仮移動の攻撃可否）／`set_done`＋`is_done`（待機）。テスト: `godot/tests/unit/test_command_actions.gd`。
  - 当面メニューに出さない: **陣形スキル**（ドメイン未実装）。**占領**は専用項目ではなく、上記の`待機`→`占領`ラベル化で表現。
- **出撃の拠点メニュー化＋右クリック=キャンセル**
  - 自軍の出撃可能な拠点をクリック → `PopupMenu`（`出撃`／`キャンセル`）→ `出撃` で候補マスをハイライト → クリックで出撃。拠点上に駒がいれば**駒の選択を優先**。
  - **拠点の上に駒がいるときは、その駒のコマンドメニューに `出撃: 〈駒〉` が合流**する（駒の行動と拠点の操作は**セパレーターで区切って**表示。出撃＝garrison の行動なので上の駒が未行動でも出せる＝輸送の降車と同じ扱い）。拠点へ移動するその足でも出せる（保留移動を確定してから出撃モードへ）。
  - **右クリック＝キャンセル・戻る**（Esc と同じ＝メニュー→選択→出撃モードを1段ずつ解除）。出撃モード入りの役割は廃止。
  - 長押し（タッチのキャンセル）はタッチ対応で入れる。
- **ターン終了ボタン＋システムメニュー**（[../../presentation/ui/hud.gd](../../godot/presentation/ui/hud.gd)）
  - 永続HUD（`godot/presentation/ui/hud.gd`）を main が常設。盤の入力を邪魔しないよう自身は素通し（ボタンだけ拾う）。
  - **ターン終了ボタン**（右下・常時表示）＝ Enter と同機能。**自ターンのみ有効**（AIターン・決着後は無効化）。
  - **⚙ システムメニュー**（歯車ボタン、または盤の**最上位 Esc**＝戻る対象が無い時に開く）: `リスタート`（現ステージ再読込）／`ステージセレクト`（[stage_select.md](stage_select.md)）／`セーブ`（中断スロット5枠の一覧。保存内容は自ターン開始時点の盤面）／`ロード`（オートセーブ＋中断スロット5枠の一覧）／`設定`（無効表示）／`閉じる`／デバッグビルドのみ `敵を殲滅`。
  - HUD は進行を持たず、押下をシグナル（`end_turn_requested`／`restart_requested`）で main（`MatchController` 所有者）へ委ねる。
- **タッチ対応は未実装**（`InputEventScreenTouch`／`ScreenDrag`／長押し）。
- **盤入力のまとめ**: 左クリック=選択→（移動先クリックで）コマンドメニュー／自軍拠点クリックで拠点メニュー、右クリック=キャンセル・戻る、Esc=戻る（最上位でシステムメニュー）、Enter or ボタン=ターン終了、歯車=システムメニュー。
