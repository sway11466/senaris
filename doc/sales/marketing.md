# マーケティング

対象：誰に届けるか、何をどの面で伝えるか。店頭での見せ方（カプセル画像・タグ・説明文）を扱う。

価格・配布バリエーション・販売チャネルの選定は [monetization.md](monetization.md)、タイトル名と副題は [naming_decision_senaris.md](naming_decision_senaris.md)、公式サイトの中身は [site.md](site.md)。

## 届ける相手 【方針】

英語圏に振る。ヘックス制ターン戦術の潜在層は英語圏のほうが厚く、Steam の集客もこの層で回る。同人系直販のうち itch のユーザーベースが英語圏中心なのも同じ方向を向く（[monetization.md](monetization.md) の販売チャネル）。

英語テキストの質が効く。盤面のゲーム性で買う客層のため、絵よりも文が読まれる。優先度が高いのはストアページの一行目とチュートリアルの会話パートで、ステージ内の UI ラベルは短く誤解の余地が少ないぶん後回しでよい（[i18n.md](../tech/i18n.md)）。

## 伝達の役割分担 【方針】

四つの面がそれぞれ別の仕事をする。同じことを重ねて言わない。

| 面 | 仕事 |
| --- | --- |
| カプセル画像 | 他のどれでもないこと（ヘックス盤＋ファンタジー） |
| タグ | どの棚に並ぶか＝誰に見つかるか |
| 短い説明文 | なぜ買うか（乱数なし・生産なし） |
| 特徴の箇条書き | 何ではないか＝期待値の設定（ステージ制・手作りのマップ） |
| 副題 | 名前しか見えないときのジャンル保険 |

タイトル名そのものは語義を伝えない。`Senaris` は造語で、英語話者が拾えるのは `-is` 終わりのラテン語風の響き（Solaris / Polaris の系列）＝SF かファンタジーの固有名、という程度。名前の仕事は覚えられることと検索で辿り着けることの二つに限り、意味の伝達は上の四つに割り振る。

## カプセル画像 【方針】

ヘックス盤にファイターとドラゴンを置く。ヘックス盤は英語圏では第一にウォーゲームの記号で、そこにドラゴンが乗る取り合わせ自体が引きになる。

リスト表示では横 200px 程度まで縮む（正確な寸法は登録時に要確認）。この寸法では網目は模様として残るが盤上の駒は識別できないため、盤面の縮図ではなくモチーフを二つだけ大きく置く構図にする。スクリーンショット的な密度にすると縮小時にただの灰色の面になる。

ヘックス盤は硬派層に効く一方、軽快な戦術ゲームを探す層には重く見える方向にも振れる。どちらに転ぶかは線の太さ・彩度・キャラの造形が決めるため、絵柄の方針（[direction.md](../art/direction.md)）と次節の棚選びは同じ判断になる。

## 棚選び（タグ）

Steam のタグは開発者が初期値を設定でき、それが「このゲームに似たゲーム」棚と Discovery Queue の入力になる（上限や運用の細部は登録時に要確認）。タグを選ぶ行為は語を選ぶことではなく、誰の隣に並ぶかを選ぶこと。

英語圏のヘックス戦術棚は客層が三つに割れている。

- Advance Wars 系 … 軽快・キャラ立ち・カジュアル寄り。母数が最も大きい。
- ヘックスウォーゲーム系 … 硬派・歴史もの・数値志向。濃いがファンタジーとは遠い。
- 戦術パズル系 … 与えられた戦力を噛み合わせて解く手触り。コンセプト（[concepts.md](../concepts.md)）に最も近い。

このうち戦術パズル系は語では取りに行けない。あの手触りに対応するタグが Valve のリストに無く、`Puzzle` を使うと「解が一つある問題」を期待した層が来て外れる。パズル性は説明文の deterministic が担当し、タグでは `Difficult` で歯ごたえの側だけを拾う。

したがって選ぶのは Advance Wars 系とヘックスウォーゲーム系の配分になる。大きいタグ（Strategy / Turn-Based Strategy）が露出の母数を、小さいタグ（Hex Grid / Wargame）が能動的に追う層への到達を担当するので、両方を混ぜたうえで並び順で配分する。

| 順 | タグ | 役割 |
| --- | --- | --- |
| 1 | Turn-Based Tactics | 棚の中心 |
| 2 | Strategy | 母数の最大化 |
| 3 | Turn-Based Strategy | 同上。Advance Wars 系の主戦場 |
| 4 | Hex Grid | ニッチだが能動的に追う層へ確実に届く。本作の看板 |
| 5 | Fantasy | ヘックス棚では珍しく、差別化がタグ側でも効く |
| 6 | Turn-Based Combat | 取りこぼし回収 |
| 7 | Tactical | 同上 |
| 8 | Singleplayer | 期待値の設定（マルチを期待させない） |
| 9 | Difficult | 歯ごたえを探す層。パズル側の濃度をここで代替する |
| 10 | Medieval | 世界観 |
| 11 | Indie | 規模の期待値 |
| 12 | Wargame | 硬派側。低位に置いて弱く効かせる |

- `Wargame` を上位に置かない。この層は歴史ものとシミュレーション的な深さを期待しているため、上位に来ると期待値が外れる。低位ならヘックス好きだけを拾える。
- 絵柄を名乗るタグ（`Hand-drawn` ほか）は使わない。本作はアートに AI 生成を含み、Steam ではそれがストアページに開示表示される（[monetization.md](monetization.md) の AI 生成コンテンツ）。手描きを名乗るタグと開示が同じページに並ぶと矛盾として突かれる。上の「期待値の設定」でいう手作りのマップはレベルデザインの話で、こちらは抵触しない。
- 20枠に対して12。埋めきらない。迷う語を足すと並び順が濁る。
- タグは最終的にユーザー投票で動く。設定できるのは初期値と初期の並びまで。

タグ名は Valve の固定リストに合わせる必要があるため、上の綴りは Steamworks 登録時に実在を確認する。

itch のタグは推薦に効かず、ブラウズ導線も弱い。itch で仕事をするのはタグではなく devlog とサムネ（[monetization.md](monetization.md) の itch の性格）。

## 短い説明文

乱数なしと生産なしを一行目で言い切る。どちらも画面では伝わらず、タグにも定着した受け皿がない（No RNG に相当する Steam タグは無い。要確認）。運で負けないことは戦術ゲーム好きが能動的に探している価値のため、言葉で言い切る価値がある。

英語で通る語彙は perfect information / deterministic / no RNG / no dice。副題が `Deterministic` を使うので、説明文は別の語で言い換えて重複を避ける。

先行作の固有名詞は宣伝文に出さない（[monetization.md](monetization.md) の IP・権利）。ジャンルは自前の語で説明する。

## 期待値の設定

差別化（なぜ買うか）と期待値の設定（何ではないか）は別の仕事。前者は説明文の一行目に使い切り、後者は特徴の箇条書きに置く。混ぜると焦点がぼける。

ステージ制は後者にあたる。英語圏のこのジャンルではステージ制がデフォルト（Advance Wars 系も戦術パズル系も区切られたミッションを順に解く形）のため、mission-based と書いても情報量がない。書く価値があるのは、そこから派生する二つ。

- 手作りのマップであること。近年は hand-crafted が品質のシグナルとして働き、手続き生成への疲れの受け皿になる。
- 1ステージが短く、区切って遊べること。所要時間を添える。

ただし冒険譚の中では戦力が引き継がれる（[map.md](../gdd/map.md) の carryover）。「1ステージ完結」と言い切ると逆方向の誤解が出るため、ステージは短く区切られるが冒険譚を通して戦力が繋がる、というところまで含める。

期待値を外すと返金とレビューに出る。恒久的な部隊育成や戦略マップを期待して買った人が外れる形が典型。一行目で押さず、箇条書きで確実に伝える。

ステージ制に相当する Steam タグは無い（要確認）。Roguelike が付かないこと自体が答えになる。
