## 2. 由来・命名意図 【指針】

- **語源**: ラテン語 *senarius* / *seni*(「6つ一組の」「6つずつの」)。
- **隠し意味**: 包囲が成立する **6つの隣接ヘクス＝6** を、響きの裏に仕込んだ名前。
- **設計オマージュ**: 末尾 `-is` は **Nectaris** へのオマージュ。
  ネクタリスが「Mare Nectaris＝神酒の海＝月(舞台)」を隠していたのと同じ構造で、
  「響きはかっこいいが、実は意味が仕込まれている」造語手法を踏襲。
- **狙い**: コア機構(包囲)を、説明くさくならない形で固有名に織り込む。

## 3. 選定理由 【指針】

検索ヒットのしやすさ(独自性・サービス名としての発見可能性)を主軸に5候補を実調査し、Senaris を採用。

- **ゲーム/ソフト/大手ブランドの競合がゼロ**。
- 既存の被りは「スペイン／ガリシア系の姓 Señaris(ティルダ付き)」と、
  ルーマニアの小規模ゲーマーコミュニティ(Senaris Network / senaris.net)、
  GitHub 個人ユーザー程度。いずれも非商用・小規模でブランド上の障害にならない。
- 完全な独自綴りのため、ウィッシュリストが少し付くだけで検索1ページ目を独占しやすい。
- 検索強さ・独自性・意味性の3点を同時に満たした唯一の候補。

## 4. サブタイトル 【指針】

英語表記は `Senaris: Deterministic Fantasy Tactics`。

副題の仕事は、カードやリストで名前しか見えないときのジャンル保険。差別化そのものはキービジュアルと説明文が担当する（[marketing.md](marketing.md)）。

込めたい要素はターン制・ヘックス・乱数なし・ファンタジーの四つあるが、リスト表示で読める長さは3〜5語で、入るのは二つか三つ。落とす順序は次のとおり。

- ターン制 … 英語圏では `Tactics` がターン制を含意するため明示しない。
- ヘックス … カプセル画像が担当する。盤面を見れば一目で分かる要素に語数を使わない。

残った乱数なしを `Deterministic` の一語に畳む。画像でもタグでも代替できない唯一の要素のため、ここに語数を割く。

`No Dice` は採らない。英語の慣用句として「却下だ」の意味を持つダブルミーニングになり、正統な中世ファンタジーのトーンと合わない。`Deterministic` はラテン語層の硬い語で、senarius 由来の `Senaris` と語の格が揃う。

`Deterministic` が読めるかは懸念しない。土台の determine が日常語で `-istic` も生きた接尾辞のため分解して意味に届くうえ、戦略ゲームの客層には RNG と並んで定着した語彙。学術的な語感が残るのは狙いどおりで、思考型のゲームだという印象に働く。

カード幅で切られると `Tactics` から先に落ちる。語順を入れ替えると意味が壊れるため、この副作用は受け入れる。
