# 宣伝素材の方針（ロゴ・ストア用カプセル・プロモ画像／動画）

ゲームの外に出る絵の正本。ストアページ・サイト・SNS に置くものを扱う。ゲーム内アセットの方針は [direction.md](direction.md) が正本で、こちらはそれと条件が違うため分けている。

ゲーム内アセットとの違いは4つ。

- 絵に文字を載せる（ゲーム内アセットは「絵に文字を入れない」が全体ルール。宣伝素材はその例外）
- ベクター形式が要るものがある（ロゴ）
- 寸法が Steam の規定で決まっている
- AI 生成の開示対象になる

作業ソースは `assets/promo-src/`（`.gdignore` 済み＝Godot は読み込まない）。命名は [direction.md](direction.md) の三段階（`_01_raw` → `_02_dew` → `_03_master`）に揃える。

## 1. ロゴ

### モチーフ

剣が刺さった中央のヘックスを、6つのヘックスが囲む。囲みそのものが絵になっている形。

包囲は本作の面白さの核であり（[concepts.md](../concepts.md)）、タイトルの由来 senarius（6つ一組＝包囲の隣接6ヘックス）とも一致する。ロゴが作品の芯を説明する形になる。

要素は足さない。「剣」と「ヘックス」を並べるのではなく、剣の刺さった1枚と周囲6枚で1つの図として成立させる。

### 構成

絵が上、文字が下に積む。紋章の下端が文字の上端に浅くかかって、2つが1つの塊として読めるようにする。文字を潰すほど深く重ねない。

### 文字

書体は **EB Garamond**。古典的なセリフ体で、線の太さが読みやすさと格調の両立する範囲にある。カジュアルな書体は世界観に合わないため使わない。字間は広めに取る（この様式の上品さはほぼ字間で決まる）。

選定の経緯と、なぜ OFL のフォントに限るのかは [ADR-0004](../adr/ADR-0004-logo-typeface-ofl.md)。

#### フォントの取得元と取り扱い

- 取得元は Google Fonts のリポジトリ `github.com/google/fonts` の `ofl/ebgaramond`。ライセンスは SIL Open Font License 1.1
- リポジトリに同梱している＝`assets/promo-src/logo/fonts/EBGaramond-variable.ttf` と `OFL.txt`。ロゴを後から作り直せるようにするため。**OFL はフォントを再配布する際にライセンス文の同梱を求める**ので、`OFL.txt` を必ず隣に置いたままにする
- 可変フォント（1つのファイルで太さを連続的に変えられる形式）。現状は既定の太さを使っている
- **ゲームには同梱しない。** `promo-src` は `.gdignore` により Godot が読み込まず、製品ビルドにも入らない。ロゴはパス化した図形として書き出すので、実行時にフォントは不要
- 書体を変えたくなった場合も OFL のものから選ぶ。フォント自体を売らない限り、出力の利用・ロゴ化・商標登録が明示的に許されているため。Windows 同梱のフォント（Times New Roman ほか）はロゴ化や商標登録での扱いが曖昧なので使わない

作業は、フォントで打つ → 字間を調整 → **パス化（アウトライン化）** の順。パス化すると文字が図形に変換され、フォントの無い環境でも崩れない。人に渡す成果物では必須。

### 幾何

紋章はベクターで幾何的に作る（生成に頼らない）。**盤と同じカメラで投影する**＝俯角 52 度・画角 42 度（`presentation/board/board_camera.gd` の `PITCH_DEG` / `FOV`）、カメラ距離はヘックス半径の 7 倍。これで奥のタイルが小さく、行の間隔も詰まって、盤らしい奥行きが出る。

単に縦へ潰す（正射影）だけでは奥行きが出ない。奥行きを作っているのは「奥ほど小さい」ことのほうで、そこが効く。

7枚の並びは中央1枚＋周囲6枚。描画は奥から手前の順（手前のタイルが奥に重なる）。各タイルは自身の中心を基準に 94% へ縮めて、隙間で分離を作る（輪郭線は引かない）。

小サイズ版はこの隙間が詰まるため、縮小率を 90% 程度まで下げて隙間を広げる。

剣は中央ヘックスの**中心に刺さる**。刺さり口より下は描かない（地面の下なので見えない）＝見えている長さは刺さり具合で決まる。傾きは刺さり口を軸に回す（切っ先を軸にすると、傾けたときに刺さり位置がずれる）。

### 視点

盤と同じ角度に合わせる。盤のカメラは水平から 52 度見下ろしている（`presentation/board/board_camera.gd` の `PITCH_DEG`）。

寝かせたヘックスはこの角度で、画面上では縦方向に sin(52°) = 0.79 倍に潰れて見える。正六角形を描いて縦を 79% に縮めれば、盤と同じ見え方になる。

遠近は付けない。厳密には奥のヘックスがわずかに小さくなるが、ロゴは左右対称に揃っているほうがよい。

### バリエーション

2つ作る。

- フル版（絵＋文字）— ヘッダーカプセル、起動スプラッシュ、サイト、動画の末尾
- 簡略版（文字のみ、または中央ヘックスと剣だけ）— 小カプセル、アイコン、ファビコン

**最小寸法は小カプセルの 231×87。** 高さ 87 ピクセルの中に収まって読めることが要件で、細い線の7ヘックスはこの寸法では潰れる。設計は最小寸法から始めて、成立を確認してから大きい枠へ広げる。

### 色

タイルには色を載せる。**クラスタ全体を左から右へ横切る1本のグラデーション**で、左が味方の鋼青、右が敵の深紅、中央がどちらにも属さない灰。タイル1枚ずつがグラデーションするのではなく、各タイルはその位置の色でべた塗りする。剣と文字はこのグラデーションを受けない無彩色で、青と赤が出会う中央に剣が立つ。

戦闘画面の左右固定（味方が左・敵が右）と陣営配色（[direction.md](direction.md)）が、そのままロゴの中に入る形になる。彩度は落とす＝渋め（muted）の基調に合わせ、鮮やかな原色の青と赤にはしない。

**背景ごとに2種類の配色を持つ。** 形は1つ、配色が2つ。

- 暗背景版（主）— Steam のカプセル、扉、サイト、起動スプラッシュ、動画。置かれる場所のほとんどがこちら
- 明背景版（従）— プレスキット、印刷物、白地の資料

明背景版は暗背景版の色を濃くしただけでは合わない。**白地では淡いほうが合う。** 白地に濃い色の塊を置くと優美さが消えて武骨になるので、タイルを淡く落とし、文字は濃い鋼灰のまま残す。文字が実体で絵が繊細な添え物、という関係になる。

決めた値。左端の鋼青から右端の深紅へ**2色を直接つなぐ**（中間に灰を挟まない＝中央が紫を帯びて色に厚みが出る。灰を挟むと中央が抜けて色あせて見えた）。ロゴはベクターで持ち、この値を参照する工程があるので、生成アセットと違って数値で決める（[direction.md](direction.md) が HEX を決めないのは、生成がテキスト指定で参照工程を持たないため）。

| 版 | 左（味方） | 右（敵） |
| --- | --- | --- |
| 暗背景版 | `#6e92b8` | `#c05a62` |
| 明背景版 | `#abbed1` | `#daafb3` |

淡くすると小さいときに消えるため、明背景版は大きく見せる用と割り切り、小サイズは単色版で受ける。

### 確定した寸法

生成スクリプトは [`tools/build_logo.py`](../../tools/build_logo.py)。値を変えて走らせれば SVG 一式が出る。

| 項目 | 値 |
| --- | --- |
| カメラ距離 | ヘックス半径の 7 倍（俯角 52 度・画角 42 度） |
| タイルの縮小率（隙間） | 0.94（小サイズ版は 0.90） |
| 剣の全長／見える長さ | 430 ／ 260（差が地面に埋まっている分） |
| 剣の傾き | 15 度（刺さり口を軸に） |
| 文字の幅／字間 | 1200 ／ 0.12 |
| 文字と紋章の重なり | 文字の大文字高さの 0.70 |

加えて運用のために単色版（白1色・黒1色）も持つ。小カプセル・アイコン・ファビコン・印刷・モノクロ表示で要る。

形を先に固めてから色を決める。形が定まっていない状態で色を比べても判断できない。

### 制作方法

**生成AIは使わない。** [direction.md](direction.md) の共通メソッド（Gemini で生成）はゲーム内アセット向けで、ロゴには当てはまらない。理由は3つ。

- 生成AIは文字を正確に描けない。似た字形の別物になる
- 拡大縮小・単色化・透過が要るのでベクター（線と面を座標で持つ形式）で持つ必要があり、生成画像はピクセルの集まりにしかならない
- 小サイズ用の調整（線を太くする・要素を減らす）が手作業でできない

作り方は、モチーフの線画だけ生成して下絵にし、それをなぞってベクター化し、文字は既存フォントで組む。ヘックスは幾何的に作れる（正六角形を縦 79%）ので、下絵が要るのは剣だけ。ツールは Inkscape（無償・SVG）で足りる。

フォントは**ロゴへの使用が許諾されているか**を確認する。商用利用が可でもロゴ化・商標利用を禁じているフォントがある。

## 2. ストア用カプセル

Steam が要求する看板画像。用途ごとに寸法違いが5種類ほどある（ヘッダー 460×215／小 231×87／メイン 616×353／縦 374×448／ページ背景 1438×810。寸法は提出時に Steamworks で最終確認する）。

- 5種は同じ1枚の絵から切り出す。別々に作ると印象がばらける
- タイトルロゴが載っていることが要件。文字が無いと一覧で何のゲームか分からない
- 最小の小カプセル（231×87）で成立するかを先に確認し、そこから大きい枠へ広げる
- ページ背景は主役ではないので、情報量の少ない絵（空・遠景）を選ぶ

## 3. プロモ画像・動画

- 生成物の扱いは [direction.md](direction.md) の三段階命名に従う
- 動画は自前でホストせず Steam か YouTube に載せる（変換・再生互換・転送量を持たなくて済む）
- 生成映像はイラスト調のまま使い、最後は実機の絵で落とす＝本編と地続きに見せる
- スクリーンショットは実画面をそのまま出す。加工した宣材は使わない
- Steam の AI 生成コンテンツ開示の対象になる（[direction.md](direction.md) の配布注意）
