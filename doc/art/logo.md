# ロゴ

作品の紋章の正本。モチーフ・配色・寸法・作り方を扱う。

宣伝素材だけのものではない。ストアのカプセルやサイトに出るほか、起動スプラッシュ（[menu.md](menu.md)）と盤の右上（[../gdd/uiux.md](../gdd/uiux.md)）にも出る。作業ソースは `godot/assets/promo-src/logo/`。

書体の選定と、なぜ OFL のフォントに限るのかは [ADR-0004](../adr/ADR-0004-logo-typeface-ofl.md)。

---

## モチーフ

剣と杖がクロスして刺さった中央のヘックスを、6つのヘックスが囲む。囲みそのものが絵になっている形。

包囲は本作の面白さの核であり（[concepts.md](../concepts.md)）、タイトルの由来 senarius（6つ一組＝包囲の隣接6ヘックス）とも一致する。ロゴが作品の芯を説明する形になる。

要素は足さない。「武器」と「ヘックス」を並べるのではなく、剣と杖の刺さった1枚と周囲6枚で1つの図として成立させる。

## 構成

絵が上、文字が下に積む。紋章の下端が文字の上端に浅くかかって、2つが1つの塊として読めるようにする。文字を潰すほど深く重ねない。

## 文字

書体は **EB Garamond**。古典的なセリフ体で、線の太さが読みやすさと格調の両立する範囲にある。カジュアルな書体は世界観に合わないため使わない。字間は広めに取る（この様式の上品さはほぼ字間で決まる）。

選定の経緯と、なぜ OFL のフォントに限るのかは [ADR-0004](../adr/ADR-0004-logo-typeface-ofl.md)。

### フォントの取得元と取り扱い

- 取得元は Google Fonts のリポジトリ `github.com/google/fonts` の `ofl/ebgaramond`。ライセンスは SIL Open Font License 1.1
- リポジトリに同梱している＝`godot/assets/promo-src/logo/fonts/EBGaramond-variable.ttf` と `OFL.txt`。ロゴを後から作り直せるようにするため。**OFL はフォントを再配布する際にライセンス文の同梱を求める**ので、`OFL.txt` を必ず隣に置いたままにする
- 可変フォント（1つのファイルで太さを連続的に変えられる形式）。現状は既定の太さを使っている
- **ゲームには同梱しない。** `promo-src` は `.gdignore` により Godot が読み込まず、製品ビルドにも入らない。ロゴはパス化した図形として書き出すので、実行時にフォントは不要
- 書体を変えたくなった場合も OFL のものから選ぶ。フォント自体を売らない限り、出力の利用・ロゴ化・商標登録が明示的に許されているため。Windows 同梱のフォント（Times New Roman ほか）はロゴ化や商標登録での扱いが曖昧なので使わない

作業は、フォントで打つ → 字間を調整 → **パス化（アウトライン化）** の順。パス化すると文字が図形に変換され、フォントの無い環境でも崩れない。人に渡す成果物では必須。

## 幾何

紋章はベクターで幾何的に作る（生成に頼らない）。**盤と同じカメラで投影する**＝俯角 52 度・画角 42 度（`godot/presentation/board/board_camera.gd` の `PITCH_DEG` / `FOV`）。これで奥のタイルが小さく、行の間隔も詰まって、盤らしい奥行きが出る。カメラ距離は下記「確定した寸法」。

単に縦へ潰す（正射影）だけでは奥行きが出ない。奥行きを作っているのは「奥ほど小さい」ことのほうで、そこが効く。

7枚の並びは中央1枚＋周囲6枚。描画は奥から手前の順（手前のタイルが奥に重なる）。各タイルは自身の中心を基準に 94% へ縮めて、隙間で分離を作る（輪郭線は引かない）。

小サイズ版はこの隙間が詰まるため、縮小率を 90% 程度まで下げて隙間を広げる。

剣と杖は中央ヘックスに **X にクロスして刺さる**。剣が左から刺さって頭が右へ、杖が右から刺さって頭が左へ、剣が手前。刺さり口は中心から左右対称に離し、同じ高さに置く。刺さり口より下は描かない（地面の下なので見えない）＝見えている長さは刺さり具合で決まる。傾きは刺さり口を軸に回す（切っ先を軸にすると、傾けたときに刺さり位置がずれる）。手前の剣は奥の杖から余白で抜いて分離する（タイルから文字を抜くのと同じ流儀）。

**文字と武器は、タイル側から形を抜いて隙間を作る。** 紋章と文字を深く重ねると、タイルの上に載った文字が明度差を失って沈む。抜けば背景色の隙間が入って明度差が戻り、文字が浮かび上がる。抜きは背景色で縁取るのではなく実際に穴を開ける＝絵の上に置いても縁取りだけ浮かない。

## バリエーション

背景ごとに2種類（暗背景版・明背景版）、加えて小サイズ用に1種類。

- フル版 — ヘッダーカプセル、サイト、動画の末尾
- 小サイズ版 — 小カプセル、アイコン、ファビコン。タイル同士の隙間を広げてある（縮小すると隙間が詰まって塊に見えるため）
- 起動スプラッシュ版 — フル版（暗背景）の下に開発元名 `craftkobo` を足したもの。ゲームに入る画像なので作業元も出力も `promo-src` ではなく `menu-src` / `menu` に置く（[menu.md](menu.md) §6 が正本）
- アプリアイコン版 — 文字を落とした紋章だけ。寸法で7枚版と1枚版を使い分ける（[icon.md](icon.md) が正本）
- 盤の常設版 — 小サイズ版（暗背景）をそのまま PNG にしたもの。盤の右上に出しっぱなしにする（[../gdd/uiux.md](../gdd/uiux.md) が正本）。出力は `godot/assets/logo/logo.png`（表示 72px 高に対し4倍で焼く）。作業元は小サイズ版そのものなので `promo-src` のまま増やさない

- 絵を伴う版 — 題字を主役にして、その周りに絵を額縁のように配した1枚。用途は、既にページを開いた人に名前を覚えてもらうこと（[../sales/steam_page.md](../sales/steam_page.md)）。ロゴ単体を大きく置くだけでは間が持たないので絵を添えるが、主役は題字のままにする

**最小寸法は小カプセルの 231×87。** 高さ 87 ピクセルの中に収まって読めることが要件。設計はここから始めて、成立を確認してから大きい枠へ広げる。

## 色

タイルには色を載せる。**クラスタ全体を左から右へ横切る1本のグラデーション**で、左が味方の鋼青、右が敵の深紅、中央がどちらにも属さない灰。タイル1枚ずつがグラデーションするのではなく、各タイルはその位置の色でべた塗りする。文字はこのグラデーションを受けない無彩色。剣と杖は陣営色を受けず、材質の色で塗る（後述）。青と赤が出会う中央で剣と杖がクロスする。

戦闘画面の左右固定（味方が左・敵が右）と陣営配色（[direction.md](direction.md)）が、そのままロゴの中に入る形になる。彩度は落とす＝渋め（muted）の基調に合わせ、鮮やかな原色の青と赤にはしない。

**背景ごとに2種類の配色を持つ。** 形は1つ、配色が2つ。

- 暗背景版（主）— Steam のカプセル、扉、サイト、起動スプラッシュ、動画。置かれる場所のほとんどがこちら
- 明背景版（従）— プレスキット、印刷物、白地の資料

明背景版は暗背景版の色を濃くしただけでは合わない。**白地では淡いほうが合う。** 白地に濃い色の塊を置くと優美さが消えて武骨になるので、タイルを淡く落とし、文字は濃い鋼灰のまま残す。文字が実体で絵が繊細な添え物、という関係になる。

決めた値。左端の鋼青から右端の深紅へ**2色を直接つなぐ**（中間に灰を挟まない＝中央が紫を帯びて色に厚みが出る。灰を挟むと中央が抜けて色あせて見えた）。ロゴはベクターで持ち、この値を参照する工程があるので、生成アセットと違って数値で決める（[direction.md](direction.md) が HEX を決めないのは、生成がテキスト指定で参照工程を持たないため）。

| 版 | 左（味方） | 右（敵） | 文字 |
| --- | --- | --- | --- |
| 暗背景版 | `#6e92b8` | `#c05a62` | `#e8ecf0` |
| 明背景版 | `#abbed1` | `#daafb3` | `#333942` |

### 剣と杖の材質

剣と杖は少し質感を持たせる＝材質ごとに色を分け、面に明暗のグラデーションを付ける。タイルと文字がべた塗りの幾何なので、中央の武器だけが「物」として立つ。

- 剣の刃＝鋼。溝の脇に光を置き、左の面が明るく右の面が暗い
- 剣の鍔の弧・鍔の中央の金具・柄の巻き・柄頭の輪＝金。鍔は上が明るく下が暗い、柄と柄頭は左が明るく右が暗い
- 杖＝木。頭の渦から柄まで1本の材質で、左が明るく右が暗い。渦だけ石や鋼にする案は、剣の鋼と材質が被るので採らない
- 剣の革色と杖の木色が被らないよう、剣の柄は金にする（剣の柄を茶にすると杖と同系になった）

各材質は明るい側→暗い側の色の並びで持つ（刃だけ4段＝左の面・溝の脇の光・右の面・右端）。

| 版 | 刃（鋼） | 金（鍔・柄・柄頭） | 鍔の弧（上→下） | 木（杖） |
| --- | --- | --- | --- | --- |
| 暗背景版 | `#bfc7ce` `#eef2f5` `#b3bbc4` `#a3abb4` | `#e2c97e` `#b2913f` `#75591f` | `#ead58c` `#8f6f2a` | `#a8805c` `#71503a` `#4a3426` |
| 明背景版 | `#6f7a87` `#a4adb7` `#5f6975` `#4e5762` | `#c9a84f` `#9c7c2e` `#6b5218` | `#d2b55e` `#7f6420` | `#8c6a4a` `#5e4430` `#40301f` |

明背景版は暗背景版より一段暗い同系色。それでも白地では武器の明るい側が白に近く端がぼやけるので、明背景版だけ武器のシルエットに文字と同じ色（`#333942`）の細い線を敷く。線は端の内外に半分ずつ出るので、見える幅は線幅の半分。暗い色の塊なので文字と同じ「実体」側に並び、「文字が実体で絵が添え物」という関係は崩れない。暗背景版には引かない（タイルから抜いた隙間が輪郭の役をする）。

小さい版（小サイズ版・盤の常設版・アプリアイコンの 1 枚版）では材質の色は点に潰れるが、剣が金・杖が茶の点として区別はつくので、版によって塗りを変えない。

塗りの仕組み：武器の形は1本の輪郭（シルエット）のまま持ち、その形で切り抜いた上に材質ごとの帯（矩形）を重ねる。鍔の弧のように上下に曲がる部位は帯では切れないので、刃だけが通る中央の幅を刃の色で上から重ね、弧と溝の V 字に挟まれた中央の金具は三角形で塗る。境界の値は「確定した寸法」。部位ごとに形を分けて持つ作りにはしていない（武器を描き直したら境界を測り直す）。

## 確定した寸法

生成スクリプトは `godot/tools/logo/` に3本。[`trace_sword.py`](../../godot/tools/logo/trace_sword.py) と [`trace_staff.py`](../../godot/tools/logo/trace_staff.py) が剣と杖の生成画像を SVG のパスに変換し、[`build_logo.py`](../../godot/tools/logo/build_logo.py) がそれらとフォントからロゴ一式を組む。武器を描き直したくなったら、`sword_01_raw.png` / `staff_01_raw.jpg` を差し替えて該当の trace と build を順に走らせる。値を変えて走らせれば SVG 一式が出る。

SVG を PNG にするのは [`rasterize_svg.gd`](../../godot/tools/rasterize_svg.gd)（[../tech/tools.md](../tech/tools.md)）。Godot 内蔵の SVG 読み込みを使うので、外部のラスタライザは要らない。タイルから文字と剣を抜くマスクも描ける。

| 項目 | 値 |
| --- | --- |
| カメラ距離 | ヘックス半径の 6 倍（俯角 52 度・画角 42 度）。小さいほど奥行きが強い |
| タイルの縮小率（隙間） | 0.94（小サイズ版は 0.90） |
| 剣の全長／見える長さ | 516 ／ 312（差が地面に埋まっている分） |
| 杖の全長／見える長さ | 504 ／ 306（剣よりわずかに短い） |
| 剣と杖の傾き | 各 20 度（刺さり口を軸に。剣は右へ・杖は左へ倒れて X にクロス） |
| 刺さり口の位置 | 中央ヘックスの中心から 14 だけ下・左右へ ±30（剣が左・杖が右） |
| 地面の切り口の傾き | 8 度（水平だと切り口が刃と平行に近く、食い込んで止まって見えない）。それぞれの刺さり口を通り、剣は右下がり・杖は右肩上がり＝自分の軸と噛み合う向きに切る |
| 文字の幅／字間 | 1200 ／ 0.12 |
| 文字と紋章の重なり | 文字の大文字高さの 0.70 |
| 紋章の横位置 | 語の中心ではなく、中央の `A` の中心に合わせる（書体の字幅から毎回計算する。数値は焼かない） |
| 紋章の縦位置 | 24 だけ下げる（下げないと `N` の上端と左下タイルの下辺が一直線に重なって、接線が目につく） |
| 文字と武器の抜き | タイルから 12 の余白で抜く |
| 剣と杖の抜き | 手前の剣を奥の杖から 12 の余白で抜く |
| 剣の部位の境界（武器のローカル座標＝高さ 1000） | 柄頭の輪 0〜62・柄の巻き 62〜244・鍔の弧 244〜300・刃の根元 266（刃だけが通る中央の幅は x 88〜160）・鍔の中央の金具は三角形 (96,262)(152,262)(124,280) |
| 材質のグラデの向き | 刃 x 92→156・金 x 100→148・鍔 y 244→300・木 x 60→170（いずれも武器のローカル座標） |
| 明背景版の縁取り | 線幅 6（見える幅 3）・色は文字と同じ |

単色版（白1色・黒1色）は作らない。単色が要るのは、社名ロゴをグッズや看板や印刷広告に載せるような場面で、本作にはその予定が無い。小カプセルもファビコンもアプリアイコンもカラーのままでよく、Godot の起動スプラッシュは地が単色なので、地の色に合う色版をそのまま置ける。必要になったら `godot/tools/logo/build_logo.py` にパレットを2行足せば出る（武器をタイルから抜く処理は残してある）。

形を先に固めてから色を決める。形が定まっていない状態で色を比べても判断できない。

## 制作方法

**生成AIは使わない。** [direction.md](direction.md) の共通メソッド（Gemini で生成）はゲーム内アセット向けで、ロゴには当てはまらない。理由は3つ。

- 生成AIは文字を正確に描けない。似た字形の別物になる
- 拡大縮小・色替え・透過が要るのでベクター（線と面を座標で持つ形式）で持つ必要があり、生成画像はピクセルの集まりにしかならない
- 小サイズ用の調整（線を太くする・要素を減らす）が手作業でできない

作り方は、モチーフの線画だけ生成して下絵にし、それをなぞってベクター化し、文字は既存フォントで組む。ヘックスは投影の計算で作れるので、生成が要るのは剣と杖だけ。組み立ては `godot/tools/logo/` の3本のスクリプトが担う（手で触りたくなったら SVG を Inkscape で開けばよい）。

フォントは**ロゴへの使用が許諾されているか**を確認する。商用利用が可でもロゴ化・商標利用を禁じているフォントがある。
