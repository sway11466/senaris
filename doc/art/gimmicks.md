# 仕掛けの絵の方針

盤に置く仕掛け（スイッチ・罠など）の絵の作り方と書き出し。仕掛けそのものの決まり（置き方・状態・絵のファイル名）は [../gdd/gimmicks.md](../gdd/gimmicks.md) が正本。

---

## 1. 描くもの

- 仕掛けは、地形の上に重ねる立ち絵。描き方は地形のオブジェクト（作業机など）と同じ＝白一色の背景の上に物だけを描き、白を抜いて使う（→ [terrain.md](terrain.md) §1・§3）。
- 状態ごとに1枚描く（スイッチなら `on` と `off`）。状態のあいだで違ってよいのは、状態を見せる部分だけ。形・大きさ・位置・色はそろえる。
- そろえるため、最初の1枚を描いたら、残りの状態はその絵を参照画像として渡し、変える部分だけを指示して作る。
- 状態の違いは、盤の縮尺（1マス30〜70px）で読める大きさの形で見せる。細い線や小さな模様だけに頼らない。

## 2. 大きさと書き出し

- 物差しは地形のオブジェクトと同じ。384px 四方のキャンバスに、下端揃えで置く。大きさは仕掛けの見た目の表（[gimmick_visual.csv](../../godot/data/gimmicks/gimmick_visual.csv)）の `map_scale`＝絵の幅がヘックスの幅の何割か（→ [terrain.md](terrain.md) §1）。大小の差はキャンバスの余白が持つ。
- 状態ごとの絵は、全部を同じ範囲で切り出し、同じ倍率で縮める。切り出す範囲は、全部の状態の絵の輪郭を合わせた範囲。`map_scale` はその範囲の幅に掛ける。状態ごとに輪郭で切り詰めると、動く部分（レバーの向きなど）の違いで倍率と位置がずれ、状態が変わるたびに物が伸び縮みして見える。
- 画面のどれだけ下へ寄せるかは、表の `foot_z`（地形の `object_foot_z` と同じ意味）。
- 書き出したコマンドは、元絵と一緒にレシピに残す（→ §4）。

## 3. 戦闘の画面の絵

- 地形の重ね絵と同じ4つのスロット（奥・隊列の後ろ・中央の継ぎ目・手前）に、状態ごとの絵を置ける＝`{kind}_{state}_combat_{スロット}.png`。描き方・大きさの決まりはスロットごとに地形と同じ（→ [terrain.md](terrain.md) §1・[../tech/combat_scene.md](../tech/combat_scene.md)）。隊列の後ろの大きさは表の `combat_scale`。
- 置くかどうかは種類ごとに決める。置かなければ戦闘の画面には出ない。

## 4. 元絵とレシピの置き場

- 盤・戦闘の画面の絵は `godot/assets/gimmicks/`。
- 元絵・プロンプト・レシピは `godot/assets/gimmicks-src/{kind}/`。ファイルの作法は地形と同じ（→ [terrain.md](terrain.md) §4）。状態ごとの元絵とプロンプトは、名前に状態を入れて並べる（`{kind}_{state}_01_raw.png`・`{kind}_{state}_prompt.txt`）。参照画像を渡して作った絵は、プロンプトの先頭に渡した画像を書いておく。
