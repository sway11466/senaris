# 世界観・設定

Senaris の世界観メモ。冒険譚から読み取れる設定を書き出す。組み立てるときの決めごと（役割で呼ぶ・陣営の色付け・国は厚い組織と主神で描く）は [worldbuilding.md](worldbuilding.md)。構想中の冒険譚から来た設定は、その旨を添える（[roadmap.md](roadmap.md)）。

---

## 冒険譚から読み取れる設定

世界の骨格

- 世界には複数の国があり、大きな国がいくつも存在する。**国ごとに厚い組織が違う**のが色付けの基本線。
  - **冒険者の国**（冒険譚1・3の舞台）— 冒険者ギルドが厚い
  - **聖職の国**（冒険譚2・邪神三部作の舞台）— 教会が厚い
  - **魔法使いの国** — 魔法ギルドの本拠
  - 帝国 — 軍が厚い。軍事力の強い国（まだ冒険譚には出ていない）
  - 海洋国家 — 商人の私兵団が厚い。島の多い商業の国（まだ冒険譚には出ていない）
  - イーストエンド — 厚い組織は未定。サムライやニンジャがいる国（まだ冒険譚には出ていない）

冒険者の国（冒険譚1・3の舞台）

- **冒険者の王が立てた国。** 国土が広い。
- 国土が広いぶん自警団や冒険者ギルドが発達している。町の守りは自警団が担い、その手に負えない案件を冒険者が請け負う。
- 主教を持たない珍しい国。職人ギルドが発達しており、職人の神の信者は多い。

聖職の国（冒険譚2・邪神三部作の舞台）

- 法王が統治し、首都は聖都と呼ばれる。**信仰が国の掟そのもので、身分も信仰上の位階で決まる。**
- 中心は教会（クレリック/プリースト/ビショップ）。**騎士団は聖職の一形態（武の聖職）**で、**パラディンはその最高位の称号**。聖都には聖騎士（パラディン）が7人いる。
- 魔法ギルド（ウィザード/ウィッチ/ソーサラー）は魔法使いの国を本拠とする別系統。聖職の国でも厚く、教会・騎士団と並んで組織として力を持つ（階位が下ということはない）。
- **冒険者は制度の外にいる者。** どの組織にも属さないので、制度が拾わない仕事が回ってくる。
- **大きな館と別荘には祈り所が標準装備。** 有力者の屋敷には秩序の神の祈り所があり、聖職者はそこで祈れる（盤では休める拠点として置く。邪信徒は使わない）。

魔法使いの国

- 魔法ギルドの本拠。詳細は未定（舞台にする冒険譚が出たときに書く）。
- 帝国とは緊張関係にある（下記 帝国）。
- **学者の国。** 太古の文明（下記）の研究に一番熱心なのはこの国。太古の文明と縁があるからではなく、純粋に学者の国だから。知りたいという欲が厄災の前でも止まらないのが、この国の闇（構想中「古代遺跡」より → [ancientruins.md](ancientruins.md) 両国の闇）。

帝国

- **枯れた土地が多く、貧しい者が多い。** それでも軍事には力を入れており、実際に軍隊は強い。
- **兵器類の研究も熱心。** 攻城兵器や輸送技術は非常に高い。技術は自前の研究で伸びたものだが、太古の文明の分析にも積極的（下記 太古の文明）。その縁で**ドワーフとは仲がよい**（職人どうしの付き合い。国どうしの取り決めとは別の線）。
- **独裁が強い。** 統治者の呼び名は未定（役割で呼ぶ → [worldbuilding.md](worldbuilding.md)）。
- 物語上はどちらかというと悪役側に置く国。ただし国民＝悪ではなく、貧しさと軍の強さが同居している国として描く。
- 貧しさから脱するために国土を広げたい。太古の兵器は厄災だと認識しており、撃つためではなく抑止兵器として持ちたい（構想中「古代遺跡」より → [ancientruins.md](ancientruins.md) 両国の闇）。
- **魔法使いの国とは緊張関係にある。** 国境の山の鉱山は、両国が相手に利する条件をのめないため、第三国（冒険者の国）のドワーフに産出物を渡す3国の取り決めで収めている（構想中「古代遺跡」より → [ancientruins.md](ancientruins.md)）。

海洋国家

- 島が多い商業の国。商人が私兵団を持ち、国家というより有力豪族の集合体。
- 国王は投票で決まるが、歴史的に有力豪族の輪番。
- 名前は未定。

イーストエンド

- サムライやニンジャがいる国。ショーグンが治める。詳細は未定。

盗賊ギルド

- **盗賊ギルドは各国に存在する。** 国によって扱いが違う。冒険者の国では公認の大きな組織。聖職の国では表立っては存在しない（裏の組織として街の下水道などを縄張りにしている。邪神三部作 第1部の舞台）。
- 縄張りは組織の生命線。縄張りを荒らす者には、相手が誰であれ手を貸す側に回る。

異種族

- 異種族（エルフ＝森の里、ドワーフ＝山の里 など）は、人間と共に暮らすことも敵対することもあり、人間同士と同じような関係にある。
- エルフは森の奥に里を構え、人間とは距離を置く。長命ゆえに人間の営みを短慮と見ており、とくに森を切り拓く行為には厳しい。明確に敵対はしないが、信用もしていない。森そのものを神として信仰しているので、森を拓くことは神への冒涜になる（下記 神々）。
- ハーフリングはたまたま仲間でいることが多いが、関係としては他の異種族と同じ。
- ドワーフの多くは冒険者の国の出身（職人ギルドが発達した国。上記 職人の神）。魔法使いの国と帝国の国境の山には、ドワーフが活用する鉱山があり、産出物はドワーフの物という3国の取り決めがある（構想中「古代遺跡」より → [ancientruins.md](ancientruins.md)）。

脅威

- 魔物の襲撃が各地で起きる。ゴブリン一族（巣穴・数で攻める／冒険譚1）、アンデッド（墓地から湧く／冒険譚2）、竜害に群がるモンスター（冒険譚3）。
- 上位の脅威が段階的に控える。アンデッドの元凶ネクロマンサー、その奥に魔王（冒険譚2）。度々街を襲うドラゴン＝竜害（冒険譚3）。

技術・魔法

- 飛空艇などの飛行手段がある（冒険譚2）。
- **機械兵は珍しくない。** 歯車で動く機械の兵は、この世界では見慣れたもの（構想中「古代遺跡」より。太古の機械はそれとは格が違う → 下記 太古の文明）。
- 合体魔法・聖なる加護・神の裁きといった、複数人で行う術＝陣形スキルが存在する。

太古の文明（構想中「古代遺跡」より → [roadmap.md](roadmap.md)）

- **太古の文明の遺跡があることは広く知られており、各地に遺跡が残っている。** 特定の国の領土や祖先に結びついた存在ではない。
- 超魔法や科学技術が発展しており、いまの文明を超えていたと推測されている。
- 研究に一番熱心なのは魔法使いの国。縁があるわけではなく、純粋に学者の国だから（上記 魔法使いの国）。
- **滅んだ理由は不明で、様々な説がある。** 有力なのは2つ。高度に発達した魔法と技術を使った戦争で取り返しのつかない被害が出た、という説。傲慢な振る舞いに神々が怒り滅ぼされた、という説。
- **古代兵器はレア度や機能でランク分けされている。** 仕組みは分からないが威力の高い銃など、よく出土して使い方も簡易なものは通常品。通常品といっても極めて高価で、一般人は買えないし見る機会も非常に少ない。**Sランクのものは「超古代兵器」と呼ばれる**（構想中「古代遺跡」の魔人製造機はこれ → [ancientruins.md](ancientruins.md)）。
- **太古の文明は魔法も工業も優れていた。** 魔法の面は魔法使いの国が、工業の面は帝国が、それぞれ深く研究している。遺跡への向き合い方は国ごとに違う（厚い組織がそのまま出る）。
  - 魔法使いの国 — 研究対象。学者の国として最も熱心。太古の魔法を研究する。
  - 帝国 — 兵器や技術の供給源と見る。軍が厚い国の見方。太古の工業を研究する（自前の兵器研究と並行して分析している）。
  - 冒険者の国 — 遺跡荒らしは冒険者の仕事の一種。冒険者ギルドが依頼を仲介する。
  - 聖職の国・海洋国家・イーストエンド — 未定（古代遺跡の冒険譚では出さない）。

## 神々

神は役割で呼び、固有名を持たない（[worldbuilding.md](worldbuilding.md) 役割で世界を見せる）。国ごとに主に祀る神が違い、神々の間に上下はない。秩序と混沌の骨格は [twingods.md](twingods.md)。

| 神 | 信者の厚いところ | 備考 |
|---|---|---|
| 秩序の神 | 聖職の国 | 混沌の神と双子。片方だけでは降臨できない |
| 混沌の神 | 祀る国はない | レアな神で、存在自体が一般に知られていない。聖職の国はその存在を隠しており、知るのは限られた高位の神職だけ。記された書物は厳重に管理されている。聖職の国では「邪神」と呼ばれる |
| 知識の神 | 魔法使いの国 | |
| 商売の神 | 海洋国家 | |
| 海の神 | 海洋国家 | 商売の神と併せて崇める |
| 戦の神 | 帝国 | |
| 森 | エルフの里 | 森そのものが信仰の対象であり、神そのものでもある |
| 職人の神 | ドワーフの山の里・冒険者の国 | 職人ギルドが発達した所に信者が多い |
| 音楽と快楽の神 | 国に依らず各地 | 音楽と快楽で1柱。ご利益が多いので、多くの国に一定数の信者がいる |
| 気まぐれの神 | 国に依らず各地 | 運の神。神自身が気まぐれでご利益は本当に神頼みなので、本気で信じる者は少ない。隠す必要も公言する必要もなく、害もないので禁じる国もない。気に入られた者にはとてつもない力が授けられる |

- 冒険者の国は主教を持たない。
- 気まぐれの神に気に入られた者の力は、いまのところ設定だけでシナリオにはしない。

信仰

- 多くの神は信仰が自由。誰が信じてもよく、国や組織に属する必要はない。
- 神は、とくに信心深い者に加護や特別な力を授ける。信仰がある＝聖職、ではない。
- 多くの人は軽い信仰しか持っておらず、特別な加護や力は受けていない。
- 国をあげて聖職を育成しているのは聖職の国のみ。他国の聖職者は制度ではなく個人の信仰から出る（冒険者の国のプリースト → [twingods.md](twingods.md) 冒険者一行）。

## 国の隣接関係

いまのところの隣接。世界地図は描かない（[worldbuilding.md](worldbuilding.md)）。位置関係はこの一覧で持ち、国境をまたぐ冒険譚を書くときに略図を起こす。

- 冒険者の国 — 大きいので多くの国に接する。聖職の国・魔法使いの国・海洋国家。
- 聖職の国 — 冒険者の国・魔法使いの国のみ。
- 魔法使いの国 — 冒険者の国・聖職の国・帝国。
- 帝国 — 魔法使いの国。
- 海洋国家 — 冒険者の国・イーストエンド。
- イーストエンド — 海洋国家。
