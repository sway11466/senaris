# 冒険譚の制作方針（全キャンペーン共通）

すべての冒険譚（キャンペーン）に共通する作り方の取り決め。各冒険譚ファイル（`campaign/<冒険譚>.md`）はこの方針に従い、固有の内容（物語・casting・盤面）だけを書く。

---

## 難度帯と冒険譚の連なり

難度帯は「危機のスケール」を目安にする（あくまで規模の軸。手応えそのものは盤面設計で作る）。

- 初級: 町・街・都市レベルの危機
- 中級: 国家レベルの危機
- 上級: 世界レベルの危機

危機の大きさ＝脅威が滅ぼせる規模（何を脅かせるか）であって、舞台の地理的な広さではない。小さな島の一室でも、そこで起きるのが世界の危機なら上級。

冒険譚どうしはゆるく繋げてよい（伏線・再登場・格上げ）。ただし各冒険譚は単体で完結させる＝前提クリアを要求せず、続きに持ち越す cliffhanger にもしない。繋がりはご褒美であって依存関係にはしない。

- 危機が大きくなる連なりは難度帯をまたいで自然（局地→国家→世界）。同格の横並びは同じ帯に置く。
- どちらでも各話の単体完結は死守。硬い依存は物語のゲート（腕前の壁）にも単品購入の妨げにもなるので避ける。
- 繋がりに気づかせたいときは軽い目印（同じ地方・「関連: 〇〇」・再登場キャラ）を添える。棚（難度帯）の隣接には頼らない。
- スレッドは短く（2〜3本）。長い連結は避ける（単一の長編化＝ゲートと単品売りの弊害）。

## ステージの題名

題名の正本は `godot/data/i18n/campaigns.csv`。次を目安にする。当てはまらない題を置いてもよい。

日本語は、

- 戦闘を表す語を入れる
- 体言止めにする
- 場所か相手のどちらかを含める

英題は日本語の訳ではなく、英語の題として魅力があるかを先に見る。

- 命令形（プレイヤーへの作戦指示）で書く。冒険譚の最終ステージだけ `The` ＋名詞にする
- 2〜4語に収める。動名詞は使わない
- 場所の描写より、その回が要求する戦術を名指す

## 会話パート（台本）

各ステージは**戦闘前と戦闘後に短い会話パート**を挟む。

- **構成**: 前（状況説明＋掛け合い）→ 戦闘 → 後（締め＋次回への引き）。戦闘後の終盤で**次ステージの教える要素を予告**し、ステージ間を1本につなぐ。
- **戦闘中**: 盤で何かが起きた瞬間にも短い会話を挟める。引き金はステージJSONの `events` で、イベントに `dialogue`（台本のキー名）を書く（[../gdd/map.md](../gdd/map.md) イベント）。盤の出来事だけでは何が起きたのか伝わらないとき（端に増援が湧いただけ、など）に、言葉で立てるのが役目。前後の会話より短く、3〜4行に収める。
- **拠点を取った瞬間**: 引き金には指定ターンの到来のほかに、拠点の占領（`on: "capture"`）を書ける。中立拠点を解放して仲間が加わる場面や、その里を敵に先に取られる場面を、その場で立てる。同じ拠点に味方版と敵版の台本を置き、`once` に同じ名前を書いて片方だけを流す。敵が取った場合も敵ターンの最中に会話が入る。
- **チュートリアル装置**: 前半は質問役が問い、指示役が答える形にして、操作のヒントを会話へ自然に織り込む（説明くさくなりすぎない範囲で）。
- **登場人物**: 各冒険譚で定義する。**役職ベースの没個性キャラ**（指示役・質問役・報告役など）を推奨。盤上ユニットと対応づけてよい。固有名は後付け可。
- **書式**: 引用ブロックで `> **話者**: セリフ`。ト書きは `> _（…）_`。台本は各ステージ詳細の「会話（戦闘前）／（戦闘後）」に直書きする。
- **効果音**: 会話の途中で音を鳴らせる。台本では `> 効果音：ガシャーン（sound:slash_m）` と1行を立てる（擬音＝画面に出る文字／`sound:` は素材ID＝`godot/data/audio/sfx_catalog.gd` の素材＝`godot/assets/sfx/{id}`）。会話の流れを断つ出来事（物音・悲鳴）を、台詞で説明せずに立てるのが役目。
- **話者は連続させない**: 同じ人物の台詞を2行続けて置かない。長くなるなら別の人物に振るか、1行にまとめる。表示が左右交互のチャット風（`ConversationPanel`）なので、同一話者が続くと掛け合いに見えず読み手が置いていかれる。
- **データ化**: 会話の構造（誰が・どの顔で・どの順で）はステージJSONの `dialogue`（`intro` / `outro` ＋ イベントから名指しされる任意のキー、各行 `{ speaker, skin, text }`＋任意 `when`）に持つが、**presentation 専用**＝盤面データ(BattleState)には入れない（案P・`StageLoader.parse_dialogue`）。**テキストと話者名は翻訳キー**で持ち、実文字列は Godot 標準の翻訳CSV（正本 `godot/data/i18n/dialogue.csv`＝`keys, ja, en…`）→ `tr()` で解決する（多言語対応の全体方針 → [../tech/i18n.md](../tech/i18n.md)）。効果音の行は話者を持たない行 `{ "text": "<擬音の翻訳キー>", "sfx": "<素材ID>" }`＝顔も名前も出さず中央に文字だけを置き、その行が出るときに音が鳴る（文字送り音の代わり）。顔は `UnitSkin` の絵で、基本は `map` スキンを流用する（`portrait` があればそちらを優先／どちらも無ければ名前プレースホルダ）。`portrait` を用意するのは、盤に出ないキャラがしゃべる場合と、`map` では表せない表情を見せたい場合に限る。表示は `ConversationPanel`（右エリアのチャット風・話者左右交互・「次へ」/「会話をスキップ」・戦闘後会話は勝利時のみ）。戦闘中の会話も同じパネルで、盤を止めて出す。

### 誰が会話に出るか

継承（carryover）の冒険譚では、仲間が増えるか減るかがプレイヤーの戦い方で変わる。会話の出欠はこう決める。

- 出欠は名簿（[supply.md](supply.md)）だけを見る。在籍していれば喋る。
- 兵力ゼロで戦線を離れた仲間も喋る。ゼロは離脱であって死亡ではない＝盤には出ないが物語からは退場しない。台本でも死亡として扱わない（「二度と戦えない」までは書いてよい）。
- 仲間にできなかったキャラは以後まったく登場しない。名簿に載らないので分岐を書く必要もない。

### 会話の分岐

台本の行に条件 `when` を付けて出し入れする。

```json
{ "speaker": "...", "skin": "elf", "text": "t3.st5.elf.01", "when": "joined:elf" }
```

- 粒度は行単位。条件は `joined:<actor>`（在籍）と、その否定 `!joined:<actor>`。
- 見る名簿は会話パートごとに違う＝戦闘前はステージ開始時の名簿、戦闘後はクリア後の名簿。加入が確定するのはクリア時（[supply.md](supply.md)）なので、中立拠点で仲間にした駒はその回の戦闘後から喋れる。
- 落とせない情報（次ステージのヒント・筋の進展）は必ず固定メンバーの台詞に置く。加入キャラの台詞は、足しても引いても筋が通る色付けに限る。これを守れば分岐は数行の足し引きで済み、代替台詞を書き分けずに済む。
- 分岐させるのは加入の有無だけ。誰が生き残ったかでは分岐させない（組み合わせが爆発する）。
- 条件の評価は application 層（表示側は渡された行を順に出すだけ）。
