## 骨格 — いがみ合う混成チームが、認め合っていく

**基本の筋は一行の中にある。** 緊張関係にある2国からやむなく出し合った混成チームが、鉱山・遺跡・古代兵器と進むうちに互いを認め合っていく。**そこに両国の思惑が乗ってくる。** 三部作の敵は、盤の上では魔物・守護者だが、物語の敵は**両国の闇**（下記）。

- 一行の変化（いがみ合い → 認め合い）が縦糸、両国の思惑（闇）が横糸。
- 一行は両国の人間なので、国の命令と仲間との板挟みが自分の問題になる。双子の神の一行（二重に制度の外）とは逆で、**制度の内側の人間が、内側の闇と向き合う**。

## 舞台 — 国境の山とドワーフの鉱山

- **魔法使いの国と帝国の国境の山。** 冒険者の国も近い（隣接関係 → [world.md](world.md) 国の隣接関係。魔法使いの国は冒険者の国・聖職の国・帝国に接する）。
- **ドワーフが鉱山として活用している。** 産出物はドワーフの物という取り決めが、**魔法使いの国・帝国・冒険者の国の3国**で結ばれている。
- **取り決めの益は冒険者の国に出るようになっている。** 魔法使いの国と帝国は緊張関係にあり、相手に利する条件はのめない。どちらでもない第三国（冒険者の国）のドワーフに産出物を渡す形が、両国が唯一のめる落とし所だった。
- **3国とも取り決めのもとで鉱山に人を置いている。** ドワーフは掘る。帝国は道具の整備に技師を常駐させている（トロッコやレールは帝国の輸送技術）。魔法使いの国は出土品の鑑定に学者を置く（鉱山からは時々、太古の遺物が出る）。
- **多くのドワーフは冒険者の国の出身。** 山の里は魔法使いの国の側にあるが、人は冒険者の国から来ている＝鉱山は三国の人が交わる場所になる。
- 鉱山の奥に太古の文明の遺跡が広がっており、最深部には古代兵器が眠っている。
- **魔物が出た原因: 掘り進めた先が遺跡の外縁で、封じられていた合成魔獣が出てきた。** 以後は出続ける。誰かの意図はない。
- **敵は合成魔獣と兵器系の敵が混じる。** 古代兵器っぽいものは割と最初から出す。第1部の終わりに出るのが「明らかに古代兵器」と分かる半魔半機の怪物。
- **遺跡荒らしは三部作を通して出さない**（決定）。
- **第1部の後、両国はそれぞれの判断で鉱山を封鎖する**（第2部の前提 → [ancientruins2-ruins.md](ancientruins2-ruins.md) st1）。

## 魔力炉と魔人

**ゲーム内の呼称は「魔力炉」**（第1部 st7 で、失敗した装置を初めて見たウィザードが名付ける。魔力と機械が融合している、から）。本書で「炉」と書くものはすべて魔力炉のこと。

古代兵器はランク分けされており、Sランクが「超古代兵器」（[world.md](world.md) 太古の文明）。魔力炉は、**人（デミヒューマンを含む）・魔獣・兵器を合成して「魔人」（仮称）を作るもの**。魔人は**1人で1国を滅ぼす程度の力**を持つ。魔人が世界を滅ぼしたわけではない。

- **魔法と工業の両方でできている。** 魔法使いの国は魔法の側を、帝国は工業の側を読める。どちらの国も半分しか読めない＝両国の闇が揃って初めて動く。
- 帝国の「抑止兵器」は、魔人を1人持つこと。魔法使いの国の「研究」は、作動させる＝魔人を作ってみること。**どちらも人を材料にする。** 両国の思惑はここで同じ闇に落ちる。
- **炉には番号がある**（第2部 st4 の破れた地図で分かる）。
  - **1号炉**＝第1部 st7 の失敗した装置。失敗の分析のために残されたもの。生成は止まっている。
  - **4号炉**＝第2部の建設中の炉（完成間近）。
  - 2号炉・3号炉は地図の破れた部分で読めない。
- **いま湧き出ているのは失敗作。** 目を覚ました炉が、合成魔獣（魔獣寄りの失敗作）と兵器系の敵（兵器寄りの失敗作）を吐き続けている。
- **最深部には、成功した魔人が1体だけ眠っている。** 太古に作られた魔人のうち、唯一残った完全体。第2部で4号炉が起動されたことで目を覚ます。第3部のボス。
- 結末は「壊す」（下記 一行の最終判断）。炉を止めるだけでは、魔人は活動を停止するだけで死なない。
- 呼び名は役割で（[worldbuilding.md](worldbuilding.md)）。「魔人」は仮称。**ゲーム内で「魔人」という言葉が初めて出るのは第2部 st7**（魔人になった学者が自ら言う）。それまで一行は知らない（第2部 st3 の図書館で分かるのは「究極の生命体の研究」まで）。

### 各部の頭目

- **第1部＝半魔半機の怪物**（ゲーム内の呼び名。魔人の失敗作）。魔獣でもない、兵器でもない、半分魔獣で半分兵器の異形。人の部分が無い（学者を材料にする前の炉が、遺跡内の魔獣と兵器だけで吐いたもの）。「明らかに古代兵器」と分かる敵で、第2部の報告と密命に繋がる。
- **第2部＝魔人になった学者**。4号炉に自ら入った魔法王国の学者。未完成の炉なので不完全体。**最初は強力だが、魔力が時間で尽きて弱体化し、倒せるようになる**（決定 → [ancientruins2-ruins.md](ancientruins2-ruins.md) st7）。
  - **材料になるのは第2部で来る学者**で、一行のウィザード／ウィッチではない（一行の人間だと「撃つ相手は明確に」が揺れる。そこまでダークにはしない）。一行の学者2人は「同じ欲を持っているのに踏みとどまる側」。
- **第3部＝完全体の魔人**。**賢く、残虐。** 自分が成功体だと認知したとき、「自分が最も強い」状態を維持するために開発者を全員殺した。これを本人に語らせる。

### 魔人は盤に出る — 魔力が切れて弱る

- **魔人は盤に出る**（第2部・第3部の山場）。一行だけでは倒せない格のもの。
- **魔人は生きていくために膨大な魔力が要る。** 炉がこれを供給して、初めて動ける。弱点は魔力。
- 第2部は「時間で尽きる」、第3部は「炉を止めて断つ」で弱らせる（下記 第3部の流れ・仕組みの追加）。

### 古代図書館と持ち出した本

- **第2部 st3 に古代図書館が出てくる。** 機械と魔法で管理された図書館。ここで遺跡が「究極の生命体」を研究していたと分かる。図書館の中では間接攻撃ができない（詳細 → [ancientruins2-ruins.md](ancientruins2-ruins.md) st3）。
- **ウィッチと銃の技師が、隣の研究室の本（図書館から正式に貸し出し済み＝持ち出せる）をこっそり持ち出す**（第2部 st4）。持ち出すのは「炉」の本。
- **第3部の後半で魔人が図書館を焼く。** 炉に関する書類が焼けるが、2人が持ち出していた本から、魔人の弱点が魔力だと知る（下記 第3部の流れ）。

### 第3部の流れ — 魔人に翻弄される

遺跡に潜るというよりは、魔人に翻弄される流れ。

1. 最初、魔人は直接出てこない（プレイヤーには示唆する形で見せる）。遺跡を操作して調査隊を奥へいざない、炉＝魔力の供給元を解放させる。
2. 魔人が正体を明かし、調査隊に接触してくる。魔力が回復していないので声だけ。遺跡の機能を操作して調査隊を始末しようとする。
3. 後半、魔人が古代図書館を焼く。炉に関する書類が焼けるが、ウィッチと銃の技師が持ち出していた本から、魔人の弱点が魔力だと知る。
4. 魔人も気づき、調査隊を始末しようと追い詰めてくる。調査隊は、最初に解放した炉を止めに向かう。
5. 最後、強力な魔人の攻撃を受けながら炉を止め、魔人にとどめを刺す。魔人は活動を停止するが、死なない。
6. 完全に止めるには炉を壊す。エネルギー逆転（ターボ）で臨界点を超えさせ、内部崩壊させる。全員がこれを選ぶ（下記 一行の最終判断）。炉からエネルギーが溢れ出し、遺跡は崩壊する。

- **「魔力の管を壊して供給を断つ」仕掛けは第3部で使う**（第2部 st5 の案から移した → 下記 仕組みの追加）。

## 両国の闇

物語の敵。盤の上の敵（魔物・守護者）とは別に、一行の背中にいる。深みは1〜2行で見せる（[worldbuilding.md](worldbuilding.md) 陣営の色付け）。

### 帝国の意思 — 抑止兵器として持ちたい

- **貧しさから脱するために国土を広げたい。** 枯れた土地の国が、力で状況を変えようとする。
- **その手段として古代兵器を使いたい。** ただし、それが厄災であることは認識している。だから撃つためではなく、**抑止兵器として持ちたい**＝持っていることで相手を黙らせ、国土を広げる交渉を有利にする。
- 動機は国全体のもの（貧しさ）で真っ当。手段は独裁的。独裁者の野心と国の貧しさが重なっているので、技師2人は「国のためだ」と信じて密命を受けられる。
- **密命の中身は「魔力炉を、動く状態を保全して使えるようにする」。** 第2部では帝国の研究者が「出し抜いて手に入れろ」と押す。技師が信じたものと、最後に一行が選ぶこと（炉を壊す）の差が、第3部で割れる。

### 魔法使いの国の意思 — 純粋に自由に研究したい

- **純粋に、自由に研究したい。** 学者の国として、太古の魔法を誰にも邪魔されずに調べたい。
- ただし、研究を進めれば**結果的に作動させる必要が出る**。厄災を「調べるために」動かすことになり、被害は出そうだと分かっていても止まらない。闇は**知りたいという欲が厄災の前でも止まらないこと**に置く（滅びの神罰説「傲慢な振る舞いに神々が怒った」と重なる → [world.md](world.md) 太古の文明）。
- 第2部では魔法王国の学者が「帝国側に魔力炉は渡さん」「技師たちを焼いてしまえ」まで踏み込む。
- 帝国の「厄災と分かっているから抑止に留める」と、魔法使いの国の「厄災と分かっていても調べる」が正反対。どちらが危ういかはプレイヤーに委ねる。

### 思惑が見える段

- **第1部には密命がない。** 一行は湧き出たモンスターの討伐で忙しく、いがみ合いは純粋に「反目する混成チーム」のもの。両国もまだ動いていない。
- **第1部の終わりに、半魔半機の怪物（明らかな古代兵器）が出てくる。** ここで初めて「鉱山の奥に太古の兵器がある」と分かる。
- **第2部は、報告を受けた両国が鉱山を封鎖し、調査団を送り込むところから始まる。** ここから疑心が一行に入る。**st5 で一行が国ごとに分断され、分かれた先で両国の密命が明かされる**（→ [ancientruins2-ruins.md](ancientruins2-ruins.md) st5）。
- 3段（魔物 → 遺跡 → 兵器）と、思惑の段（無し → 密命 → 裏切り）が揃う。

### 一行の最終判断 — 炉を壊す（全員が自分の国を裏切る）

- **1つの国が独占してよい技術ではない。そもそも、今の世界では正しく扱えない。** 調査隊は圧倒的な力を手に入れた者の成れの果てを2回見た（魔人になった学者・古代の魔人）。だから全員がこの遺跡の破棄を決断する。
- **全員が自分の国を裏切る判断をする。** 学者は研究を捨て、技師は密命（炉の保全）を捨て、ドワーフは（山の産出物としての）取り分を捨てる。縦糸（認め合い）の到達点が、横糸（両国の思惑）を断つ形になる。
- **壊し方はエネルギー逆転（ターボ）。** 炉を臨界点を超えさせて内部崩壊させる（上記 第3部の流れ）。遺跡は崩壊する。
- **両国には「古代遺跡が暴走して壊滅した」と報告するにとどめる。** 両者ともそう報告するので、このチームが叱責を受けるような事態にはならない。
- その後の一行は未決。

## 主役の一行 — 魔法使いの国と帝国の混成軍

**必要に応じて生成されたチーム。** 鉱山で掘り当てたモンスターを倒すために、緊張関係にある魔法使いの国と帝国が、やむなく人を出し合って組んだ。一行の戦う理由は「掘り当てた魔物を倒す」で、国の思惑の外にある（上記 善悪の置き方）。**人は5人、それに兵器のユニット（技師が扱う → 下記 技師と兵器）が付く。** 第2部から両国の調査団が加わる（下記）。

| | 出身 | 役どころ | 備考 |
|---|---|---|---|
| ウィザード | 魔法使いの国（学者） | 長射程の間接（貫通） | 既存 type |
| ウィッチ | 魔法使いの国（学者） | さらに長い射程の間接（貫通） | 既存 type |
| 銃の技師（新 type `gunner`） | 帝国 | 間接（貫通・対空あり）。ウィッチより射程が1短い | 女性。リペア持ち |
| 盾の技師（新 type `guard`） | 帝国 | 受ける前衛（古代の盾持ち） | リペア持ち |

## 技師と兵器

帝国から来た技師たちと、彼らがリペアする兵器。帝国の強み「攻城兵器と輸送技術」（[world.md](world.md) 帝国）に乗る役。

### 技師（新 type）— リペア

- **ユニットスキル「リペア」**: 機械の駒の兵数を回復する。対象は**兵種が兵器（`emplacement`）と輸送（`transport`）の駒**（決定）＝この三部作の兵器（移動砲・移動壁・ドリル＝兵器、トロッコ＝輸送）と、既存のバリケード・バリスタ・馬車・飛空艇。兵種「兵器」は既存のもの（バリケード・バリスタと同じ）で、新しい兵種は作らない。**回復量は仮で +2、チャージ無し（毎ターン撃てる）**。テストプレイで調整する。発動者1体・隣接1体の既存の仕組み（[../gdd/skills.md](../gdd/skills.md)）に乗せる。
- **兵種は「技師」**（新しい兵種。占領はできない。リペアはこの兵種だけ）。
- **3種類**。どれもリペアを持つ。
  - **銃の技師** — 女性。通常品の古代兵器（銃 → [world.md](world.md) 太古の文明）を持つ間接。型 `gunner`。**攻30／対空30／貫通0.5／防30／移4／射程2-4・歩行・兵種「技師」**（決定。調整は実プレイで）。ウィッチ（30/30/貫通0.5/防30/移4/射2-5）と値が同じで、**射程だけ1短い＝ウィッチよりちょい弱い**。その分リペアを持つ。古代の銃は貫通を持つ（魔法兵と同じ0.5）＝硬い失敗作にも通る。
  - **盾の技師** — 古代の盾を持つ前衛。ドワーフと並ぶ2枚目の前衛。型 `guard`。**攻20／対空0／貫通0／防70／移5／射程1・歩行・兵種「技師」**（決定。調整は実プレイで）。ナイトの防御70で、攻撃は殴れないほど低い＝**受け専門**。ドワーフ（攻60/防60/移4）が「殴れる前衛」、こちらが「受ける前衛」で対になる。移5は一行で唯一の中速＝壊れかけた兵器のところへ一番早く着いてリペアできる役どころに合わせた。古代の盾は `shield` 列（兵数の手前で損害を受ける器 → [../gdd/combat.md](../gdd/combat.md) シールド）では表さない。この器はステージ中に回復せず、継承にも損耗として乗るので、連戦の味方に持たせると剥がれっぱなしになるため。防御70で表す。
  - **調査技師**（第2部から） — 帝国の戦闘要員。斥候寄りの調査担当。新 type（名前・値は未決）・兵種「技師」。**リペアを持つ。罠発見のスキルを持つ。攻撃後の移動（斥候の再行動）はできない**（決定）。
- 山場での役どころ（何をリペアするか）は未決。

### 兵器

鉱山で使う道具と、レアな古代兵器。兵種は既存の兵器（`emplacement`＝バリケードと同じ）か輸送（`transport`＝馬車と同じ）で、技師がリペアできる。

- **トロッコ** — レールの上を高速に動く特殊移動。レールは地形（[../gdd/terrain.md](../gdd/terrain.md)）として盤に敷く（[../gdd/movement.md](../gdd/movement.md)）。**運ぶ用**（馬車の親戚）。**4人乗り**。型は2つ作る（決定）。
  - **レール車（改良トロッコ）** — 型 `railcar`。**移動タイプは既存の「車輪」**（馬車と同じ。道・平地・荒地は歩行と同じで、森・茂みは重く、岩地は不可。レールは道と同じコスト1）。**0／0／貫通0／防10／移8・車輪／搭乗4・兵種「輸送」**（移8は決定。防10は馬車と同じ仮の値）。**この三部作で使うのはこちら。** 第1部 st2 でレールの起点に置かれ、回収した時から一行の駒（名簿に載る）。
  - **レール専用** — 型 `minecart`。移動タイプはレール専用（レール以外は進入不可）。**0／0／貫通0／防10／移8・搭乗4・兵種「輸送」**（移8は決定。防10は仮）。**この三部作では使わない**（他のシナリオ用に型だけ用意する）。
- **移動壁** — 鈍足で移動できるバリケード（盾車の類）。間接は魔法兵2人と銃持ちで足りているので、兵器の2つ目は壁。型 `mantlet`。**攻0／対空0／貫通0／防60／移2・車輪／射程1・兵種「兵器」**（決定）。攻撃0なので殴れず、反撃もしない。
- **ドリル（削岩機）** — 近接の兵器。**攻撃できる壁**＝移動壁と同じく鈍足で硬く、こちらは殴れて反撃もする。型 `drill`。**攻50／対空0／貫通0／防50／移2・車輪／射程1・兵種「兵器」**（決定）。岩の地形は壊せない（決定）。
- **移動砲** — 動ける砲（バリスタの親戚で移動できるもの）。型 `cannon`。**攻50／対空20／貫通0／防20／移2・車輪／射程2-5・兵種「兵器」**（決定）。バリスタ（90/30/防20/射2-6・動かない）よりだいぶ弱い砲＝一行の火力の主役は学者2人のままで、砲は射程5で先に削る役。
- **偵察ドローン**（第1部） — レアな古代兵器。**ピクシーの別スキン**（型は既存の `pixie`＝攻防10・移5・飛行）。**罠を発見できる**＝ユニットスキル「罠発見」を持つ（スキルはスキンIDで照合するので、ピクシーダストは撃てず、罠発見だけを持つ → [../gdd/skills.md](../gdd/skills.md)）。発見すると印が付き避けられる。繊細で魔物のいる所には飛ばせない（[ancientruins1-mine-monsters.md](ancientruins1-mine-monsters.md) st3）。**銃の技師の持ち物**（秘蔵っ子）。第2部では出さない（上記 人物）。
- **調査用の古代兵器**（第2部から） — 調査技師が持ってくる高ランクの古代兵器。**長距離の罠発見のスキルを持つ。威力は低いが、長距離の間接攻撃ができる**（決定）。新 type（名前・値・見た目は未決）。技師がリペアできる兵種（兵器の想定）。偵察ドローン（近くの罠を見る・魔物のいる所に飛ばせない）とは、離れた所から罠を見て撃てる点で役を分ける。
- 罠は5種（踏むとデバフ・ダメージ・警報・足止め・転移）。
