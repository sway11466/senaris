# 古代遺跡（仮）— 共通設定

太古の文明の遺跡を舞台にする冒険譚の、共通の土台。構想中（[roadmap.md](roadmap.md) アイデアネタ帳）。世界設定（太古の文明・各国の向き合い方）は [../gdd/world.md](../gdd/world.md) 太古の文明に置き、ここには冒険譚固有の舞台・人物・骨格を置く。

ネタ帳の骨子は3段（鉱山の魔物 → 古代遺跡 → 古代兵器）で、**三部作**にする（各部の単体完結は [authoring.md](authoring.md) 難度帯と冒険譚の連なり）。

---

## 骨格 — いがみ合う混成チームが、認め合っていく

**基本の筋は一行の中にある。** 緊張関係にある2国からやむなく出し合った混成チームが、鉱山・遺跡・古代兵器と進むうちに互いを認め合っていく。**そこに両国の思惑が乗ってくる。** 三部作の敵は、盤の上では魔物・守護者・遺跡荒らしだが、物語の敵は**両国の闇**（下記）。

- 一行の変化（いがみ合い → 認め合い）が縦糸、両国の思惑（闇）が横糸。
- 一行は両国の人間なので、国の命令と仲間との板挟みが自分の問題になる。双子の神の一行（二重に制度の外）とは逆で、**制度の内側の人間が、内側の闇と向き合う**。

---

## 舞台 — 国境の山とドワーフの鉱山

- **魔法使いの国と帝国の国境の山。** 冒険者の国も近い（隣接関係 → [../gdd/world.md](../gdd/world.md) 国の隣接関係。魔法使いの国は冒険者の国・聖職の国・帝国に接する）。
- **ドワーフが鉱山として活用している。** 産出物はドワーフの物という取り決めが、**魔法使いの国・帝国・冒険者の国の3国**で結ばれている。
- **取り決めの益は冒険者の国に出るようになっている。** 魔法使いの国と帝国は緊張関係にあり、相手に利する条件はのめない。どちらでもない第三国（冒険者の国）のドワーフに産出物を渡す形が、両国が唯一のめる落とし所だった。
- **多くのドワーフは冒険者の国の出身。** 山の里は魔法使いの国の側にあるが、人は冒険者の国から来ている＝鉱山は三国の人が交わる場所になる。
- 鉱山の奥に太古の文明の遺跡が広がっており、最深部には古代兵器が眠っている（ネタ帳）。
- **魔物が出た原因: 掘り進めた先が遺跡の外縁で、封じられていた合成魔獣が出てきた。** 以後は出続ける。誰かの意図はない（遺跡荒らしは第2部以降に取っておく）。
- **敵は合成魔獣と兵器系の敵が混じる。** 古代兵器っぽいものは割と最初から出す。第1部の終わりに出るのは、その中でも「明らかに古代兵器」と分かるもの（上記 思惑が見える段）。

## 古代兵器 — 魔人を作る炉

古代兵器はランク分けされており、Sランクが「超古代兵器」（[../gdd/world.md](../gdd/world.md) 太古の文明）。最深部に眠る超古代兵器は、**人（デミヒューマンを含む）・魔獣・兵器を合成して「魔人」（仮称）を作るもの**。魔人は**1人で1国を滅ぼす程度の力**を持つ。「かつて世界を滅ぼした」は、これが作った魔人が滅ぼした、と読める（滅びの戦争説 → [../gdd/world.md](../gdd/world.md) 太古の文明）。

- **いま湧き出ているのは失敗作。** 掘り当てて目を覚ました炉が、合成魔獣（魔獣寄りの失敗作）と兵器系の敵（兵器寄りの失敗作）を吐き続けている。第1部の敵はこれ。
- **魔法と工業の両方でできている。** 魔法使いの国は魔法の側を、帝国は工業の側を読める。どちらの国も半分しか読めない。
- 帝国の「抑止兵器」は、魔人を1人持つこと。魔法使いの国の「研究」は、作動させる＝魔人を作ってみること。**どちらも人を材料にする。** 両国の思惑はここで同じ闇に落ちる。
- 「封じる」が必然になる。壊せば中身が溢れる（失敗作が止まらない）ので止めるしかなく、動かせば人を材料にする。
- 呼び名は役割で（[../gdd/worldbuilding.md](../gdd/worldbuilding.md)）。「魔人」は仮称。陣営で呼び名が変わってよい（学者の呼び名・帝国の呼び名・ドワーフの呼び名）。

### 魔人は盤に出る — 遺跡の力で仕留める

- **完成した魔人は盤に出る**（第3部の山場）。一行の7人だけでは倒せない格のもの。
- **この遺跡には、中途半端な魔人を壊す装置がある**（炉の付属＝出来損ないを処分するための仕組み、と読める）。一行はこれを活用して魔人を仕留め、それでやっと止められる。
- 盤の上では「装置を動かす」が勝利の手順になる。魔人を装置の効く所へ追い込む・装置を守る・起動役（技師か学者か）を届ける、のどれで作るかは第3部を詰めるときに決める。
- **盤に出る魔人は完成品ではない。** 壊れた古代兵器で出力される部品を使っているから。だから「中途半端な魔人を壊す」装置が効く。
- **材料: 学者が自分で材料になる。** 魔獣と兵器の部品は遺跡内で調達できる。人の部分だけは誰かが要り、魔法使いの国の学者が「知りたい」の果てに自らを差し出す（上記 魔法使いの国の意思＝知りたい欲が厄災の前でも止まらない、の行き着く先）。誰の学者か＝一行のウィザード／ウィッチ本人か、第2部で密命と共に来る国の学者かは未決（一行の人間だと「撃つ相手は明確に」が揺れるので、後者が素直）。
- **装置は魔獣の力を落とし、兵器の力を削ぐもの。** 装置を掛けても人の部分は残る＝最後の相手は**魔人として強化された魔術師**。盤の山場は「装置で魔獣と兵器の層を剥がす → 強化魔術師と戦う」の2段になる。
- **装置も壊れており、リペアしながら戦う。** 技師の役どころはこれが本命（下記 技師）。

未決: 材料になる学者が誰か、第1部の終わりに出る「明らかに古代兵器」が失敗作のどれか、通常品の古代兵器（銃など）を一行や敵が持つか。

## 両国の闇

物語の敵。盤の上の敵（魔物・守護者・遺跡荒らし）とは別に、一行の背中にいる。深みは1〜2行で見せる（下記 善悪の置き方）。

### 帝国の意思 — 抑止兵器として持ちたい

- **貧しさから脱するために国土を広げたい。** 枯れた土地の国が、力で状況を変えようとする。
- **その手段として古代兵器を使いたい。** ただし、それが厄災であることは認識している。だから撃つためではなく、**抑止兵器として持ちたい**＝持っていることで相手を黙らせ、国土を広げる交渉を有利にする。
- 動機は国全体のもの（貧しさ）で真っ当。手段は独裁的。独裁者の野心と国の貧しさが重なっているので、技師2人は「国のためだ」と信じて密命を受けられる。
- 密命の中身は未決（兵器の確保・学者に渡すな、が素直な線）。技師が信じたものと独裁者が望むものの差が、第3部で割れる。

### 魔法使いの国の意思 — 純粋に自由に研究したい

- **純粋に、自由に研究したい。** それだけ。学者の国として、太古の魔法を誰にも邪魔されずに調べたい。悪意も野心もない。
- ただし、研究を進めれば**結果的に作動させる必要が出る**。厄災を「調べるために」動かすことになり、被害は出そうだと分かっていても止まらない。闇は野心ではなく、**知りたいという欲が厄災の前でも止まらないこと**に置く（滅びの神罰説「傲慢な振る舞いに神々が怒った」と重なる → [../gdd/world.md](../gdd/world.md) 太古の文明）。
- 帝国の「厄災と分かっているから抑止に留める」と、魔法使いの国の「厄災と分かっていても調べる」が正反対。どちらが危ういかはプレイヤーに委ねる。

### 思惑が見える段 — 第2部から

- **第1部には密命がない。** 一行は湧き出たモンスターの討伐で忙しく、いがみ合いは純粋に「反目する混成チーム」のもの。両国もまだ動いていない。
- **第1部の終わりに、敵として明らかな古代兵器が出てくる。** ここで初めて「鉱山の奥に太古の兵器がある」と分かる（何が出るか＝古代兵器そのものではなく、その一端＝は未決）。
- **第2部は、各チームがそれを自国に報告し、密命を受けるところから始まる。** 学者は魔法使いの国へ、技師は帝国へ。ここから疑心が一行に入る。
- 3段（魔物 → 遺跡 → 兵器）と、思惑の段（無し → 密命 → 裏切り）が揃う。

### 一行の最終判断 — 封じる（全員が自分の国を裏切る）

- **1つの国が独占してよい技術ではない。そもそも、今の世界では正しく扱えない。** 一行は最後に古代兵器を封じる。
- **全員が自分の国を裏切る判断をする。** 学者は研究を捨て、技師は密命を捨て、ドワーフは（山の産出物としての）取り分を捨てる。縦糸（認め合い）の到達点が、横糸（両国の思惑）を断つ形になる。
- 裏切りの形（封じ方・国にどう報告するか・その後の一行）は未決。第3部を詰めるときに決める。

## 主役の一行 — 魔法使いの国と帝国の混成軍

**必要に応じて生成されたチーム。** 鉱山で掘り当てたモンスターを倒すために、緊張関係にある魔法使いの国と帝国が、やむなく人を出し合って組んだ。一行の戦う理由は「掘り当てた魔物を倒す」で、国の思惑の外にある（上記 善悪の置き方）。7人。

| | 出身 | 役どころ | 備考 |
|---|---|---|---|
| ウィザード | 魔法使いの国（学者） | 長射程の間接（貫通） | 既存 type。冷静な理屈屋（気質は絵ごとに固定 → [authoring.md](authoring.md)） |
| ウィッチ | 魔法使いの国（学者） | さらに長い射程の間接（貫通） | 既存 type |
| 技師（新 type） | 帝国 | 未決（下記） | 2人 |
| 技師（新 type） | 帝国 | 未決（下記） | |
| ドワーフ | 冒険者の国出身・鉱山の住人 | 硬い壁（山歩行） | 既存 type（60/防60/移4） |
| 両手斧のドワーフ（新 type） | 同上 | 攻撃に特化した重装 | 下記 |
| 盾のドワーフ（新 type） | 同上 | 防御に特化した重装 | 下記 |

- **一行の中に三国が揃っている。** 学者（魔法使いの国）・技師（帝国）・ドワーフ（冒険者の国出身）。会話の掛け合いは、この3組の見方の違いで作る。学者は遺跡を読み、技師は遺跡を動かし、ドワーフは山を守る。
- 双子の神の一行（[twingods.md](twingods.md)）と比べて、前衛は全員ドワーフ＝山歩行で鈍足、後衛は全員間接。**速い駒がいない**一行。鉱山・遺跡の狭い盤なら成立するが、広い盤では手が遅くなる＝盤の設計で受ける（あるいは技師に機動を持たせる）。
- 対空はウィザード・ウィッチだけ。飛行の敵（ガーゴイルなど）はこの2人に全部乗る。

### ドワーフ3種（新 type ×2）

[../gdd/units.md](../gdd/units.md) のロスター調整の指針「重装は攻防合計を揃え、配分で性格づけ（攻／守／均等）」をそのまま使う。既存ドワーフが均等（60/防60）なので、合計120を配分で振る。

- 両手斧のドワーフ — 攻撃特化。目安 80/防40。値は実プレイで。
- 盾のドワーフ — 防御特化。目安 40/防80。値は実プレイで。
- 3人とも山歩行・移4・近接・対空0。型名は陣営中立にする（敵スキンを後から貼れる）。

### 技師（新 type）— 未決

帝国から来た2人。帝国の強みが「攻城兵器と輸送技術」（[../gdd/world.md](../gdd/world.md) 帝国）なので、その線で役どころを決める。**本命は「壊れた古代の装置をリペアする役」**（上記 魔人は盤に出る＝装置をリペアしながら戦う）。第3部の山場がこの役で立つので、第1部から同じ役で育てる。候補は次で、選ぶのはステージを順に詰めるとき。

- 遺跡のギミックを動かす・リペアする役（扉・橋・古代の装置）。盤の仕組みが要る。**本命。**
- 攻城兵器の扱い手（間接の物理＝魔法兵とは別の間接）。既存の投石機系があればその親戚。
- 輸送（馬車の親戚）。一行の鈍足を補う。

## 善悪の置き方 — 撃つ相手は明確に、理由には深みを

この作品は善悪を種族や陣営で固定しない（[../gdd/worldbuilding.md](../gdd/worldbuilding.md) 陣営の色付け、[twingods.md](twingods.md) 秩序も混沌も善悪ではない）。古代遺跡もその線に揃える。ただし会話は短くスキップもできる（[authoring.md](authoring.md) 会話パート）ので、深みは読まないと分からない形では出さない。

- **盤の上の敵は迷いなく敵。** 撃つことにプレイヤーが躊躇する構図は作らない。一行が戦う理由は、国の思惑の外に置く（双子の神の「一行が止める理由は神学の外にある」と同じ）。
- **深みは「なぜそうするか」に置き、1〜2行で見せる。** 説明しない。敵の頭目の台詞1本と、味方の誰かが漏らす一言で足りる。
- **帝国はこの型にそのまま乗る。** 独裁者と、その命令で動く軍が敵。貧しい国が力で状況を変えようとする理由は真っ当で、兵士は悪ではない（[../gdd/world.md](../gdd/world.md) 帝国）。ドワーフが帝国の職人と仲がよい設定が、その一言を言わせる口になる。

## 未決

- 技師（新 type）の役どころ（本命＝リペア。盤の仕組みをどう作るか）。
- 材料になる学者が誰か（一行の人間か、国から来る学者か）。第1部の終わりに出る古代兵器が失敗作のどれか。通常品の古代兵器を誰が持つか（上記 古代兵器）。
