# キャンペーン・ロードマップ

冒険譚（キャンペーン）をボード（シリーズ）単位で並べた全体の見取り図と制作状況。ボードの仕様は [../gdd/stage_select.md](../gdd/stage_select.md) シリーズボード。個々の設計は各冒険譚ドキュメント、共通の制作方針は [authoring.md](authoring.md)。用語（冒険譚／ステージ／シナリオ）は [../gdd/map.md](../gdd/map.md)。

## 凡例

- 難易度: ★☆☆☆☆（5段階）。ボードをまたいで同じ物差し。
- 状況は2軸で管理する。
  - シナリオ: 物語・会話台本・設計（各冒険譚ドキュメント）。未着手／ドラフト／作業中／完了。
  - データ: 盤面・ステージJSON（`godot/data/stages/<冒険譚>/`）。未着手／作業中／完了。

## アイデアネタ帳

シナリオに限らず、ユニットなど、やりたいことを仕様や難易度を決めずに積む場所。膨らんで方向が見えたら、シナリオは上のボードへ移し（シリーズになるなら板を立てる）、ユニットは `gdd/` の各ドキュメントへ移す。世界観の設定は最初から [../gdd/world.md](../gdd/world.md) に書く。1行＝1構想でよい（教える要素・敵・舞台などメモ程度に）。

### シナリオ

- 古代遺跡 — 魔法の王国の話にする。いまの魔法使いの国（[../gdd/world.md](../gdd/world.md)）との関係（前身か別物か）は未定。
  - 鉱山の魔物
    - 鉱山のなかに魔物がでた
    - 敵はキメラなどの合成魔獣系（古代の魔法研究で生まれた生物）
    - 独自ギミックや特殊地形あり
  - 古代遺跡
    - 鉱山の奥には古代の遺跡が広がっていた
    - ゴーレム・ガーゴイルなどの守護系（実は古代兵器を守護している）
    - 遺跡荒らしなんかも登場する
    - ギミック多め
  - 古代兵器
    - 遺跡の最深部には、かつて世界を滅ぼした古代兵器が眠っていた
    - 古代兵器の取得を巡る国同士の軋轢も入る
    - 特殊な勝利条件があっても良い気がする

### ユニット

- エンチャンター — ユニットスキルで味方を強化する。ピクシーダスト（[../gdd/skills.md](../gdd/skills.md)）と同じ枠なので、違いをどこに置くか（対象の範囲・持続・チャージなど）は未定。
- サモナー — ユニットスキルで召喚する。生産なしの思想（[../concepts.md](../concepts.md)）に触れるので、入れるなら形を決めてから。
  - 敵専用 — 双子の神の対比（召喚・分裂は混沌＝敵の力の出し方、[twingods.md](twingods.md)）にそのまま乗る。スライムスプリットと同じ扱い。
  - 味方に持たせて「呼び寄せる」 — 生み出さず、ステージ側が与えた戦力（控え）を盤に出す口にする。輸送・出撃の親戚。戦力固定は守れる。
  - 味方に持たせて期限付き — 数ターンで消える。総戦力が一時的に増えるので思想に一番触れる。
- 吟遊詩人（特殊ユニット） — 弱い。ユニットスキルで広い効果範囲にバフ・デバフを掛ける。いまのユニットスキルは対象が隣接1体なので、範囲効果は仕組みの追加になる。
- ケットシー — 味方。扱いは未定。
- 船（乗り物） — 馬車・飛空艇に続く3つ目の輸送。水域だけ進入できる移動タイプを movement.csv に足せば成立する（[../gdd/movement.md](../gdd/movement.md)）。海を川と同じ地形タイプにするか別にするかは未定。使い所は双子の神 第3部の島へ渡る回。第4話（島の海岸・娘たちを船へ逃がす）が本命で、第3話は甲板が盤のまま（[twingods3-advent.md](twingods3-advent.md)）。
