# キャンペーン・ロードマップ

冒険譚（キャンペーン）を難易度帯で並べた全体の見取り図と制作状況。個々の設計は各冒険譚ドキュメント、共通の制作方針は [authoring.md](authoring.md)。用語（冒険譚／ステージ／シナリオ）は [../gdd/map.md](../gdd/map.md)。

## 凡例

- 難易度: ★☆☆☆☆（5段階）。帯（かけだし〜ベテラン）内でも作品ごとに上下する。
- 状況は2軸で管理する。
  - シナリオ: 物語・会話台本・設計（各冒険譚ドキュメント）。未着手／ドラフト／作業中／完了。
  - データ: 盤面・ステージJSON（`data/stages/<冒険譚>/`）。未着手／作業中／完了。

## 邪神三部作（構想中）

3つの冒険譚で1本のスレッドを作る。上の3帯に1つずつ置く。固まった冒険譚から `campaign/<冒険譚>.md` へ分離する（チュートリアル3本と同じ形）。各冒険譚は単体完結させる（[authoring.md](authoring.md) 難度帯と冒険譚の連なり）。

### 背骨

**邪神は器を欲しがる。** 宿れる肉体は稀なので、教団は若い娘を大量に攫って選別する。**選ばれるまで誰も殺されない**（むしろ丁重に扱われる）。選ばれなかった娘も予備として生かされる＝最後に助け出せる。攫われた娘が生きていることが、三部を通した縦糸になる。

主役は通しで**とある冒険者の一行**。各ステージには、その場限りの支援ユニットが出る。**レベルは冒険譚ごとにリセットする**（世界観としての説明はしない＝ゲームの都合と割り切る）。

| | 初級「邪神徒の蠢き」 | 中級「邪神の神殿」 | 上級「邪神復活」 |
|---|---|---|---|
| 危機 | 街 | 国家 | 世界 |
| こちらの立場 | 依頼を受けた冒険者 | 討伐軍の一員 | 戦の裏で送り込まれる刺客 |
| 盤の手触り | 市街・下水・館の小競り合い。追跡もの | 野戦と攻城。数がぶつかる | 潜入。少数で、失えない |
| 支援ユニット | 街の人が1〜2体 | 軍勢が大量に付く | ほとんど付かない |
| 娘の扱い | 出てこない。行方が分からないまま終わる | 大半を解放する。選りすぐりは既に島へ | 残りを助け出す |
| 敵の頭目 | 神官 | 高位神官 | 大司教（教主） |

- **なぜ中級で戦になるか**: 初級で有力者から神殿の存在が知れ、国が討伐軍を出す。教団は隠れるのをやめ、神殿と信徒を挙げて迎え撃つ。ここで初めて教団の規模が絵で見える。
- **なぜ上級が単独潜入か**: 正面の戦では中枢に届かない。削り合っている間に儀式が完成してしまうので、軍が敵を引きつけている裏で、腕の立つ一行に中枢の撃破を託す。中級で味方だった大軍が、上級では画面から消える。
- 駒の数が「少ない→多い→少ない」と往復する。**上級が難しいのは敵が強いからではなく、手駒が戻らないから**。

### 教義 — 秩序と混沌

対立の軸は**秩序と混沌**。舞台は**聖職の国**で、そこが秩序の担い手、邪神教が混沌を崇める（国の設定 → [../gdd/world.md](../gdd/world.md) 聖職の国）。

**混沌の神は形を持たない。** ここから教義が一本で降りてくる。

- **器＝まだ形が固まっていない肉体。** 年若く、これから何になるかが定まっていない者。だから若い娘が選ばれる（条件は「未来の量」ではなく「未確定さ」）。
- **選別が要る理由。** 多くの娘は神の力に耐えられず形が壊れる。耐えられる器を探して大量に集めているので、選ばれなかった娘も予備として生かされる（捨てるわけにいかない）。
- **若者が惹かれる理由。** 聖職の国は信仰上の位階で身分が決まる＝生まれた時点で先が決まっている。そこへ混沌が「お前の人生は決まっていない」と言う。**秩序が厚い国だからこそ刺さる**。
- **流行る理由。** 差し出せば少し返ってくる（力・治癒・幸運）。混沌は「変わること」を許す神なので、恩寵の中身も教義と一致する。効くから広まる。邪信徒が実際に術を使えるのもこれ。
- **混沌は国を持てない。** 形を持たないものは国を作れないので、教団は他国の内側に寄生する＝初級は街の裏の細胞、中級は国の中に封じられていた神殿、上級は島（国ではなく、形を失った場所）。秩序の側には国があり、混沌の側には無いという非対称。

**聖女が器として適格な理由は逆説になる。** 彼女は秩序の側の極み（代々の務めを継ぎ、定められた役目だけを生きた）で、混沌が求める未確定さの正反対。読み方は2つあり、併用できる。

- **冒瀆として**: 混沌が最も欲しがるのは、最も硬く定まったものを崩すこと。封を守る血筋の最後の一人を器にする＝秩序の象徴を混沌が着る
- **強度として**: 神に触れて生きてきた血筋なので壊れない。普通の娘では耐えられない

**一行は二重に制度の外にいる。** 冒険者の国から来た余所者で、かつどの組織にも属さない。だから初級で「教会も自警団も動かない事件」が外の人間に回ってくるし、終盤で制度の内側（有力者）に混沌が入り込んでいたと判る。秩序の制度に属さない者が、秩序の側で戦う。

#### 秩序と混沌が盤に降りる

**陣形スキルは秩序の術。** 秩序の力は形を組むことで発動する＝複数人が定められた配置に就いて初めて力になる。ディバインジャッジメント（パラディン＋占領兵2）は最高位の聖職が率いる術＝秩序の頂点（[../gdd/world.md](../gdd/world.md) パラディン＝騎士団の最高位の称号）。

| | 秩序（こちら） | 混沌（敵） |
|---|---|---|
| 力の出し方 | 形を組む＝陣形スキル・隊列・支援・包囲 | 形を崩す・増やす＝召喚、分裂、変異 |
| 盤での現れ | 配置の噛み合わせで勝つ | 数と不定形で押す |

- **混沌は形を組めない**＝敵は陣形スキルを使わない。いまそうなっているのは実装の都合（[formations.md](../gdd/formations.md) 実装方針）だが、この設定ではそれが仕様になる。将来「敵にも陣形を」と言い出さずに済む。
- **形が崩れていく段階を三部で描く。** 初級＝邪信徒はまだ人の形（集会も見た目は普通の若者）／中級＝深く関わった者の形が崩れ始め、召喚される魔物は混ざり物／上級＝島そのものが形を失い、地形が定まらない。上級の島の異様さが、設定の飾りではなく教義から出てくる。

### 冒険者一行

三部を通して同じ7人。レベルは冒険譚ごとにリセットする。

| | ステータス（対地/対空/防/射/移） | 地形の個性 | 役どころ |
|---|---|---|---|
| ファイター | 50/0/40/1/6 | — | 速い万能の前衛 |
| ドワーフ | 60/0/60/1/4 | 山歩き | 硬い壁 |
| ランサー（仮・新 type） | 40/0/40/1-2/5 | — | 距離2から反撃を受けずに突ける前衛 |
| エルフ | 30/60/10/1-5/4 | 森歩き | 対空の主力。防御は紙 |
| ウィザード | 40/40/30/2-4/4 | — | 長射程の間接（貫通0.5） |
| シーフ | 50/10/20/1/7 | 軽歩行 | 遊撃（攻撃後移動） |
| プリースト | 40/0/20/1/2 | — | 聖職（占領可）。鈍足 |

- **地形の個性が3つ揃っている**（山＝ドワーフ／森＝エルフ／軽歩行＝シーフ）＝舞台が変わるたびに主役が入れ替わる一行。
- 穴は2つ。**対空がエルフとウィザードだけ**なので飛行の回はこの2人に全部乗る。**プリーストが移動2**なので後方が渋滞する。
- この渋滞は聖女と噛み合わせると美点になる＝**鈍足の後衛塊（プリースト＋聖女）を前衛3人でどう囲うか**が中級後半の盤の骨格になる。
- **ナイトはパーティに入れない。** 国の軍人＝支援ユニット（軍）側の顔として取っておく。

#### ランサー（仮・新 type）

前衛をもう1枚足すための新 type。別の型に差し替える可能性があるので仮。

- **40/0/防40/射1-2/移5・歩兵・対空0**。ファイター（50/防40/移6/射1）に対し、攻撃-10と移動-1を払って、距離2から反撃を受けずに突ける。
- [map_patterns.md](../gdd/map_patterns.md) の戦力見積もり式（射程は実効防御に +10/1マス）では ファイター 50×40=2000 に対し ランサー 40×(40+10)=2000 で**同格**。性格だけが違う。
- 射程は `2` ではなく **`1-2`**。`min_range` が2だと懐に入られて何もできない駒になり、前衛として使えない。
- **対空は0のまま**。持たせると一行の穴（対空が2人だけ）が埋まって「誰を守るか」の問いが弱くなる。[units.md](../gdd/units.md) の「歩兵の近接は対空なし」とも揃う。
- 移動5は、毎ターン自由に「距離2を選び直す」ことをさせないための値（見積もり式では移動5と6は同じ扱いだが、盤では効く）。
- 型名 `lancer` は陣営中立なので、敵スキン（オークランサー／スケルトンランサーなど）を後から貼れる。

#### 陣形スキルの扱い

**この一行は自前では陣形スキルが1つも成立しない**（トリニティスペル＝術者3体に対しウィザード1人／ホーリーアリア＝占領兵5体に対しプリースト1人／ディバインジャッジメント＝パラディン不在）。看板機能なので、**支援ユニットを材料にして賄う**。

- 初級: 支援が1〜2体なので陣形は基本出ない
- 中級: 軍が付くので、術者3人が揃う回・聖職5人が揃う回を作れる＝**軍が居るから撃てる**
- 上級: 支援が付かないので撃てない

「大軍が居るから撃てた技が、潜入では撃てない」が機構として出る＝上級の孤独さが台詞ではなく盤で分かる。

### 初級「邪神徒の蠢き」ステージ骨子（ドラフト）

背景: 最近、若い娘の失踪が多い。若者のあいだで怪しげな信仰が流行っている。

| # | シナリオ |
|---|---|
| 1 | 人さらいが若い娘を誘拐しようとしている場面に出くわし、娘を守る |
| 2 | 酒場で人さらい退治の依頼を受け、町外れのアジトを壊滅させる。人さらいの頭のほかに邪信徒が1人混じっている |
| 3 | 若者の集会が開かれる館へ侵入する。邪信徒は殲滅するが、神官には逃げられる |
| 4 | 下水道に邪信徒の巣窟があるとの噂を聞きつけ調査する。道中だけの回 |
| 5 | 下水道の祭壇を見つけ、邪信徒を殲滅する。またも神官には逃げられる |
| 6 | 祭壇は街の有力者の館へ通じていた。神官を追って館へ潜入する |
| 7 | 神官を追い詰めて討つ。有力者も金を出していた末端の1人でしかなく、大規模な組織を匂わせて幕 |

- 攫われた娘は1人も出てこない。「どこへ連れて行かれたんだ」で終わる。
- st1・st2 は人さらい（金）の顔で通し、st3 で信仰が裏にいたと分かる＝プレイヤーの理解が段で上がる。
- 神官に逃げられるのが2回あるので、逃げ方の理由を変える（st3＝集会の人混みに紛れる／st5＝祭壇の隠し扉）。
- st4 は箸休め。下水を知る案内役（浮浪児・清掃人など）を支援ユニットに立てて、この回の顔にする。
- 舞台が市街・下水・館中心なので**ドワーフの山歩きが一度も効かない**。硬い壁としては十分働くが、7話やって一度も彼らしさが出ないのはもったいない。石切場・採掘跡・崩れた地下といった足場の悪い回をどこかに混ぜたい（st4・st5 の下水道が候補）。

### 中級「邪神の神殿」ステージ骨子（ドラフト）

初級で知れた神殿へ国が討伐軍を出す。教団は隠れるのをやめ、神殿と信徒を挙げて迎え撃つ。

**迷いの森は結界。** 邪神殿を封じるために先人が張ったもので、だから聖なる森と呼ばれる。神殿は森の向こうにあるのではなく、森に閉じ込められている＝牢の壁が森。これが「なぜ大規模な神殿が今まで見つからなかったのか」の答えになる。

| # | 舞台 | 内容 |
|---|---|---|
| 1 | 街道 | 討伐軍の緒戦。教団が布陣して待つ。規模が絵で見える |
| 2 | 森の縁 | 先発隊が戻らない。森へ入るが道が閉じ、迷う。生き残りを収容して退がる |
| 3 | 森の神殿 | お告げを受けた聖女のもとへ。教団が彼女を消しに来ている。守り切り、同行を得る |
| 4 | 迷いの森（浅み） | 聖女が開いた細い一本道を進む。外れれば迷う。森の魔物が道を塞ぐ |
| 5 | 迷いの森（奥） | 待ち伏せ。狙われるのは聖女。この冒険譚で一番の護衛戦 |
| 6 | 邪神殿・外郭 | 攻城。攫われた娘たちの痕跡に行き当たる |
| 7 | 邪神殿・大伽藍 | 高位神官を討つ。娘の大半を解放。選りすぐりは既に島へ |

- **前半3話の役割**＝「戦を見せる → 壁にぶつかる → 鍵を取る」。st2 は**勝っても前進できない**回で、st3 の必要性がプレイヤーの側から出てくる。
- st2 で迷った森を st4 で通れるようになる＝**同じ地形が前後で意味を変える**。聖女の価値が説明ではなく体験で分かる。
- **森に気づくのも、近くに神聖な森の神殿があったことを思い出すのもエルフ**（長命種）。盤でも同じ役を担う＝st2 で他の6人が身動きの取れない森を、エルフだけが森歩きで動ける。それでも道が見つからないから「森の神殿へ行くしかない」に説得力が出る。st4・st5 でも、細い一本道を全員が歩く中、**エルフだけが道から外れて側面を守れる**。
- **幕は「勝ったが、遅かった」。** 神殿は選別の場で、選別は既に終わっていた。高位神官がやっていたのは後始末と時間稼ぎ。ただし単体完結は死守する＝国の危機は去り（神殿は壊れ、国内の教団組織は崩れる）、娘の大半は家へ帰る。残る余韻は「選ばれた数人の行方が誰にも分からない」だけ（解放された娘たちも何も聞かされていない）。

### 聖女

中級 st3 で加入し、上級まで通して同行する。**死んだらその時点で敗北**（中級 st3〜7・上級 全話）。中級 st3 が初教示。

- 迷いの森の封を守る務めを代々継ぐ者。教会の系譜ではない、忘れられた古い信仰の最後の一人。森の縁の小さな神殿にひとりで暮らしている。世間から忘れられているから、国も「森を抜ける手立てがある」ことを知らなかった。
- お告げを受けて待っているところへ、冒険者たちが来る。**邪神を封じるのが自分の責務だと信じているので、止めても神殿までついてくる**＝護衛が押し付けではなく彼女の意思の結果になる。

ユニット案（値は仮）:

| 項目 | 案 |
|---|---|
| 対地 / 対空 | 0 / 0（攻撃できない。反撃もしない） |
| 防御 | 40〜50（殴られてもすぐには落ちない） |
| 移動 | 4・普通の歩行（**森歩きにはしない**。森を自在に動く役はエルフのもので、聖女まで動けると「細い一本道」の意味が消える） |
| 占領 | 不可（守られる側に徹させる） |
| スキル | 癒し＝隣接する味方1体の兵数を回復。チャージ付き。回復量は聖女の残兵数に応じる |

- **癒しを主スキルに推す理由は上級**。いま回復手段は拠点と泉だけなので、潜入の上級では**回復手段が聖女ひとりになる**。守る理由が「死んだら負けだから」だけでなく「彼女が居ないと立ち行かないから」になり、ルールの縛りと実利が二重に効く。削られた聖女の祈りは薄い（ピクシーダストと同じ考え方）。
- **森を通す力はスキルにせず存在効果**として盤の作りで表す。操作させると毎ターン押すだけのボタンになる。

### 上級「邪神復活」ステージ骨子（ドラフト）

**導入の流れ**: 第2部で邪神殿が壊れ、国内の教団組織は崩れた。邪神教は表向き影を潜めている。しかし第2部のボス（高位神官）は倒される前に、**聖女の存在を島の本部（大司教）に伝えていた**。聖女は邪神の器として適格であり、教団は刺客を送って奪いに来る。

同時に、**島とは反対の方角で邪神教の大規模な活動が観測される**。これは囮だが、規模が大きすぎて軍は制圧に向かわざるを得ない。聖女に神託が下り、島の存在と儀式の進行を知る。軍は囮の方へ、**冒険者一行だけが島へ向かう**。

通しのテーマ: **潜入。8人（7人＋聖女）で島に乗り込み、儀式を止める。回復は聖女の癒しだけ。1人も失えない。**

| # | 舞台 | シナリオ |
|---|---|---|
| 1 | 街（野営地） | 聖女に刺客が襲ってくる。撃退する。開幕＝8人だけで戦う手触りを最初に見せる。刺客は少数だが精鋭 |
