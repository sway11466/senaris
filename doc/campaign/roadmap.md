# キャンペーン・ロードマップ

冒険譚（キャンペーン）を難易度帯で並べた全体の見取り図と制作状況。個々の設計は各冒険譚ドキュメント、共通の制作方針は [authoring.md](authoring.md)。用語（冒険譚／ステージ／シナリオ）は [../gdd/map.md](../gdd/map.md)。

## 凡例

- 難易度: ★☆☆☆☆（5段階）。帯（かけだし〜ベテラン）内でも作品ごとに上下する。
- 状況は2軸で管理する。
  - シナリオ: 物語・会話台本・設計（各冒険譚ドキュメント）。未着手／ドラフト／作業中／完了。
  - データ: 盤面・ステージJSON（`data/stages/<冒険譚>/`）。未着手／作業中／完了。

## 邪神三部作（構想中）

3つの冒険譚で1本のスレッドを作る。上の3帯に1つずつ置く。固まった冒険譚から `campaign/<冒険譚>.md` へ分離する（チュートリアル3本と同じ形）。各冒険譚は単体完結させる（[authoring.md](authoring.md) 難度帯と冒険譚の連なり）。

### 背骨

**邪神は器を欲しがる。** 宿れる肉体は稀なので、教団は若い娘を大量に攫って選別する。**選ばれるまで誰も殺されない**（むしろ丁重に扱われる）。選ばれなかった娘も予備として生かされる＝最後に助け出せる。攫われた娘が生きていることが、三部を通した縦糸になる。

主役は通しで**とある冒険者の一行**。各ステージには、その場限りの支援ユニットが出る。**レベルは冒険譚ごとにリセットする**（世界観としての説明はしない＝ゲームの都合と割り切る）。

| | 初級「邪神徒の蠢き」 | 中級「邪神の神殿」 | 上級「邪神復活」 |
|---|---|---|---|
| 危機 | 街 | 国家 | 世界 |
| こちらの立場 | 依頼を受けた冒険者 | 討伐軍の一員 | 戦の裏で送り込まれる刺客 |
| 盤の手触り | 市街・下水・館の小競り合い。追跡もの | 野戦と攻城。数がぶつかる | 潜入。少数で、失えない |
| 支援ユニット | 街の人が1〜2体 | 軍勢が大量に付く | ほとんど付かない |
| 娘の扱い | 出てこない。行方が分からないまま終わる | 生きていると分かる | 助け出す |

- **なぜ中級で戦になるか**: 初級で有力者から神殿の存在が知れ、国が討伐軍を出す。教団は隠れるのをやめ、神殿と信徒を挙げて迎え撃つ。ここで初めて教団の規模が絵で見える。
- **なぜ上級が単独潜入か**: 正面の戦では中枢に届かない。削り合っている間に儀式が完成してしまうので、軍が敵を引きつけている裏で、腕の立つ一行に中枢の撃破を託す。中級で味方だった大軍が、上級では画面から消える。
- 駒の数が「少ない→多い→少ない」と往復する。**上級が難しいのは敵が強いからではなく、手駒が戻らないから**。

### 初級「邪神徒の蠢き」ステージ骨子（ドラフト）

背景: 最近、若い娘の失踪が多い。若者のあいだで怪しげな信仰が流行っている。

| # | シナリオ |
|---|---|
| 1 | 人さらいが若い娘を誘拐しようとしている場面に出くわし、娘を守る |
| 2 | 酒場で人さらい退治の依頼を受け、町外れのアジトを壊滅させる。人さらいの頭のほかに邪信徒が1人混じっている |
| 3 | 若者の集会が開かれる館へ侵入する。邪信徒は殲滅するが、神官には逃げられる |
| 4 | 下水道に邪信徒の巣窟があるとの噂を聞きつけ調査する。道中だけの回 |
| 5 | 下水道の祭壇を見つけ、邪信徒を殲滅する。またも神官には逃げられる |
| 6 | 祭壇は街の有力者の館へ通じていた。神官を追って館へ潜入する |
| 7 | 神官を追い詰めて討つ。有力者も金を出していた末端の1人でしかなく、大規模な組織を匂わせて幕 |

- 攫われた娘は1人も出てこない。「どこへ連れて行かれたんだ」で終わる。
- st1・st2 は人さらい（金）の顔で通し、st3 で信仰が裏にいたと分かる＝プレイヤーの理解が段で上がる。
- 神官に逃げられるのが2回あるので、逃げ方の理由を変える（st3＝集会の人混みに紛れる／st5＝祭壇の隠し扉）。
- st4 は箸休め。下水を知る案内役（浮浪児・清掃人など）を支援ユニットに立てて、この回の顔にする。

### 中級・上級（粗い筋）

- **中級「邪神の神殿」**: 初級で知れた神殿へ国が討伐軍を出す。教団は神殿と信徒を挙げて迎え撃ち、大規模戦になる。神殿で娘たちが生きていると分かるが、戦の最中で手が届かない。大司教を討つ。
- **上級「邪神復活」**: 戦は膠着し、削り合ううちに儀式が完成してしまう。軍が敵を引きつけている裏で、腕の立つ一行に中枢の撃破が託される。囚われた娘たちを助け、降臨を止める。
