# ADR-0004: ロゴの書体を OFL のフォントから選ぶ（EB Garamond を採用）

- **ステータス**: 承認済み (Accepted)
- **決定日**: 2026-08-12
- **対象**: タイトルロゴの文字（宣伝素材。ゲーム内で描画するフォントは対象外）

---

## コンテキスト

タイトルロゴを起こす段になった。ロゴは Steam のカプセル画像・起動スプラッシュ・サイト・動画で使われ、いずれ商標登録の対象にもなりうる。構成は紋章（剣の刺さった中央ヘックスを6枚が囲む）と、その下に置く `SENARIS` の文字。

文字は生成AIでは作れない（綴りが崩れる）ため、既存のフォントで組んでパス化する。ここで問題になるのがフォントのライセンスで、論点は3つに分かれる。

1. フォントファイルそのものを再配布する — 多くのライセンスが制限する
2. 打った文字の形を使う — たいてい許される
3. それをロゴにして商標登録する — **ここが分かれ目**。有償フォントの利用規約にはロゴ化や商標登録を明示的に禁じるものがある

Windows 同梱のフォント（Times New Roman ほか）は 3 の扱いが曖昧で、書体そのものに権利が及ぶ国もある。安心して長く使える保証がない。

---

## 決定

**ロゴの書体は SIL Open Font License (OFL) のフォントから選ぶ。** 具体的には **EB Garamond** を採用する。

- OFL は「フォント自体を売らない限り、出力の利用は自由」と明示しており、ロゴ化も商標登録も問題にならない
- 取得元は Google Fonts のリポジトリ `github.com/google/fonts` の `ofl/ebgaramond`（可変フォント）
- `assets/promo-src/logo/fonts/` に `EBGaramond-variable.ttf` と `OFL.txt` を同梱する。OFL は再配布時にライセンス文の同梱を求めるため、両者は必ず一緒に置く
- 制作の流れは、フォントで打つ → 字間を広げる → **パス化（アウトライン化）**。パス化後はフォントファイルを配らないので、成果物の側に OFL の制約は残らない
- 運用の詳細（字間・色・小サイズの扱い）は [../art/promo.md](../art/promo.md) が正本

書体そのものの選定理由は、古典的なセリフ体で線の太さが読みやすさと格調の両立する範囲にあること。カジュアルな書体は世界観に合わない。

---

## 根拠と影響 (Consequences)

### 採用する利点

- **商標登録まで見据えて安全。** 後から「このフォントはロゴに使えない」と判明して作り直す事態が起きない
- **再現性がある。** フォントをリポジトリに同梱してあるので、ロゴを後から作り直せる
- **費用がかからない。** 有償フォントのライセンス料も、用途ごとの追加契約も不要
- 書体を変えたくなっても、同じ条件（OFL）で選び直せば手続きは変わらない

### トレードオフ・留意点

- OFL のフォントは選択肢が有償フォントより狭い。ただし今回の比較では十分な候補が得られた（下記）
- **`OFL.txt` を消さない。** フォントファイルをリポジトリに置いている以上、ライセンス文の同梱が条件になる
- ゲーム内で描画するフォントはこの ADR の対象外。現状 `assets/fonts/RockSalt-Regular.ttf`（Apache License 2.0）を使っており、こちらは配布時の表記義務が別途ある

## 検討した代替案

比較結果の画像は生成時に `assets/promo-src/logo/font_test.png` として作成した（判断後に削除。同じものは再生成できる）。

| 案 | 概要 | 不採用の理由 |
| --- | --- | --- |
| **Cinzel** | ローマ碑文体。大文字専用 | 格調はあるが線が華奢で、白地では弱い |
| **Marcellus** | 線が太めで最も「しっかり」する | 小サイズに強いが、やや素朴 |
| **Cormorant Garamond** | 最も細く優美 | 繊細すぎて小サイズで消えかける |
| **Playfair Display** | 縦横の太さの対比が強い | 装飾性が高く、現代のファッション誌寄りに見える |
| **Windows 同梱フォント** | Times New Roman ほか。追加取得が不要 | ロゴ化・商標登録での扱いが曖昧。国によっては書体そのものに権利が及ぶ |
| **有償フォント** | 選択肢が広い | 利用規約にロゴ化や商標登録の制限があることが多く、確認と契約の手間に見合わない |

## 補足

- 経緯: 5書体を黒地・白地／大小で並べて比較し、EB Garamond を選定（2026-08-12）。
- 紋章側は生成AIではなくベクターで幾何的に作る（盤と同じカメラで投影＝俯角 52°・画角 42°・距離はヘックス半径の7倍）。生成AIを使うのは剣の下絵まで。詳細は [../art/promo.md](../art/promo.md)。
