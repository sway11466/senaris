# itch コメント巡回

Senaris の itch ページに付いたコメントを読んで、日本語で報告する。読むだけのスキルで、書き込みは一切しない。

## 対象

- ゲームページ: https://craftkobo.itch.io/senaris （ページ下部のコメント欄）
- devlog: https://craftkobo.itch.io/senaris/devlog の一覧から各記事を辿り、それぞれのコメント欄

どちらもログイン不要の公開ページ。itch にコメント取得の公開 API は無いので、ページの HTML から読む（WebFetch か curl）。

## 手順

1. ゲームページを取得し、コメント欄を読む。
2. devlog 一覧から記事 URL をすべて列挙し、各記事のコメント欄を読む。
3. 各コメントの投稿時刻（「2 hours ago」「1 day ago」などの相対表記）から、過去24時間以内のものを新着とみなす。毎日1回の巡回を前提にした線引きで、状態ファイルは持たない。
4. 日本語で報告する。

## 報告の形

新着があるとき、1件ごとに：

- どこに付いたか（ゲームページ／devlog 記事名）とコメントへのリンク
- 投稿者名と投稿時刻
- 原文
- 日本語訳
- 返信が要りそうか・急ぐかの一言（バグ報告／質問／感想の別）

新着が無ければ「新着コメントなし」と1行で終わる。表や見出しで膨らませない。

## 注意

- コメントを書かない。Like も押さない。返信するかどうかはオーナーの判断。
- ページが取得できない・構造が変わって読めないときは、その旨を報告して終わる。読めなかったのに「新着なし」と言わない。
- バグ報告らしきコメントには、本文に版番号（0.1.0 など）が書かれているかも見て報告に含める（サポートは版の特定から始まるため）。
