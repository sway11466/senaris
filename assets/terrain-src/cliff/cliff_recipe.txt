# 上面＝上向きに砕けた岩（足場が無い）。1024px の原寸をそのまま切り抜く。
powershell -File tools\gen_terrain_tile.ps1 cliff assets\terrain-src\cliff\cliff_01_raw.png

# 側面＝縦に割れた岩壁。左右シームレスは全幅を保つ限り生きるので、行だけを切る。
# 厚みは180px＝山（140px）より厚い。崖は高さ0.54で山0.36の1.5倍あるので、同じ密度に見せるため。
# +700 は明度が画像全体の平均(47.80)に最も近い帯を13候補から選んだもの（差0.10）。
magick assets\terrain-src\cliff\cliff_side_01_raw.png -crop 1024x180+0+700 +repage -colors 64 -dither None assets\terrain\cliff_side.png

# terrain_skin.csv: elevation 0.54（城壁と同じ＝盤でいちばん段差が大きい）/ orientable full（1枚しか無いので回転と反転で散らす）。
# CSV を直したら JSON を焼き直す:
#   godot --headless --path . --script res://data/terrain/convert.gd
# 画像を差し替えたら .godot/imported/ の当該 ctex/md5 を消してから --import
# （消さないと古い生成物が黙って使われる。実際、旧タイルのまま盤に描画された）。

# 色は山（mountain）と同じ暖色の岩ファミリー。指定 #A89B87（HSL 59.4）に対し、割れ目が多いぶん
# タイルは 46.19 まで落ちる。山 67.05 との差 20.9、荒地 50.8 との差 4.6。荒地（通れる）と崖（通れない）が
# 同じ明るさで並ぶのを避けるため、候補8枚から暗め・明暗むら小（2.34）のものを採った。

# 選定の観点: 破片が中心から放射状に広がる絵は不可。1マスごとに中心が並び、回しても隠れない
# （放射模様は回転で位相が変わらない）。等間隔に近い並びは回転と反転で散るので許容した。
