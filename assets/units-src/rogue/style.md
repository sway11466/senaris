# 悪党陣営（rogue）ユニットの見た目ルール

ローグ一味のスキンを生成するときの正本。全陣営共通のルール（絵柄・陣営カラー＝[doc/art/direction.md](../../../../doc/art/direction.md)／制作スペック・STYLE文と敵陣営の共通方針＝[doc/art/units.md](../../../../doc/art/units.md)）を先に読む。

- 基調色＝赤黒（direction §2 の「敵（汎用）」）。ここは魔獣と違って人間なので、色は服で出す＝黒〜炭色と暗い茶、差し色に深紅（覆面・帯・裏地）。
- 装備の質で階級を出す。雑兵は安物の平服と布、上位ほど黒革・留具・磨いた刃へ上げていく。黒革の一式は下っ端に着せない（性能の弱さと食い違い、盤上で格を読み違える）。
- 弱さはボロさで表さない。破れ・継ぎ当て・襤褸巻きは物乞いに見えて、悪党の悪辣さが消える。弱いのは体格と装備の軽さで示し、服は安物のまま無傷にしておく。
- 表情は悪役。覆面で口が隠れるぶん、目つき（半目・下がり気味の眉）で意地の悪さを出す。怯え・悲哀・同情を誘う顔にはしない。
- 中身は人間。異形にしない＝肌は普通の人間の肌色、牙も角も持たせない。魔獣・亜人と並んだとき「こいつらだけ人間だ」と分かることが、この冒険譚の筋（黒幕は人間）を絵で支える。
- 味方の正規軍と混ざらないようにする。味方＝青〜鋼色の揃った装備、悪党＝黒と深紅の不揃いな私物。鎧は着ない（動きやすさ優先の軽装）。
- 顔は隠す。覆面・目出し帽・目深のフードで、目元だけ見せる。ならず者に見せる手段であり、量産の雑兵が同じ顔に見えないための逃げでもある。
- 陣営内アンカー＝ローグ（雑兵）。他の個体は SUBJECT に「same black-and-crimson bandit gear as the rogue」等を書いて展開する。
- 機能サイン：この一味は魔獣を捕らえて売る連中なので、縄・麻袋・鉤といった「捕らえて運ぶ道具」を必ず1つ身に付ける。武器は刃物（小刀・曲刀・斧）と投石紐で、弓・弩・魔法は持たない。斧は檻や柵を壊す道具の転用、投石紐は革紐と石＝訓練の要らない安物として描く＝どちらも仕事道具の延長であって、支給された兵装ではない。
- 各ユニットの生成 SUBJECT は同フォルダの `{skin_id}/{skin_id}_prompt.txt`。

## 個体の見分け

性能（type）は味方からの借用だが、見た目には持ち込まない。

| ユニット | 借用type | 見分けの特徴 |
|---|---|---|
| ローグヘッド | paladin | 一味の頭目（st6 のボス）。素顔を見せる＝フードも覆面も着けない（下っ端との一番の差）。四十がらみ・後ろへ撫でつけた短髪・薄い古傷。顔は他の駒と同じ丸いチビ顔で、しかめ面・睨み・への字口にしない＝商談中のような穏やかな薄笑い（怖さは表情でなく所業で出す）。仕立ての良い黒革と留具、磨いた曲刀1本、腰に鉤付きの鉄鎖。深紅は首に巻いた布で見せる。板金鎧・兜は着けない（悪党であって騎士ではない）。戦闘演出は `retinue`＝周りを手下のローグで固める |
| ローグアックス | priest | 一味の力仕事役。ローグの上位で、頭目の下。装備は「安物のまま・黒革を1点だけ足す」で中位を出す＝炭色の平服に黒革の前掛けと厚い革手袋、留具は数個だけ（頭目のような一式の黒革は着せない）。顔は隠すが、フードではなく深紅の布を頭に巻く＝小さく見たときローグ（尖った布フード）とシルエットで分かれる。体格はがっしり・首が太い（雑兵との差は装備でなく体で出す）。武器は両手の大斧＝木こり斧を戦闘用に仕立てた無骨なもので、刃は厚く重く、磨いていないくすんだ鉄（頭目の磨いた曲刀より格下）。捕らえる道具は太い縄を襷掛け |
| ローグスリンガー | slinger | 一味で唯一の飛び道具。雑兵の格なのでローグと同じ安物の身なり（炭色の平服・布フード・深紅の布覆面）で、革鎧も留具も持たせない。武器は革の投石紐＋石を詰めた大きな布袋の2点で、これを太く大きく描いて小さくしても分かるようにする＝ローグとの見分けは手元の小刀か投石紐か。弓・弩は持たせない（一味は弓を使わない）。捕らえる道具は肩の縄 |
| ローグ | cleric | 雑兵・アンカー。占領兵（移動2・弱い）。弱さは体格（小柄・撫で肩）と装備の軽さで出し、服は破らない＝安物だが無傷。炭色の平服・布フード・深紅の布覆面、小刀1本、縄と麻袋。革鎧・肩当て・留具の列・磨いた金属は持たせない（強そうに見えると性能と食い違う）。聖職の記号（十字・法衣）も持ち込まない |
| ならず者の馬車 | wagon | 一味の輸送。人を乗せない駒なので陣営内アンカー（ローグ）ではなく、味方の馬車と同じ構造（チビの牽引馬＋幌荷車・御者なし・幌が馬より横に広い）を踏襲し、色と積荷で描き分ける。毛色は黒鹿毛、車体は黒〜炭色、幌の帯だけ深紅。荷は空の黒鉄の檻（丸棒・棘なし）＋縄・麻袋・鉤付きの鎖＝魔獣を捕らえて売る商売がそのまま見える。攻0 なので刃・穂先・棘は一切持たせない |
