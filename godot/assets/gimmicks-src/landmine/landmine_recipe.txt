# 地雷（landmine）。隠れている間（hidden）は絵を置かない＝何も描かない。
# 見つかった後（found）＝床に描かれた黄色い三角の注意マーク（爆弾の図）。爆発した後（spent）＝床に散らばった爆弾の破片。
# どちらも置き方は flat（床に寝かせた板に貼る）。

# master＝raw の白を抜いたもの（白に近い色を全部抜く。雷の紋と同じ）。
magick assets\gimmicks-src\landmine\landmine_found_01_raw.jpg -alpha set -fuzz 8% -transparent white assets\gimmicks-src\landmine\landmine_found_03_master.png
magick assets\gimmicks-src\landmine\landmine_spent_c_01_raw.jpg -alpha set -fuzz 8% -transparent white assets\gimmicks-src\landmine\landmine_spent_c_03_master.png

# 爆発の跡の作り直しの経緯（どれも元絵とプロンプトを残す）:
#   landmine_spent_01（塗りつぶしの焦げ）＝穴に見えた。
#   landmine_spent_b（星形の煤の筋）＝弾けた印に見えた。
#   landmine_spent_c（爆弾の破片）＝採用。

# 盤の絵。map_scale は data/gimmicks/gimmick_visual.csv の行から引く（注意マークと共用）。
# 注意マークと破片は別の物なので、同じ範囲にそろえず、状態ごとに書き出す。
powershell -ExecutionPolicy Bypass -File tools\gen_gimmick.ps1 landmine found=assets\gimmicks-src\landmine\landmine_found_03_master.png
powershell -ExecutionPolicy Bypass -File tools\gen_gimmick.ps1 landmine spent=assets\gimmicks-src\landmine\landmine_spent_c_03_master.png
