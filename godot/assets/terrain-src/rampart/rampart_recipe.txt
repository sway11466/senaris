# 上面＝歩廊の敷石。元絵の中央460px四方だけを使う（全面1024pxだと敷石が17px→盤上で5pxになり砂利に見えた。
# 460なら38px→盤上11pxで敷石として読める）。gen_terrain_tile.ps1 に切り出し引数が無いので先に magick で切る。
magick assets\terrain-src\rampart\rampart_01_raw.jpg -crop 460x460+282+282 +repage tmp_walk.png
powershell -File tools\gen_terrain_tile.ps1 rampart tmp_walk.png

# 側面＝切石積みの壁面。左右シームレスは全幅を保つ限り生きるので、行だけを切る。

# （前の絵 rampart_side_01_raw.jpg は1段9個で、盤では3.3個＝上面の1.7倍の大きさに見えていた）。
# 切り出しは段の境目から境目まで＝2段ぶん。+381 は明度が画像全体の平均にちょうど一致する帯を13候補から選んだもの。
magick assets\terrain-src\rampart\rampart_side_02_raw.jpg -crop 1024x130+0+381 +repage -colors 64 -dither None assets\terrain\rampart_side.png
