盤の駒（立ち絵）— map_scale は terrain_skin.csv の plain_fort_elfvillage1 の行から引く。
マスの中で手前に寄せる量は CSV の object_foot_z（0.45 → 0.55 に上げた。駒の 0.6 より小さく保つ）。
_team0/_team1 は CSV に行が無いので、ツールが末尾の _team{N} を落として同じ行を読む
（3枚が同じ大きさで出る＝占領で貼り替えても駒が跳ねない）。

powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_fort_elfvillage1 assets\terrain-src\fort_elfvillage1\fort_elfvillage1_03_master.png -Object
powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_fort_elfvillage1_team0 assets\terrain-src\fort_elfvillage1\fort_elfvillage1_team0_03_master.png -Object
powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_fort_elfvillage1_team1 assets\terrain-src\fort_elfvillage1\fort_elfvillage1_team1_03_master.png -Object

盤の _03_master はオーナーが白抜き済み（中立・team1 はトリム済み、team0 は 1024 正方のまま。
-Object が自分でトリムするので、どちらでも同じ大きさで出る）。

戦闘の奥絵 — トリムのみ（町と同じ）。里は小屋3軒＋木の横並びで、トリム後の比率が 972x330 ≒ 2.9:1 と
帯の形になるので、礼拝堂のような余白足しは要らない。

magick assets\terrain-src\fort_elfvillage1\fort_elfvillage1_combat_03_master.png -trim +repage assets\terrain\plain_fort_elfvillage1_combat_back.png
（team0/team1 も同様に fort_elfvillage1_combat_team{N}_03_master.png -> plain_fort_elfvillage1_team{N}_combat_back.png）

戦闘の _03_master は _01_raw(jpg) から四隅フラッドフィル（fuzz 7%）で白を抜き、そのあとアルファを 1px 削って
フリンジ（縁に残る明るい輪）を落としたもの。削る量は縁1px 輪の明るさ（黒地の上・0〜100）で決めた＝
白抜きのみ 56 → 1px 削り 16.8（オーナー白抜きの盤の master が 17.3）。2px 削ると 34 に戻る（輪郭線を越えて中の明部に届く）。
-blur 0x0.5 はアルファの縁を柔らかくする（2値のままだと縮小時にぎざつく）。
（3枚ともトリム枠が一致＝分岐で造形が据え置かれている）:
magick {n}_01_raw.jpg -alpha set -fuzz 7% -fill none -draw "alpha 0,0 floodfill" -draw "alpha 1023,0 floodfill" -draw "alpha 0,1023 floodfill" -draw "alpha 1023,1023 floodfill" -channel A -morphology Erode Diamond:1 -blur 0x0.5 +channel {n}_03_master.png

戦闘の手前絵（編み垣）— オーナーが白抜き済みの master（1360x208）を、詰所の石塀（935x167 ≒ 5.6:1）と
同じ縦横比になるよう右寄せで切り出す（左は画面の外へ抜けるので落として構わない）。
magick assets\terrain-src\fort_elfvillage1\fort_elfvillage1_combat_front_03_master.png -gravity East -crop 1165x208+0+0 +repage assets\terrain\plain_fort_elfvillage1_combat_front.png
