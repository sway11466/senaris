（3枚が同じ大きさで出る＝占領で貼り替えても駒が跳ねない）。

powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_grave1_fort_chapel1 assets\terrain-src\fort_chapel1\fort_chapel1_03_master.png -Object
powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_grave1_fort_chapel1_team0 assets\terrain-src\fort_chapel1\fort_chapel1_team0_03_master.png -Object
powershell -ExecutionPolicy Bypass -File tools\gen_terrain_tile.ps1 plain_grave1_fort_chapel1_team1 assets\terrain-src\fort_chapel1\fort_chapel1_team1_03_master.png -Object

戦闘の奥絵 — トリム後、内側（右）へ透過の余白を足して比率 2.25:1 の帯にする。
独立1棟の建物は fort_town の「トリムのみ」だと窓に対して大きく出過ぎるため、
余白で大きさを決める（帯の下端が水平線より下に来ることは実機で確認済み）。

magick assets\terrain-src\fort_chapel1\fort_chapel1_combat_03_master.png -trim +repage tmp.png
magick tmp.png -background none -gravity West -extent {H*2.25}x{H} assets\terrain\plain_grave1_fort_chapel1_combat_back.png
（team0/team1 も同様に fort_chapel1_combat_team{N}_03_master.png -> plain_grave1_fort_chapel1_team{N}_combat_back.png）

_03_master は _01_raw(jpg) から四隅フラッドフィル（fuzz 7%）で白を抜いたもの:
magick {n}_01_raw.jpg -alpha set -fuzz 7% -fill none -draw "alpha 0,0 floodfill" -draw "alpha 1023,0 floodfill" -draw "alpha 0,1023 floodfill" -draw "alpha 1023,1023 floodfill" {n}_03_master.png
-Transparent は使わない。sparkle 透かしはこの6枚では残らなかった（トリム枠で確認済み）。
