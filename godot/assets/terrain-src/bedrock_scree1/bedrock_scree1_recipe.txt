# 上面＝角張った石が積み重なったガレ場（足場が無い）。1024px の原寸をそのまま切り抜く。
# 候補10枚（bedrock_scree1_a〜j.jpg＝生成時のファイル名順）から c・d・g を採った。
# 選定: 変種どうしの明度差 0.5（採用ライン1以内）・彩度 15.6〜16.2・明暗むら 2.2〜2.5。
# 大きな暗い穴のある e/f/i（むら 3.7〜5.9）と、1.3 以上暗い j は外した。
powershell -File tools\gen_terrain_tile.ps1 bedrock_scree1 assets\terrain-src\bedrock_scree1\bedrock_scree1_c.jpg assets\terrain-src\bedrock_scree1\bedrock_scree1_d.jpg assets\terrain-src\bedrock_scree1\bedrock_scree1_g.jpg

# 色: 石の色を荒地の基準色 #A89574 にそろえ、石の隙間の影で落とす。切り抜き後の明度 48.0〜48.9
# （荒地 52.6 より約4ポイント暗い＝同じ色味のまま通れる／通れないが分かれる）。

# 側面＝上面と同じ元絵 c と d を横に継いだ 1920×1024 の帯（tools/gen_side_band.py）。
# ガレ場は向きの無い模様なので、横から見た石の山として読める。
# 石の大きさ: 側面の帯は 1024px＝ヘックス幅2つに貼られ、上面は元絵 1024px＝ヘックス幅1つ。上面と同じ大きさに
# するには帯を元絵2枚ぶんの幅にする（最初 512 幅で切ったら石が上面の2倍に見えた）。
# 継ぎ目: 2枚の間と左右の端を 64px ずつ羽根合成＝石を切らずに横シームレス。
# 縦の繰り返し: 帯の高さは世界で 4×1024/1920≒2.1。盤の縁の落差（0.36＋0.45=0.81）より高いので繰り返しが
# 起きない（城壁は段の境目で切って繰り返しを隠すが、ガレ場には段が無い）。帯は上端から貼られる。
uv run --no-project --with pillow --with numpy python tools\gen_side_band.py assets\terrain-src\bedrock_scree1\bedrock_scree1_c.jpg assets\terrain-src\bedrock_scree1\bedrock_scree1_d.jpg tmp_scree_side.png
magick tmp_scree_side.png -colors 64 -dither None assets\terrain\bedrock_scree1_side.png
