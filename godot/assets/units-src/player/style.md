# 味方（player）ユニットの見た目ルール

味方陣営のスキンを生成するときの正本。全陣営共通のルール（絵柄・陣営カラー＝[doc/art/direction.md](../../../../doc/art/direction.md)／飛行の浮遊必須・制作スペック・STYLE文＝[doc/art/units.md](../../../../doc/art/units.md)）を先に読む。

- 基調色＝青〜鋼色（スティールブルー）＋銀の鎧・白・金の差し色。端正な人間体型（direction §2）。
- 各ユニットの生成 SUBJECT は同フォルダの `{skin_id}/{skin_id}_prompt.txt`。

---

## 1. 役割（兵種）デザイン言語（shape = role）

陣営に関係なく、兵種ごとに「シルエット＋必ず持つ記号」を固定する。色が抜けても役割が読めるように。

| 兵種 | シルエット | 必ず付ける記号 |
|---|---|---|
| 歩兵 | 中肉・地に足 | 剣（小＝新兵／標準／大剣で段階）※紋章型の大盾は壁役ナイトの専用記号 |
| 占領兵（聖職） | ローブ・フード | 十字モチーフ（占領役）※杖は魔法兵と被るので不可。手持ち十字／十字ロッド／十字クロジャー等で段階化 |
| 弓兵 | 細身 | 弓＋矢筒 |
| 魔法兵 | ローブ＋とんがり帽 | 杖／オーブ＋発光 |
| 斥候 | 小柄・前傾フード | 短剣・軽装 |
| 飛行兵 | 翼・浮遊 | 翼＋足元に影で浮遊表現（全陣営共通の必須ルール＝units §1） |
| 精鋭 | 一回り大きく豪華 | 重厚な装備＋オーラ（強そう） |
| 輸送 | 非戦闘・乗り物 | 荷車／船（人型でない） |
| 兵器 | 静物・機械 | 弩砲／柵（オブジェクト） |
| 技師 | つなぎ服 | 工具（スパナ等）を腰に下げる。手は武器・盾でふさがるので、工具は持ち物として見せる |

## 2. 味方28種・個体の特徴

全て「青基調＋兵種の形」。その上でグループ内の見分けを定義する。

### 占領兵（青＋白金）
| ユニット | 見分けの特徴 |
|---|---|
| クレリック | 女性・最も簡素なフード付きローブ・両手で手持ちの十字（基本の治療役／杖は持たない） |
| プリースト | 重めの法衣＋十字ロッド（十字モチーフの錫杖。攻40＝武闘派） |
| ビショップ | 司教帽（ミトラ）＋十字クロジャー（大型の十字付き錫杖。硬い・防40） |
| パラディン | 全身鎧＋十字タバード／マント＋十字柄の剣（聖騎士・最も英雄的） |

### 歩兵（青＋鋼）
| ユニット | 見分けの特徴 |
|---|---|
| ノービス | 若い・軽装・小さめの剣・盾なし（新兵感） |
| ファイター | 片手剣・盾なしの標準（主役の基準形） |
| ヴァンガード | 両手の大剣・一回り重装（移7・突撃役） |
| サムライ | 東洋甲冑＋刀（攻特化70） |
| ナイト | 重装甲＋大盾（歩兵で唯一の盾持ち＝壁）（防70・最も重いシルエット） |
| ドワーフ | 低く頑強・髭・斧／槌（山歩き） |

### 弓兵（青＋緑の自然差し色）

|---|---|

| エルフ | 長耳・優美・長弓・森のマント（対空85） |

### 魔法兵（青紫＋発光）

### 斥候（青＋暗色・軽量）
| ユニット | 見分けの特徴 |
|---|---|
| シーフ | 女性・フードは下ろす（被らない）＋ボブ／ヘアバンド・片手ダガー＋腰の巾着（盗品袋）・へそ出し軽装・ニーハイ（最速移8）。二刀はニンジャに譲る |
| ハーフリング | 小柄・スリング（射程2・撃って退く／弓ではない） |
| ニンジャ | 覆面＋暗装束・二刀 ninjato（移7・物理） |
| クノイチ | 女性の忍・クノイチ装束・忍術（魔法攻撃）＝巻物のみ（刃物は持たない／魔法光・貫通0.5）・対空可（空20）。ニンジャと男女＆武器（巻物の魔法 vs 二刀の物理）で差別化（移7） |

### 飛行兵（青＋足元に浮遊影）
| ユニット | 見分けの特徴 |
|---|---|
| ピクシー | 極小の妖精・虫翅・発光（弱い10/10/10）。指揮棒ほどの短いロッド（魔法兵の長杖より明確に短い＝背丈より小さい）。表情は口角上げの笑顔＋ウィンク（片眉上げ・半目・片方だけ上がる口角は「小憎らしい」顔になるので禁止） |
| ドラゴンナイト | 飛竜に騎乗＋槍（対空90・移12） |
| バードマン | 有翼人＝背に翼が生えた人間（鳥頭・嘴・鉤爪にはしない）・棍棒 |
| ドラゴン | 大型の竜そのもの（70/70/50・威圧感） |

### 精鋭（青＋金・一回り大きく）
| ユニット | 見分けの特徴 |
|---|---|
| ソーサラー | 巨躯の戦闘魔導・重厚＋強オーラ（90/40/80） |
| スナイパー | 長距離狙撃・大型弩／長弓・冷静（射程4・脆い） |

### 技師（青＋工具）
| ユニット | 見分けの特徴 |
|---|---|
| 銃の技師 | 女性・黒髪の高いポニーテール（額を出し、頬の横に髪の房を垂らす）・大きな丸メガネ（目は大きく見せる）・長袖で半ズボンのつなぎ＋膝下のソックス・古代の銃（間接）。銃は片手で持つレトロSFの光線銃で、全体が古代の金属（淡い真珠色の銀に青緑のつや）。銃は遺跡から出た遺物＝木や鉄の部品は付けない（ドワーフが作る銃・帝国の大砲と見分ける）。人柄（天然・機械を可愛がる）は飾りでなく表情と抱え方で出す |
| 盾の技師 | 男性・こげ茶の短髪・額に上げた作業ゴーグル・長方形のタワーシールド。盾の面は遺跡から出た古代の金属の一枚板（継ぎ目が無く、銃と同じ古代の金属の色つや）で、帝国が付けた鉄の縁と革の帯で盾にしている。ナイトの紋章型の大盾とは形で分ける |

### 輸送・兵器（人型でない＝非戦闘とわかる）
| ユニット | 見分けの特徴 |
|---|---|
| 馬車 | 馬＋幌荷車（4体積載） |
| 飛空艇 | 小型の飛行船＝ガス袋＋吊り下げた木造船体（6体積載）。攻10/10 なので丸い砲口の砲を1門だけ持つ（刃物は付けない） |
| バリケード | 板壁＋支柱の静物（攻0・壁防80）。攻0 なので尖った杭・刃は付けない（[doc/art/units.md](../../../../doc/art/units.md) §1） |
| バリスタ | 据置の大型弩砲（射程6・静物）。人は乗せない。正面は左右対称に弓臂を張り、矢は斜め上へ向ける（対空も撃つ）。地形の柵と紛れないよう陣営色・鉄帯・二層の厚みで描き分ける |
| 移動砲 | 火薬の大砲（帝国の兵器）。鉄の砲身を木の砲架と大きな車輪2つに載せる。蒸気で自走する＝砲身の下に丸いボイラー、後ろに短い煙突2本（煙・火は描かない）。人は乗せない。正面は砲身を斜め上へ向ける（対空も撃つ）。バリスタとは弓臂の無い筒と車輪で見分ける |
| 移動壁 | 蒸気で自走する鉄の盾（攻0）。木の枠の前面に鋲打ちの鉄板を張った厚い壁＋短い車輪2つ。ボイラーは壁の裏に隠し、正面からは上端の中央から煙突1本だけ見せる。攻0 なので尖った物は付けない。バリケード（木の板壁＋斜めの支え脚）とは鉄板と車輪で見分ける |
| トロッコ（改良前） | 蒸気で自走する小さな鉱山の荷車。青灰色の木の箱に鉄帯、レール用の小さな鉄の車輪4つ。後ろに丸いボイラーと短い煙突1本（煙・火は描かない）。人も荷も乗せない |
| トロッコ（改良後） | 改良前と同じ車体に、前の縁の中央へ操舵ハンドル（丸い鉄の輪）を足す＝レールの外も走れる印 |
