# 機械陣営（machine）ユニットの見た目ルール

歯車と金属で動く敵（古代遺跡の兵器寄りの失敗作）のスキンを生成するときの正本。全陣営共通のルール（絵柄・陣営カラー＝[doc/art/direction.md](../../../../doc/art/direction.md)／制作スペック・STYLE文と敵陣営の共通方針＝[doc/art/units.md](../../../../doc/art/units.md)）を先に読む。

- 基調色＝赤黒（direction §2 の「敵（汎用）」）を、この分類では茶色寄りに振る＝真鍮と錆びた鉄の茶色。赤は目・灯りの差し色に留める。
- 洞窟の床（`assets/terrain/plain_cave1.png`＝平均 RGB 138,123,105）と色味が近いので、明度で離す（床より暗い錆色を主にし、真鍮の明るい面で輪郭を立てる）。
- 味方の古代の銃・盾の色（淡い真珠色の銀に青緑のつや）は使わない＝敵味方が紛れる。
- 顔は敵共通の決まり（怖くしない）に従い、目の灯りだけで表情を作る。牙・裂けた口は使わない。
- 陣営内アンカー＝歯車兵。他の個体は SUBJECT に「same brass-and-rusted-iron build as the gear soldier」等を書いて展開する。
- 各ユニットの生成 SUBJECT は同フォルダの `{skin_id}/{skin_id}_prompt.txt`。

## 個体の見分け

性能（type）は味方からの借用だが、見た目には持ち込まない。

| ユニット | type | 見分けの特徴 |
|---|---|---|
| 歯車兵 | cleric | アンカー。遺跡で動き続けていた小型の機械兵。小柄でずんぐりした人型。真鍮と錆びた鉄の茶色。胸の丸い窓から大きな歯車が見える。頭は丸い缶のような形で、赤く光る単眼。武器は持たず、太い腕の先が鉄の塊 |
| ボマー | birdman | 遺跡の飛ぶ機械兵（爆撃）。歯車兵と同じ真鍮と錆びた鉄。丸く膨らんだ胴に赤い単眼、上に2枚羽のプロペラ1基、腹の下の留め金に丸い鉄の爆弾1つ。腕・脚・翼なし。飛行なので浮かせて足元に影。味方の偵察ドローン（古代の金属の色）とは色と爆弾で見分ける |
