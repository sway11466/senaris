# devlog #3 — パッチ 0.1.1

## 設計

狙い：**「遊んだ人の声で、体験版が分かりやすくなった」を1つ持ち帰らせる。**柱は3つ＝移動が動いて見える・ゲーム内マニュアル・小さくなった情報パネル。#1・#2 は設計の回で、この回は初のパッチノート回（[itch_devlog.md](../../../doc/sales/itch_devlog.md) のネタの型1）。#2 で「次の更新で Undead Rush が入る」と言い切っているので、これは更新ではなくパッチだと冒頭と締めで明言し、#2 の約束はそのまま生かす。

方針：チュートリアル1＋腕試し1本（demo-v0.1.1）で遊んで違いが分かる変更だけを書く。ビルドに入っていても盤に出ないもの（礼拝堂・陣形スキルの絵と演出・チュートリアル2の英文・兵器や状態補正の用語）は書かない。着手中の情報パネルの縮小（feature-98）は、週末のビルドに入らなければ記事から落とす。

語り口：#1・#2 と同じ。CraftKobo。主語は Senaris・the game に寄せる。

話の順序：

1. 謝辞。紹介動画（Richard Yorke「This NEW Fantasy Wargame Has NO DICE?! | Senaris Demo」）へのリンクを貼り、遊んで見せてくれたことに礼を言う。動画とコメント欄で「移動が分かりにくい」と分かった。これは 0.1.1 のパッチで、その返答。
2. 移動：移動先をクリックすると駒がそこへ歩いて見せ、着いた場所でコマンド（攻撃・占領・待機）を選ぶ。確定はコマンドを選んだとき。キャンセルすれば駒は元の位置へ戻る。以前はクリックしてもメニューが開くだけで駒が動いて見えず、「移動が起きていない」と読まれて待機を押すまで迷わせていた（動画で実際に起きた）。変えたのは見せ方で、盤の状態が確定するタイミングは前と同じ＝本文では「動いて見えなかった」ことを認め、以前も確定はメニューだったという弁明はしない。
3. マニュアル：ゲーム内マニュアルを入れた。Encircled・支援・地形の効き・占領を、盤の外でいつでも読める。チュートリアルは1ステージ1要素で教えるが、後から読み返す場所が無かった。
4. 情報パネル：右の情報パネルを小さくして盤を広げた。読める情報は前と同じ（移動コストの表は2列に組み直して英語でも桁が揃う）。
5. 小さな変更の列挙（下）。
6. 締め：これは 0.1.1。次の内容更新で Undead Rush（#2 で語った陣形スキルの章）が入る。

小さな変更（5番の列挙。遊んで違いが分かるものだけ）：

- ズームイン／アウトをシステムメニューに置いた。
- 拠点に入れば減った兵が戻ることを、チュートリアル1 st4 の会話で教えるようにした。
- 評価ランクの戦果の数え方を見直した。撃破は開始時の敵数からの引き算ではなく、実際に倒した数の累積。増援を倒せば乗る。
- 0.1.0 の中断セーブはそのまま読める（新しい形式に自動で変換）。ただし撃破の累積は旧セーブに無いので、旧セーブから再開したステージはランクの撃破が 0 から数え直しになる＝この1点は正直に書く。

落としたもの（ビルドには入るが T1 の盤で違いが出ない）：兵器・状態補正の英語の改名、弱者狙いAIのアイコン修正（T1・bounty1 に弱者狙いは居ない）、単体対象スキルのターゲットマークとスキルレポート（T1 でピュリファイの対象になる弱体が無い）、拠点の生来の所属（native）の修正。

用語：画面の語に合わせる（hex / Strength / Encircled）。パッチの語は patch。更新（update）の語は Undead Rush の回に取っておく。

注意：動画への言及は謝辞と「分かりにくかった」の事実だけにし、動画の内容を評しない。先行作の固有名詞は出さない（[youtube.md](../../../doc/sales/youtube.md)）。「直した」を言い訳の形（it was always possible to…）で書かない。分かりにくかったと認めて、どう変わったかだけ書く。

## タイトル

Patch 0.1.1: easier to read, easier to move

## 本文

```html
<p>Patch 0.1.1 is up. This is not the Undead Rush update &mdash; that chapter is still next. This patch fixes what the first players ran into.</p>
<p>First, a thank-you. Richard Yorke played the demo on his channel: <a href="https://www.youtube.com/watch?v=lEoUeTVAuCs">This NEW Fantasy Wargame Has NO DICE?! | Senaris Demo</a>. Watching someone meet the game for the first time is worth more than any amount of testing it ourselves, and the video made one thing plain: the movement was confusing. So that comes first.</p>
<p><strong>Units now walk before you commit.</strong> Click a destination hex and the unit walks there right away, and the command menu opens where it stands: Attack, Capture, Wait. Nothing is locked in until you pick one. Cancel, and the unit is back where it started. Before this patch the menu opened but the unit did not move, so it looked as if nothing had happened, and people kept pressing Wait to find out. Now the board shows the move before it asks for the decision.</p>
<p><img src=""></p>
<p><strong>There is a manual.</strong> The title menu has a new entry, Manual: the rules of Encircled, support, terrain, capturing, and how each enemy type decides what to do. The tutorial teaches one idea per stage, but until now there was nowhere to read an idea again once the stage was over. Everything that decides a fight is written down &mdash; which is the whole point of a game with no dice.</p>
<p><img src=""></p>
<p><strong>The information panel is smaller.</strong> The unit panel on the right took a large bite out of the board. It has been shrunk, and the board gets the space back. It shows the same information as before; the movement cost table is now laid out in two columns so the numbers line up.</p>
<p><img src=""></p>
<p>Smaller changes in the same patch:</p>
<ul>
<li>Zoom In and Zoom Out are in the system menu. Ctrl + mouse wheel still works.</li>
<li>Stage 4 of Goblin Raid now tells you that a unit resting on a fort regains its lost troops.</li>
<li>Rank scoring counts kills differently: every enemy you actually destroy counts, reinforcements included, instead of subtracting the survivors from the starting count.</li>
<li>Saves from 0.1.0 load as they are. One honest note: the kill count is new to the save file, so a stage resumed from an old save counts its kills from zero for ranking.</li>
</ul>
<p>That is 0.1.1. The next content update is Undead Rush, the chapter from the last devlog: mages, Trinity Nova, and the tide of the dead.</p>
```
